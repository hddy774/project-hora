# ALPHA EXCHANGE · 알파 익스체인지

> **새 프로젝트: HORA · 월간 경제 실험실**
>
> 월 단위 경제 생태계 기획서의 별도 Godot 검증 프로젝트를 [games/monthly-economy](games/monthly-economy)에 추가했습니다. [실행 안내·구현 범위](games/monthly-economy/README.md)와 [요구 추적표](games/monthly-economy/docs/requirements.md)를 참고하세요. `monthly-economy/…` 시험판은 아래 알파 익스체인지의 정식 업데이트와 구분합니다.

투자자 100명이 5업종·15종목에서 경쟁하는 완전 오프라인 Android 경제 관찰 게임입니다. 새 투자자의 출자금/초기 순자산은 각각 1억원입니다. 개인 AI·개인 통계는 없으며 은행은 주식 투자·인수·대여·투자자 신용 공급을 하지 않습니다.

[최신 정식 APK 다운로드](https://github.com/hddy774/project-hora/releases/latest)

v1.14.0은 밝은 리서치 보드에 실제 처리 배속을 표시하고 반복 평가와 실행 경계를 개선합니다.

- **5개 주요 메뉴:** 시장·투자자·자산·통계·더보기. 더보기의 관찰 도구에서 랭킹·뉴스·시즌·기업 상세·기록 메뉴를 엽니다.
- **공통 보고서 선택:** 통계 9개 관점과 기업 재무·분석 7개 관점을 선택해 현재 현황과 기간 추이를 비교합니다.
- **일관된 숫자 표시:** 금액·가격·주식수·누적 횟수·건수·기록수·평가수·포인트는 기본 만·억·조입니다. 화면과 모달의 공통 ‘숫자: 축약 +’ 버튼으로 호가·랭킹·재무·지분·누적 수량·차트 축과 선택값까지 정확 표시로 전환합니다. 사용자가 바꾼 모드는 보관됩니다.
- **판단 근거와 결과:** 선택 투자자의 공개 신호·확신·비용·위험·유동성·주문 이유와 사후 예측 평가를 확인합니다. 예측과 실제 체결·손익은 구분하며 수익을 보장하지 않습니다.
- **차트 탐색:** 실제 기록 시각·값·단위를 선택하고 고정 확대에서 첫/마지막 점으로 이동합니다. 누락 시간은 보간하지 않습니다.
- **기록과 AI 개선 자료:** 일반 게임·통계 백업 외에 게임·판단 기록·허용된 AI 관련 소스와 규칙이 담긴 자료를 별도로 내보낼 수 있습니다. 서명키·비밀번호는 포함하지 않습니다.

회사 공통 50종·전체시장 50종·15종목 테마 각 50종의 뉴스 850개와 분할·병합·소각·증자·합병·대체상장을 제공합니다. 초기 가격과 전체 시가총액 1조원은 유지합니다. 초기·신규 상장 시 자사주는 80%이고 나머지 유통 지분 중 투자자 미보유 수량은 개미 잔여 지분입니다. 실제 기업행동 후 지분율은 달라질 수 있습니다. 통상 주식 50% 목표에 실보유·예약·회전율 한도 내 소량 유동성 호가 예외를 두어 급락 뒤에도 투자자 간 경쟁을 이어갑니다.

Android 8.0 이상, ARM64/x86_64를 지원합니다. `AlphaExchange-v1.14.0.apk`는 기존 배포키로 서명하여 기존 앱 위에 설치합니다. **v1.13의 state11/SQLite7 시장은 그대로 이어갑니다.** v1.12 이하 시장은 DB·WAL·SHM 원본과 백업을 보관하고 새 규칙의 시장을 시작합니다. 이전 개인 보유·은행 대여 계약을 새 규칙으로 변환하지 않습니다. 업데이트 전에 앱의 기록 내보내기로 백업할 수 있습니다. 서버·계정·인터넷 권한이 필요하지 않습니다.

실제 배속은 최근 완료한 게임 시간의 추정치이며 목표 배속·계산 대기와 구분합니다. 호스트 동일 입력 계산은17.8% 단축했지만 소프트웨어 에뮬레이터100배속 기준은 미달입니다. 기기별 처리량이 다르며 실기기 FPS·배터리는 미측정입니다.

알파 익스체인지 관련 파일은 APK 배포·설치 안내·배포 서명 자동화에 사용합니다. **알파 익스체인지** 개발 소스·전체 기획·설계·검증·복구 가능한 Git 이력은 소유자의 비공개 Notion 보관본에서 관리합니다. 기존 알파 익스체인지 배포 태그로 GitHub가 자동 생성하는 Source code ZIP/TAR에는 해당 게임 소스가 포함되지 않습니다. 새 HORA 검증 프로젝트의 소스는 위 별도 폴더에 공개되어 있습니다. 과거 숨은 PR참조18개는 GitHub 삭제 제한으로 남아 있습니다.
