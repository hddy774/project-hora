# 선로만상록 PC · Chronicles of Myriad Immortal Paths

현재 버전은 루트 `VERSION`에서 관리하며 `대표.중간.소규모` 형식을 사용합니다. 기능
업데이트마다 `scripts/bump-patch-version.ps1`이 소규모 버전을 한 단계 올립니다.

10,000명의 수선자가 실시간으로 수행하고 싸우며 전투력 랭킹 1위를 노리는
Windows용 자율 관찰 시뮬레이션입니다. 플레이어는 세계를 조종하지 않고 인물을
추적하고, 판단 이유와 전투 타임라인, 순위 변동과 돌파 기록을 관찰합니다.

## 현재 구현

- 10,000명 이벤트 기반 실시간 AI
- 12개월×30일 년·월·일 달력과 모든 AI의 달마다 최대 1회 행동
- 영근·근골·체질·오성·정신·영혼의 6대 수행자질과 영혼 연속 윤회
- 폐품부터 무결품까지 0.01 단위 품질 체계와 경계별 격차 배율
- Notion Alpha 1.1.3 기반 5세 입문 Work·3 Gate→9층 Work→준비→Preflight→
  병목/안착→대원만 수행 흐름
- 선천 수행자질 50.00에서 대경지 1층→9층 대원만 전체가 최대 수명 3분의 1인 기준 기간
- 불변 공법/법술 품질, 누적 수련 경험·0.00~100.00 숙련도와 깨달음 이해도
- 자질 직접 전투력 0, 공법·법술·전투 숙련·전투 이해·전투 경험의 50%~200% 간접 보정
- 전투 경험에서 파생되는 0.00~100.00 전투 숙련도와 별도 전투 이해도
- 선택형 수요 임무, 유한 광맥·채굴 인력, 도시 생산 영석과 수선자 간 공동 시장 매매
- 법보 재료·단약 재료 2종과 대경지별 성장/돌파 단약·방어/공격 법보를 포함한 44개 상품
- 도시 기준가·품질·재고·공급·수요에 따른 동적 가격과 수요 기반 생산 대기열
- 본명법보·방어 법보·공격 법보 3칸과 실제 공격·방어 효과
- 재료와 영석으로 직접 만드는 본명법보 및 대경지 돌파와 동기화되는 본명법보 등급
- 경지·공법·법술·전투 성장·법보를 분해한 표시 전투력과 별도 실전 전투 속성
- 교대식 장기 전투, 경상~사망상 누적 부상, 전투 사망과 윤회
- 전원 1위를 목표로 하는 도전·방어 경쟁, 전투력·경지·자질 TOP 1,000 랭킹
- 만상성을 중심으로 한 3×3 지도와 클릭식 지역별 요수 개체수·수선자 탐색
- 랭킹 밖의 인물까지 10,000명 전부 조회하는 페이지 탐색과 이름·ID 검색
- 전체 경지·전투력 분포, TOP 1·3·5·10 전투력/경지 변동, 승패·사망·윤회·경제 통계표
- 일시정지, 배속, 검색과 인물 추적
- 통계·도시·분류/검색형 44개 상품 상세 시장·지역별 3×3 지도·중요 세계 로그 외부 탭
- 시장의 상품 개요/가격·수급/도시 생산, 지도의 지역 개요/요수 생태/100명 수선자 페이지 내부 탭
- 선택 탭만 조회·갱신하는 외부/내부 탭, 접기식 통계와 가상화 목록
- `대경지 · 초기/중기/후기/대원만 · 1~9층` 통일 표기
- 종류별 내부 탭을 가진 최근 로그 100줄과 생별 토글·종류 탭으로 보는 영구 연대기
- 결정론적 저장·불러오기와 Windows x64 배포
- 0세 탄생부터 소·대경지 돌파, 사망과 환생을 잇는 개인 일대기
- 전투력 구성요소와 입력·보정·합산값을 함께 공개하는 상세 계산식

게임 내 **저장**과 **불러오기**는 `%LocalAppData%\ChroniclesOfMyriadImmortalPaths\world.cmip`을
사용합니다. 저장 파일은 압축되며 checksum 검증을 통과한 경우에만 복원됩니다.

기획 정본은 [게임 디자인](docs/GAME_DESIGN.md), 코드 경계는
[아키텍처](docs/ARCHITECTURE.md), 버전별 상세 내용은 [변경 이력](CHANGELOG.md)을
따릅니다.
수행 구조는 [Notion 선로만상록 정본](https://app.notion.com/p/3acacc9e617580278373c8114c7a9ebb)의

## 개발 빌드

```powershell
dotnet build Chronicles.slnx -c Release
dotnet run --project src/Chronicles.Desktop/Chronicles.Desktop.csproj
dotnet run --project tests/Chronicles.Tests/Chronicles.Tests.csproj -c Release
```

## 이 PC에서 바로 실행

저장소 루트의 `로컬_빌드_및_실행.cmd`를 두 번 클릭하면 전체 테스트 후 Windows x64
독립 실행본을 만들고 바탕화면에 `선로만상록 PC` 바로가기를 생성합니다. .NET 런타임은
실행 파일에 포함됩니다.

자세한 로컬 점검 절차는 [PC 로컬 실행 및 테스트](docs/LOCAL_TESTING.md)를 참고하세요.
