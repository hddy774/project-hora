GITHUB ACTIONS APK BUILD AND RELEASE
.github/workflows/release.yml builds from a merged v*.minor.0 tag, reruns core
and artwork checks, uploads an unsigned APK/source artifact, signs with existing
repository Actions secrets, verifies the original certificate and app identity,
creates a draft release, uploads APK/source/checksums, downloads and checks every
asset, then publishes it as the latest release. The actual workflow run includes
CORE-CHECKS.txt, ARTWORK-CHECKS.txt, APK-VERIFICATION.txt and APK-BADGING.txt.
