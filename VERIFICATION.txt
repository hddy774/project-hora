ALPHA EXCHANGE v1.4.0 — ownership and performance verification, 2026-10-04 UTC

IMPLEMENTATION
Company ownership reconciles institutions + retail + founders + physical bank stock
+ treasury with issued stock. Outstanding stock excludes treasury; float excludes
founders as well. Borrowed stock return obligations and lending reservations are
shown separately and never added twice. Institution holders sort by actual shares
and stable owner ID, with pagination and representative links. Merger tombstones
remain distinct from active companies.

PERFORMANCE CHANGES
Financial rollups accumulate without 10,100 transient statement objects. Long/short
position valuation and institution snapshots avoid repeated scans. Net equity
uses one span-backed traversal for the engine's stock list, preserving per-position
rounding and checked gross/short totals.
PrepareSave deep-copies all mutable state; deferred thread-safe JSON encoding reads
only that copy in the writer. Immutable history strings keep every uncommitted hour;
coalescing world snapshots does not coalesce history. UTF-8 bytes are reused for
compression/hash/header validation, and full JSON syntax is validated without a DOM.
Changes-free automatic saves are skipped; explicit pause/export/back saves still
capture fractional hour progress. JSON representation/database format v5 remains.
The six-metric range extrema query uses two grouped passes rather than 14 scans;
history decoding/hash validation uses UTF-8 directly. Coverage returns contiguous
segments and handles pending/mixed-resolution legacy history with an exact fallback.
Ranking/overview summaries avoid decoding chart rows. Visible charts load their
full bounded range lazily, and offscreen charts/paths/text are skipped. Raw history,
true time axes, gap flags, extrema, chart bounds and save atomicity remain.
