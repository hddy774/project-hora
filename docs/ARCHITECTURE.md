# 기술 아키텍처

## 선택 기술

- 언어: C#
- 런타임: .NET 10
- PC UI: WPF
- 대상: Windows x64
- 배포: self-contained 단일 폴더 패키지

## 모듈

```text
Chronicles.Core
    └── Chronicles.Simulation
            ├── Chronicles.Persistence
            │       └── Chronicles.Desktop
            └──────────── Chronicles.Desktop

Chronicles.Tests ──> Core + Simulation
```

### Chronicles.Core

안정 Agent ID, 정수 simulation tick, 0.01 단위 공통 품질값과 경계 배율, 고정된 정의 ID, 결정론적 난수와 전투력 값
타입을 소유한다. UI, 파일 시스템과 WPF를 참조하지 않는다.

### Chronicles.Simulation

10,000명 권위 상태, AI 결정, 수행·돌파, 공법·법술 품질과 숙련, 도시 임무·재료·영석·
법보·단약 경제, 전투 타임라인, 전투력과
전투력·경지·자질 랭킹, 전체 인물 탐색, 생애 일대기, 수명 판정과 윤회를 소유한다. 렌더 프레임과 벽시계에 의존하지
않는다. 안정 Agent ID는 영혼 슬롯으로 유지하고 생 번호·이름·탄생 tick으로 현생을
구분한다.

달력의 권위는 계속 정수 tick 하나이며 년·월·일은 `GameCalendar`의 12개월×30일
정수 비율 함수로 파생한다. 각 인물은 `lastActionMonth`, 마지막 행동 tick과 행동 누계를
저장하고 예약 함수가 다음 행동을 반드시 다음 달 이후로 올려 같은 달의 중복 행동을
차단한다.

수행은 Notion P09 계약에 맞춰 `CultivationState`와 원인별 병목을 권위 상태로 둔다.
`CultivationProgress`는 현재 단계의 누적 Work이고 Realm Profile이 단계 요구량·수명·
안정 ID·revision을 제공한다. Work 축적, 준비, Preflight, 시도, 병목 또는 안착은 서로
다른 월 행동 경계이며 돌파 시도 전에는 RNG를 소비하지 않는다.

대규모 인물 경제 상태는 인물별 객체 사전 대신 30칸 재료와 7칸 법보의 평탄 연속 배열로
보관한다. 재료 정의·가격·범주는 `EconomyRules`의 안정 enum/정의표에 있고, UI 문자열이나
상점 화면 상태는 권위 세계에 저장하지 않는다.

`CityMarket`은 30개 재료와 수행단·돌파단·법보·공법서·법술서의 총 35개 상품을 연속
배열로 보관한다. 도시 기준가와 현재가를 분리하고 재고·누적 공급·누적 수요·도시 금고를
권위 상태와 save/hash에 포함한다. 임무 납품과 판매는 공동 재고 공급, 구매와 도시 가공은
수요이며, 구매·판매·납품·가공·생산 누계도 save/hash에 포함한다. 거래 UI 조회는 가격을
다시 계산하거나 거래를 발생시키지 않는다.

세계 중요 로그는 고정 100줄 순환 버퍼, 인물별 최근 로그도 고정 100줄 리스트다.
`LifeChronicleEntry`는 별도 무제한 목록으로 모든 생에 걸쳐 누적한다. 세 구조는 모두
문자열 대신 사건 enum·안정 ID·정수값을 저장하고 Desktop에서 문구로 변환한다. 최근
로그는 오래된 줄을 버리지만 연대기는 절대 잘라내지 않으며 schema 7 체크포인트에 함께
저장한다.

### Chronicles.Desktop

SimulationRunner가 게시한 불변 스냅샷만 읽는다. 일시정지, 배속, 검색과 추적
명령을 전달하고 WPF 화면을 그린다. 인물 상세는 최근 개인 로그와 영구 연대기를
분리하고, 우측 탭은 통계·도시·시장·중요 세계 로그 DTO만 표시한다.

### Chronicles.Persistence

Simulation의 명시적 체크포인트를 Brotli 압축 payload와 SHA-256 checksum을 가진
versioned `.cmip` container로 변환한다. 같은 폴더의 임시 파일을 flush한 뒤 원자적으로
교체하며, 손상되거나 지원하지 않는 schema는 세계를 바꾸기 전에 거부한다.

### Chronicles.Tests

외부 테스트 프레임워크 없이 실행 가능한 결정론적 계약 러너로 시작한다. 공식,
랭킹, 경쟁 활성도, 저장 왕복과 10,000명 성능 예산을 자동 검증한다.

## 실행 모델

시뮬레이션은 전용 worker에서 고정 tick으로 실행한다. 각 AI는 매 tick 전부 판단하지
않고 `nextDecisionTick` 또는 예약된 전투 행동 시점에만 활성화된다. 활성화 뒤에도
마지막 행동 월을 확인해 달마다 최대 한 번만 상태 전이를 실행한다. 화면은 제한된
주기로 생성한 불변 조회 스냅샷을 받는다.

전투력·경지·자질 순위 배열은 공식 갱신 경계에서 결정론적 동률 규칙과 함께 정렬한다.
UI에는 범주마다 상위 1,000명만 복사하고 전체 탐색은 안정 Agent ID 기반 페이지 조회를
사용한다. 구현 초기에는 정확성을 우선하고 성능 측정 결과에 따라 순위 자료구조를
최적화한다.

전체 경지·전투력 분포와 승패·사망·경제 합계는 권위 배열을 읽는 불변 통계 DTO에서
계산한다. 랭킹 변동값만 공식 정렬 직전/직후의 순위를 비교해 권위 상태로 누적하며,
통계 화면 조회 자체는 난수·상태 hash·랭킹에 영향을 주지 않는다.
