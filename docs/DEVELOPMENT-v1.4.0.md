지분의 실제 주식 합계는 발행 주식 수와 일치해야 한다. 자사주는 상장 주식 대비 비율에서 제외한다. 은행이 빌려준 주식은 현재 보유 주식과 구분하여 이중 계산하지 않는다. 합병으로 폐지된 회사도 식별 ID로 구분한다.

성능 비교는 Linux .NET Release에서 실행하며 측정 환경과 원자료를 기록한다. Android 에뮬레이터는 화면 동작 확인용이고 물리 기기 FPS/메모리 성능으로 표현하지 않는다. 저장 형식 v5와 기존 파일 내보내기/가져오기를 유지한다.
