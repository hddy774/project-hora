## 적용 기준

- 개인은 가격 흐름·최근 체결·시장 심리에 반응한다. 기업 재무/적정가/배당 분석과 기관의 위험 관리·분산 설계는 사용하지 않는다. 기관 수익이나 개인 손실을 강제로 현금 이전하여 보장하지 않는다.
- 50% 자사주/50% 은행은 새 시장과 새 회사의 기본 발행 구조다. 기존 저장의 실제 보유 주식을 빼앗아 재설정하지 않는다. 신규 초기 투자자는 현금으로 시작해 은행 매도 호가에서 주식을 매수한다.
- 자사주는 배당·의결에서 제외하며, 현재 실제 보유 주식이 투표 권리를 결정한다. 게임은 관찰 시뮬레이터이므로 AI 주주가 투표하고 플레이어는 안건/지분/결과/효과를 확인한다.
- 파산은 회계에 따른 채무 불이행/자본잠식과 운영 불능을 판정한다. 새 주체의 자금은 기존 경제 계정에서 지급하고 현금을 생성하지 않는다. 슬롯은 재사용하되 기업 식별자·투자자 세대를 구분해 과거 기록을 섞지 않는다.
- 불필요한 통계는 중복된 저장·계산과 기본 화면의 반복 정보를 먼저 제거한다. 손익·현금·거래량/금액·기업 재무·파산과 기록 연속성 자료는 유지한다.
- 전후 성능은 같은 Linux .NET Release 환경과 입력으로 비교한다. 변경된 AI/은행/파산으로 체결 경로가 달라지는 시뮬레이션과 동일 상태의 처리 비용을 구분한다. 물리 Android FPS/RAM 개선으로 표현하지 않는다.
