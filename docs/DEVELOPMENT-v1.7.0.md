## 구현과 이전 기준

- 새 시장의 **초기 시가총액**은 정확히1조 원이다. 회사 자사주50%/은행50%와 실제 납입·대여·배당·기업행동 원칙을 유지한다. 시장 가격/규모는 사업·정책·경제에 따라 변하며1조를 강제 유지하지 않는다. 투자 회사100곳은 각10억 현금으로 출발한다. 기존 시장의 잔액·주식 수·확정 원기록은 소급 확대하지 않는다.
- 개미의 한 시뮬레이션 단위는1000명을 대표하는 집단이다. 새 시장은1000집단(100만명), 최대10000집단(1000만명)이며 경제와 실제 유입 재원에 따라 증가한다. 집단은 실제 현금/주식/수수료/배당을 보유한다. 구버전 개미10000개 계정과 기록은 보존한다.
- 완료 시간과 분을 구분하고 주문·체결에 실제 분 시각을 저장한다. 시간별 원통계는 계속 보존하며 최근 체결과 영속 활동에 분 시각을 기록한다. 최근 체결 표시 버퍼160건과 전체 시간 통계·활동 보관은 구분하며, 과거 분 시각을 만들어 보충하지 않는다. 대기 시간·부분 시간 상태·분석/계획도 저장·ZIP에 포함한다.
- 투자 계획은 기간·가치 가설·상하한/손실 한도·현금/분야/종목 예산·안전/중립/공격 성향을 갖는다. 가치·리포트·위험·실제 호가가 바뀌면 재평가한다. 상하한은 체결 보장 가격이 아니며 공매도는 별도 담보/방향으로 판단한다.
- 애널리스트 리포트는 분야별 예상 방향·신뢰도·근거·가격 범위·기간을 기록하는 투자사의 내부자료다. 대표가 주 분석 책임자이며 직원이 보조한다. 다른 AI가 내부 리포트를 읽지 못하고 공공 뉴스에 기밀 내용을 노출하지 않는다. 관찰 화면은 선택한 투자사의 소유자 문맥에서 내부자료를 확인한다.
- 직원은 연구/분야 분석, 주문 집행, 포트폴리오 운용, 위험 관리, 준법/감독, 재무/회계, 거시경제, 데이터/퀀트 직무를 기획한다. 등급·인원·직무 효과·비용은 규칙 데이터로 관리하고 실제 판단/집행에 사용한다.
- 인물은 투자자100,경영자30,정치인50,금융인20으로200명이다. 정치인은25명씩 양당과 지도자/장관/의원 직무를 갖는다. 직무별 프로필/능력을 사용하고 개인 지갑/소득과 운영 법인·정부·은행 계정을 분리한다. 인물의 돈도 시스템 회계에 포함한다.
- 투자자 시즌 포인트는1~10P이며51~100위도1P를 받는다. 분야별 상위3명과 설명 가능한 종합 점수 상위3명을 표시한다. 정치/금융/경영 성과를 투자 수익률 하나로 평가하지 않는다.
- 지도자와 은행 총재는10~30일 사이의 선거로 교체한다. 정부 정책·후원 규제·금리 등 모든 새 결정은 기록되는 투표를 거친다. 이번 구현의 투표 참여자는 인물200명이며 시즌 종합 순위의 투표권을 적용한다. 현실의 선거 주기/정치 제도와 다른 게임 규칙임을 명시한다.
- 후원·정책 영향·단속은 실제 인물/자금/투표/법률 상태로 처리한다. 불법과 합법을 현재 정책 투표로 정하고, 실패/적발의 벌금을 실제 재원에서 정산한다.
- 회사 사업은 예산·추진·실행·매출/비용·결산의 실제 과정과 재무 결과로 연결한다. 현재 관찰 투자자의 **전체 지분 순위 상위3위**이면 내부 사업 과정을 열람한다. 공개 결산·공개 뉴스는 계속 볼 수 있다.
- 신규 뉴스에는 반드시 실제 활동/행동의 인물과 원인 사건이 있다. 독립적인 무작위 뉴스로 가격/실적을 조작하지 않는다. 구버전 뉴스는 이전 기록으로 보관한다.
- 기존 투자자 그림은 유지하고 인물 프로필에 확대 열람을 추가한다. 200명 명부/직무/프로필은 데이터로 관리한다. 그림 캐시·스크롤·긴 통계 조회·저장·시뮬레이션 작업을 검증한다.

## 성능 통과 기준

1. v1.6.0의 기준 측정을 보관한다. 새 기능을 모두 구현한 버전도 먼저 측정한 뒤 같은 입력/작업/결과로 최적화 전후를 비교한다. 집단 수 변화로 생긴 차이와 알고리즘 개선을 구분한다.
2. 100배속은 초당1200게임분이다. 최대10000개미 집단·200명·30회사에서 장기 시뮬레이션의 실제 처리량, 시간 경계/시즌 결산의 지연, 저장 대기/크기, 프레임 작업 비용을 기록한다. 분을 생략하거나 완료 통계를 버리지 않는다.
3. 목표는 지금보다10배다. 측정한 작업별 개선 배수를 남기고 달성하지 못한 부분을 숨기지 않는다. Linux 처리량을 모든 Android 기기의 FPS 보장으로 표현하지 않는다.
4. 경제·현금/실물 주식·개인/법인 지갑·급여/후원·정책 투표·활동 출처·구버전 해시·분 상태/ZIP의 의미 있는 회귀를 통과시킨다. 기능이 같은 최적화는 결정적 재시작과 원장 비교를 검증한다.

조사 출처, 실제 검증과 남은 문제는 같은 PR의 문서와 표에 갱신한다.
