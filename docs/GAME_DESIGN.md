# 게임 디자인 정본 0.1

## 1. 한 문장 정의

플레이어가 개입하지 않는 가운데 10,000명의 AI 수선자가 수행과 전투를 반복하며
전투력 랭킹 1위를 다투는 실시간 관찰 게임이다.

## 2. 플레이어 계약

플레이어는 세계에 능력치, 보상, 명령을 주지 않는다. 가능한 조작은 일시정지,
배속, 검색, 정렬, 인물 추적과 관찰 화면 이동뿐이다. 관찰 여부는 AI 판단,
전투 결과, 공식 통계와 난수 소비에 영향을 주지 않는다.

## 3. 핵심 순환

```text
현재 순위와 약점 평가
        ↓
수행·공법 숙련·법술 연마 또는 상위 상대 도전
        ↓
경지 돌파 / 실시간 전투
        ↓
경험·부상·숙련·전투력·랭킹 갱신
        ↓
1위와의 격차를 다시 평가
```

모든 AI의 최종 목표 순위는 1위다. 다만 현재 상태가 불리하면 회복하거나 성장한 뒤
도전한다. 상위권은 자주 도전받고, 중하위권은 자기보다 조금 높은 상대를 우선 선택해
전 인구에서 경쟁이 이어지게 한다.

## 4. 시간과 경지

- 1배속에서 현실 10초가 게임 시간 1년이다. 권위 시간은 `2,000 tick = 1년`이다.
- 1년은 12개월, 1개월은 30일인 360일 달력으로 표시한다. 월·일은 2,000 tick을
  정수 비율로 환산하므로 월 경계는 166 또는 167 tick 간격이지만 누적 오차는 없다.
- 모든 AI는 같은 달에 최대 한 번만 행동한다. 전투·윤회 때문에 행동 시점이 다시
  예약돼도 마지막 행동 월 다음 달보다 앞당겨지지 않으며, 쉬었던 달의 행동을 몰아서
  처리하지 않는다.
- 지원 배속은 1×, 10×, 25×, 50×, 100×다.
- 각 대경지는 1층~9층을 가지며 UI에서 1~3층은 초기, 4~6층은 중기,
  7~9층은 후기로 함께 표기한다. 9층 Work를 완성한 뒤 대원만을 별도로 판정한다.

| 대경지 | 기본 최대 수명 | 기준 수행 기간 |
|---|---:|---:|
| 연기경 | 150년 | 50년 |
| 축기경 | 300년 | 100년 |
| 금단경 | 600년 | 200년 |
| 원영경 | 1,200년 | 400년 |
| 화신경 | 3,000년 | 1,000년 |
| 연허경 | 9,000년 | 3,000년 |
| 합체경 | 2만 년 | 6,666.67년 |
| 도겁경 | 10만 년 | 33,333.33년 |
| 대승경 | 10만 년(별도 수명 미확정으로 유지) | 33,333.33년 |
| 반선경 | 100만 년 | 333,333.33년 |

모든 대경지의 기준 수행 기간은 **선천 수행자질 6종 산술평균 50.00**인 수선자가
그 대경지 **1층 수행을 시작해 9층 Work를 마치고 대원만에 도달하기까지의 전체
기준 기간**이며, 해당 경지 기본 최대 수명의 정확히 3분의 1이다. 각 층마다 최대 수명의
3분의 1을 따로 적용하지 않는다. 권위 계산은 월 Work를 쓰며
50.00에서 월 1,000 Work가 쌓인다. 9층의 현재 임시 가중치는
`80/90/100/105/110/115/125/135/140`이고 합계 1,000이므로 대경지 전체 기간을
보존한다.

### Notion 수행 정본 적용

수행 구조의 구현 기준은 [Alpha 1 1 3](https://app.notion.com/p/3ccacc9e6175811b9d9afd1e9e916c1b)과
[선로만상록 세계관·게임 기획·개발 정본](https://app.notion.com/p/3acacc9e617580278373c8114c7a9ebb)의
`P09. 수행·자질·윤회` 계약이다. PC판은 다음 의미 경계를 적용한다.

```text
현재 Realm Profile / 소경지
→ 단계별 누적 Work
→ 돌파 준비
→ Preflight
→ 돌파 시도
→ 성공 시 원자적 경지 전이와 안착
   또는 실패 시 원인이 명시된 병목
```

- 권위 진행값은 현재 단계의 누적 Work이며 UI 백분율은 Work/요구량에서 파생한다.
- 모든 수선자는 0세에 태어나 5세까지 준비기를 거친다. 5세부터 입문 Work 30,000과
  영근·근골·오성 중심의 3개 Gate를 검증하고 모두 통과해야 연기경 1층에 입문한다.
- 돌파 확률 RNG는 Work가 찬 순간이 아니라 준비와 Preflight가 끝난 별도 월 행동에서만
  소비한다. 화면 조회와 예상값 표시는 RNG를 소비하지 않는다.
- 병목 원인은 공법·법술 지식, 육신, 영근·영력, 돌파 자원, 정신·영혼 안정성으로
  구분한다. AI는 원인에 맞춰 수련·회복·임무·시장 행동을 선택한다.
- 성공 뒤에는 새 경지 안착 행동을 거친다. 안착과 부상 회복은 같은 상태로 저장하지
  않는다.
- 각 경지는 안정 ID와 revision을 가진 Realm Profile로 조회한다.

Notion에서 수치가 열려 있는 범위보다 이후 사용자 대화에서 직접 확정한 PC판의
10대 경지, 최대 수명, `선천 수행자질 50.00에서 최대 수명의 3분의 1` 수행 기간을
우선한다. 미확정 수치는 게임 진행이 막히지 않는 임시값으로 구현하되 안정 ID,
formula revision과 `RequiresReview` 표식을 붙여 후속 기획 검토에서 교체한다.

### 장기 행동 계획과 수행 조건

- AI 행동 기간의 공통 허용 범위는 1개월~12만개월(1만년)이다. 현재 장기 권위 계획은
  수행에 먼저 적용하며 공법·법술·임무·제작·채굴·Teaching도 3~6개월 행동 묶음으로
  처리한다.
- 수행 계획을 시작할 때 기간, 고정 지역/장소, 여유·일반·폐관 강도, 영석·성장 단약
  소비 예산, 수행 진법 방식, 공동 수행 역할과 상대를 한 번에 동결한다. 기간이 끝나거나
  위치가 달라지고, 병목·돌파·안착 경계에 닿았을 때만 계획을 끝내고 다음 행동을 판단한다.
- 도시에는 기존 수행 진법이 있다고 임시 판정한다. 야외 직접 설치는 공법 이해 30.00
  이상이어야 시도할 수 있고, 지식과 설치 경험이 성공률을 높인다. 같은 장소의 관계인이
  충분한 지식을 가지면 외부 설치 도움을 받을 수 있다.
- 계획 자원은 실제 개인 재고와 영석에서 월별로 차감한다. 성장 단약을 우선 소비하고
  없으면 계획한 영석을 사용하며, 계획 예산을 넘겨 소비하지 않는다.
- 같은 장소에서 스승과 제자가 모두 수행 중일 때만 공동 수행으로 판정한다. 스승의
  수행 진척을 떼어 주지 않고, 제자는 스승의 수행 지식·경험과 자신의 받아들이는 자질로
  계산한 별도 진척 보너스를 얻는다. 가르치는 인물에게는 공동 수행 경험이 귀속된다.
- 성장은 월 단위 의미를 유지하되 목표·계획·인과·개인 로그를 매월 다시 만들지 않는다.
  여유/일반/폐관 수행은 각각 최대 6/12/24개월을 한 pulse로 계산하고, 수행 경계까지의
  월수만 일괄 적용한다. 같은 수행 로그는 매년 한 행의 지속 개월만 갱신한다.

기간 선택, 강도·진법·자원 계수, 설치 성공률과 공동 수행 보너스는 아직 승인 수치가
아니므로 각각 `PC-TEMP-CULT-ACTION-DURATION-019`,
`PC-TEMP-CULT-CONDITION-FACTOR-019`, `PC-TEMP-CULT-FORMATION-INSTALL-019`,
`PC-TEMP-CULT-JOINT-TEACHING-019` revision 1로 다음 기획 검토에 이관한다.

## 5. 자질

| 자질 | 수행에서의 역할 | 전투에서의 역할 |
|---|---|---|
| 영근 | 영기 흡수와 수행 진척 | 영력량과 영력 회복 |
| 근골 | 육체 단련과 동작 안정 | 물리 위력과 행동 회복 |
| 체질 | 장기 수행과 부상 회복 | 생명력과 피해 저항 |
| 오성 | 공법·법술 이해와 돌파 | 법술 운용과 대응 효율 |
| 정신 | 수행 통제와 정신 부담 | 신식·정밀 제어와 복합 행동 |
| 영혼 | 수행 잠재와 영구 변화 | 영혼 강도와 고경지 부담 대응 |

자질은 전투력에 직접 더하지 않는다. 각 자질은 명시된 파생 능력과 공법·법술·전투
성장 보정만 바꾸며, 경지로 이미 얻은 전투력을 다시 중복 증폭하지 않는다. Component
파생 역할값 0.00은 50%, 50.00은 100%, 100.00은 200%로 변환되고 이 범위를
벗어나지 않는다. 품질 등급의 큰 경계 배율은 이 보정률에 적용하지 않는다.

| 보정 대상 | 자질 가중치 | 범위 |
|---|---|---:|
| 공법 효과·수련 경험·이해 성장 | 근골 35%·체질 35%·정신 15%·영혼 15% | 50%~200% |
| 법술 효과·수련 경험·이해 성장 | 영근 40%·오성 35%·정신 15%·영혼 10% | 50%~200% |
| 전투 숙련 효과 | 근골 20%·오성 30%·정신 30%·영혼 20% | 50%~200% |
| 전투 이해 효과·성장 | 오성 45%·정신 35%·영혼 20% | 50%~200% |
| 전투 경험 획득 | 오성 25%·정신 35%·영혼 25%·체질 15% | 50%~200% |

위 표의 `영근·근골` 등은 대표값 자체가 아니라 아래 수행/전투 문맥 파생 능력을 뜻한다.
각 파생 능력은 핵심 Component 두 개를 각 30%, 보조 Component 두 개를 각 20%로
합산한다.

| 자질 | 파생 능력 | 핵심 30% + 30% | 보조 20% + 20% |
|---|---|---|---|
| 영근 | 영기 수행 기반 | 감응도 + 흡수 효율 | 체화 효율 + 통로 폭 |
| 영근 | 영력 전투 운용 | 통로 폭 + 안정성 | 내구성 + 순도 |
| 근골 | 육체 수행 효율 | 근육 성장성 + 경맥 유연성 | 골격 밀도 + 경맥 내구성 |
| 근골 | 육체 전투 기반 | 근육 출력 + 골격 강도 | 건인대 강도 + 관절 가동성 |
| 체질 | 체질 수행 수용 | 성장성 + 수용력 | 안정성 + 적응성 |
| 체질 | 체질 전투 내구 | 강도 + 안정성 | 완전성 + 적응성 |
| 오성 | 학습·이해 능력 | 이해력 + 분석력 | 기억력 + 집중력 |
| 오성 | 전투 판단 능력 | 분석력 + 관찰력 | 응용력 + 통찰력 |
| 정신 | 수행 통제 능력 | 수행 통제력 + 정밀 제어력 | 정신 안정성 + 정신 지속력 |
| 정신 | 전투 제어 능력 | 정밀 제어력 + 병렬 제어력 | 의지력 + 신식 감응력 |
| 영혼 | 영혼 성장 기반 | 영혼 성장성 + 자질 조화력 | 자질 각인력 + 영혼 공명력 |
| 영혼 | 영혼 전투 기반 | 영혼 강도 + 영혼 안정성 | 영혼 공명력 + 자질 발현력 |

### 세부 선천자질 Component 정본

각 영역은 정확히 10개의 0.00~100.00 선천 Component를 가진다. 대표값은 10개
산술평균이며 요약 UI·자질 랭킹·비교에만 사용한다.

| 영역 | 10개 Component |
|---|---|
| 영근 | 영근 크기, 통로 폭, 구조 밀도, 순도, 완전성, 내구성, 안정성, 감응도, 흡수 효율, 체화 효율 |
| 근골 | 골격 강도, 골격 밀도, 관절 안정성, 관절 가동성, 근육 출력, 근육 지구력, 근육 성장성, 건인대 강도, 경맥 내구성, 경맥 유연성 |
| 체질 | 체질 완전성, 체질 순도, 체질 안정성, 체질 강도, 체질 수용력, 체질 성장성, 체질 각성성, 체질 적응성, 체질 융합성, 체질 변성성 |
| 오성 | 기억력, 이해력, 분석력, 추론력, 연산력, 관찰력, 집중력, 응용력, 창의력, 통찰력 |
| 정신 | 의지력, 정신 안정성, 정신 지속력, 정신 회복력, 수행 통제력, 정밀 제어력, 병렬 제어력, 신식 발현력, 신식 확장력, 신식 감응력 |
| 영혼 | 영혼 강도, 영혼 안정성, 영혼 순도, 영혼 회복력, 영혼 수용력, 영혼 성장성, 영혼 공명력, 자질 각인력, 자질 조화력, 자질 발현력 |

초기 생성은 공통 기반값에서 Component별 제한 편차를 주되 중간값이 흔하고 극단값이
드물어야 한다. 현재 PC 임시 구현은 두 균등 난수 평균을 기반값으로 하고 각 Component에
±12.50 편차를 적용한다. 역할별 가중치, 분포·편차, 영근을 오행별로 다시 10개씩
분리할지는 각각 `PC-TEMP-TRAIT-ROLE-113`, `PC-TEMP-TRAIT-DIST-113`,
`PC-TEMP-SPIRIT-ROOT-113`으로 다음 버전 검토안에 남긴다. 세 값은 저장과 UI에서
`RequiresReview`로 식별한다.

자질 랭킹을 위한 종합지수는 여섯 대표값의 합으로만 계산한다. 이는 비교용 지표이며
개별 수행·전투 공식에서는 각 자질이 맡은 입력을 따로 사용한다. 윤회할 때 영혼 자질은
10개 Component 전체가 동일 영혼에 남고, 오성·근골·체질·영근·정신의 50개 Component는
새 육신 조건에서 다시 형성된다.

### 공통 품질 척도

자질·공법·법술은 모두 0.00~100.00의 같은 품질값과 다음 품질명을 쓴다. 경계를
0.01만 넘어도 범주 배율이 먼저 바뀌고, 같은 범주 안에서는 원래 품질값이 비교된다.

| 품질 | 값 범위 | 직전 경계 대비 효과 |
|---|---:|---:|
| 폐품 | 0.00~9.99 | 기준 |
| 극하품 | 10.00~29.99 | 약 5배 |
| 하품 | 30.00~39.99 | 약 2배 |
| 중품 | 40.00~59.99 | 약 1.5배 |
| 상품 | 60.00~79.99 | 약 1.5배 |
| 극상품 | 80.00~89.99 | 약 2배 |
| 천품 | 90.00~99.99 | 약 4배 |
| 무결품 | 100.00 | 약 10배 |

극하품→하품 문장에는 1.5배와 `29.99→30.00 약 2배`가 함께 제시되어 있으므로,
현재 정본은 더 구체적인 경계 수치인 약 2배를 적용한다. 배율은 정수 비율로 계산해
플랫폼에 따라 결과가 달라지는 부동소수점 연산을 권위 상태에 넣지 않는다.

## 6. 생애·일대기·윤회

- 모든 AI는 세계 0년에 0세로 태어나 제1생을 시작한다.
- 매 tick의 미세 변화는 기록하지 않고 탄생, 첫 병목 실패, 병목 돌파, 소경지 돌파,
  대경지 돌파, 대원만, 공법·법술 신규 획득, 기연, 수명/전투 사망,
  윤회의 강 진입·도하 완료와 환생만 일대기에 남긴다.
- 현재 나이가 현재 경지의 기본 최대 수명에 도달하면 육신이 사망한다.
- 영혼은 사망 당시 개인 최고 경지에 따른 정해진 전체 체류 기간 동안
  윤회의 강을 단계별로 건넌 뒤 제2생 이상의 새 인물로 태어난다.
- 새 생은 이름·육신 자질·경지·공법·법술·전투 경험을 새로 형성하지만 영혼 자질과
  모든 전생 일대기는 유지한다.
- 안정 `AgentId`는 영혼의 관찰 슬롯이다. `SoulId`는 생을 넘어 유지하고 `BodyId`와
  `PersonId`는 각 생마다 새로 발급해 전생과 현생의 Identity를 구분한다.

### 단계형 윤회 여정

| 사망 당시 개인 최고 경지 | 전체 윤회의 강 체류 기간 | 적용 상태 |
|---|---:|---|
| 연기경 | 3년 | Alpha 1.1.3 정본 |
| 축기경 | 5년 | Alpha 1.1.3 정본 |
| 금단경 | 8년 | Alpha 1.1.3 정본 |
| 원영경 | 13년 | Alpha 1.1.3 정본 |
| 화신경 | 21년 | Alpha 1.1.3 정본 |
| 연허경 | 34년 | PC 임시 확장 |
| 합체경 | 55년 | PC 임시 확장 |
| 도겁경 | 89년 | PC 임시 확장 |
| 대승경 | 144년 | PC 임시 확장 |
| 반선경 | 233년 | PC 임시 확장 |

상위 5경지 기간은 `PC-TEMP-REINCARNATION-UPPER-DURATION-113`으로 다음 버전에서
재검토한다. 여정은 사망 확정과 Soul/Body 인계 뒤 `진입 → 도하 →
후반 도하 → 도하 완료 → 새 생 준비`로 진행한다. 각 단계의 누적 종료 경계는
전체 기간의 1/12, 8/12, 10/12, 11/12, 12/12이다. 나누어떨어지지 않는 tick은
정수 경계로 흡수해 총기간을 정확히 보존한다. 이 단계 비율은
`PC-TEMP-REINCARNATION-STAGES-113`으로 재검토한다.

도하 완료는 새 BodyId·PersonId가 아직 발급되지 않은 중요 생사 경계이다.
새 생 준비가 끝난 뒤에만 환생을 확정하고, 기존 SoulId와 전생 계보를 유지하면서
새 BodyId·PersonId를 발급한다. 모바일 정본의 부모·환경·용량 조건을 가진 출생 후보
대기열은 PC판에 권위 가족/출생 모델이 없어 제외했다. PC 대체 규칙은
`PC-TEMP-REINCARNATION-BIRTH-CANDIDATE-113`으로 다음 버전 검토안에 이관한다.

### 생 계보와 전생 흔적

- 각 생은 안정 `LifeRecordId`와 직전 생 ID를 가지며 Soul/Body/Person ID, 생
  번호, 당시 이름, 탄생/사망 tick, 사망 원인, 개인 역사적 최고점과 `JourneyId`를
  추가 전용 계보로 영구 보존한다.
- 전생 흔적은 autobiographical memory(자서전적 기억), relationship/social
  memory(관계·사회 기억), cultivation principles/realm knowledge(수행 원리·경지
  지식), technique/spell/pill/crafting knowledge(공법·법술·단약·제작 지식),
  world/faction/environment knowledge(세계·세력·환경 지식), embodied/action
  trace(육신·행동 흔적)의 정확히 6개 영역이다.
- 각 영역은 0~10,000 고정소수점의 preserved, accessible, integrated를 따로
  보존한다. 보존 판정은 8,000 이상 온전, 5,500 이상 부분, 3,000 이상 파편,
  그 미만 소실이다. 접근 판정은 8,500 이상 즉시, 6,000 이상 부분,
  3,000 이상 잠재, 그 미만 봉인이다.
- 항상 `integrated ≤ accessible ≤ preserved`를 만족한다. 환생 직후 integrated는
  0이며, 전생 흔적 수치가 높아도 현생 경지·공법·법술·전투 경험·능력치를
  자동 복구하지 않는다. 통합은 향후 별도 권위 행동으로만 확장할 수 있다.
- 전생 실적에서 6영역 후보를 계산하는 세부 가중치는
  `PC-TEMP-REINCARNATION-TRACE-113`으로 다음 버전 검토안에 이관한다.
- schema 22 이하 저장에 전생 흔적 근거가 없다면 점수 0을 복원값으로 조작하지
  않는다. `HasEvidence=false`를 저장해 실제 0이나 실제 소실과 기록 부재를 구분한다.

### 인물 인과·관계·Teaching

- 모든 AI는 최종 목표 `랭킹 1위`와 현재 보조 목표를 가진다. 목표→현재 판단→선택 행동·
  차선 행동→선택 이유→typed Resolution을 revision이 있는 인과 trace로 저장해 관찰자가
  행동 이유와 결과를 확인할 수 있다.
- 관계는 10,000명 전체 쌍이 아니라 인물당 최대 8개의 인접 관계만 유지한다. 각 방향은
  호감/반감·신뢰/불신·존중/경시·은혜·원한·경계의 6개 축을 가진다. 역할 flag는
  사제·우정·연애·실제 동료·지속 경쟁이며 사제 방향은 별도 MasterAgent로 구분한다.
- 같은 지역의 기존 관계와 지식 격차에서 후보를 선택한 뒤 사제 관계를 성립시켜
  Teaching을 시작한다. 대상은 공법 또는 법술이며 정확한 `KnowledgeRef`와 전수 출처를
  기록한다.
- Teaching 결과는 학습·이해 진전, 오해 발생, 오해 교정, 전승 성립·갱신, 중단,
  거부로 나뉜다.
  대경지 수행 Work는 직접 올리지 않고 공법·법술 수련 경험, 이해도, 오해/교정과 지식
  접근만 바꾼다.
- 연속 전수는 `관계+대상 종류+KnowledgeRef`별로 집계한다. 다른 대상을 사이에
  가르치거나 새 서적을 얻어도 이전 연속성이 섞이지 않는다. 중요한 전수는 대상 Ref,
  출처와 당시 PersonId를 영구 이력으로 보존하고 당시 이름은 생애 연대기에서 복원한다.
- 전투 시작, 육신 사망, 윤회의 강 진입과 환생은 양쪽 진행 Teaching을 중단한다.
- 생애 경계에서는 현재 관계의 양방향 metrics·상호작용 횟수·대상별 Teaching 연속
  상태를 초기화하고, 과거 PersonId가 담긴 중요 관계 history만 유지한다.
- AI 효용 가중치, 관계 변화/역할 임계값, Teaching 확률·성장량은 각각
  `PC-TEMP-AI-UTILITY-113`, `PC-TEMP-RELATION-BALANCE-113`,
  `PC-TEMP-TEACHING-BALANCE-113` 임시값이며 다음 버전 검토안에서 확정한다.

### 로그와 연대기

- 전체 세계 로그에는 1위 교체, 대경지 돌파, 죽음·윤회·환생, 천품 이상 성취,
  최상위권 전투 결과처럼 세계적으로 중요한 사건만 표시한다.
- 세계 로그와 개인 최근 로그는 각각 최대 100줄을 유지한다.
- 세계 로그와 별도로 새로운 1위, 대경지 돌파·대원만, 상위권 입문·죽음과 천품 이상
  성취를 영구 보존하는 세계 연대기를 둔다. 사건 당시 이름을 함께 저장해 환생 후에도
  과거 기록의 인물명이 바뀌지 않는다.
- 개인 최근 로그에는 월 행동과 전투·거래·임무 등 해당 인물의 사건을 기록한다.
- 같은 장기 행동이 여러 달·여러 해 계속되면 새 줄을 매달 추가하지 않고 기존 줄의
  지속 개월과 `N년 차` 표시만 갱신한다.
- 연대기는 탄생·병목·소/대경지 돌파·기연·죽음·윤회·환생의 중요 기록이며
  100줄 제한을 적용하지 않는다. 모든 생의 연대기는 저장 파일에 영구 보존한다.
- 최근 로그는 전체·수행·전투·경제·이동·생애·죽음 내부 탭으로, 영구 연대기는
  사건 종류 내부 탭과 제1생·제2생 같은 생별 토글로 필터링한다. 깨달음은 이해도
  성장 사건이지만 영구 연대기에는 기록하지 않는다.
- 세계 기록 화면은 최근 세계 로그·세계 영구 연대기·세션 디버그를 내부 탭으로 나눈다.
  세계/디버그 로그는 각각 자동 또는 수동으로 로컬 UTF-8 파일에 출력할 수 있다.
- 세계 연대기는 개인별 사건을 모아 쓰지 않고 100년마다 한 권의 세계 역사서로
  압축한다. 각 권은 대경지별 돌파 횟수와 고유 인원, 전투력·경지·자질·부자
  TOP 1·3·5·10 자리 교체와 현재 1위, 사망·윤회의 강 진입·환생 횟수와 고유 인원,
  윤회의 강 잔류 인원, 전투·요수 사냥·임무·채굴·제작 합계를 기록한다.
- 세계 로그는 전체·경쟁·전투·수행·경제·생사·윤회로, 세계 역사서는 전체 역사·수행사·
  경쟁사·생사·윤회사로 내부 탭을 나눠 선택한 종류만 관찰한다. 파일 출력은 모든 종류의
  권위 기록을 포함한다.

## 7. 전투력

전투력은 다음 여섯 행으로 UI에 분해해 공개하되, 자질 행은 직접 합산값이 아닌 간접
보정임을 명시한다.

1. **경지 전투력**: 대경지와 층계가 만드는 기본 격차
2. **자질 간접 보정**: 직접 전투력 0, 역할별 50%~200% 효과만 표시
3. **공법 전투력**: 공법 품질·숙련·이해와 자질 보정으로 얻는 기반 강화
4. **법술 전투력**: 법술 품질·숙련·이해와 자질 보정
5. **전투 성장 전투력**: 전투 경험·숙련·이해의 제한된 합산 기여
6. **법보 전투력**: 본명법보·공격 법보·방어 법보의 품질과 장착 효과

표시 전투력은 비교와 랭킹을 위한 예측치이며 승리를 보장하지 않는다. 현재 생명력,
영력, 부상과 행동 선택 때문에 낮은 전투력의 AI도 이길 수 있다. 전투 경험에는
체감 수익을 적용해 오래 산 승자가 무한히 독주하지 않게 한다. 전투 숙련도는 누적
전투 경험의 제곱근 곡선에서 0.00~100.00으로 파생하고, 전투 이해도는 별도
0.00~100.00 권위 상태로 전투·사냥 결과에서 성장한다.

### 공법·법술 성장

- 공법과 법술은 불변 품질, 누적 수련 경험, 0.00~100.00 숙련도, 0.00~100.00
  이해도를 각각 가진다.
- 반복 수련은 경험과 숙련도를 높인다. 숙련도는 누적 경험의 제곱근 곡선을 사용해
  수치가 높을수록 같은 0.01을 올리는 데 더 많은 경험이 필요하다.
- 공법/법술 수련 경험과 깨달음 이해 증가량은 각 역할 자질 보정률 50%~200%를
  적용한다. 자질은 공법/법술의 불변 품질을 바꾸지 않는다.
- 깨달음은 이해도만 높인다. 기존 공법/법술 품질을 올리지 않으며, 더 높은 품질은
  새 공법서/법술서를 얻어 기술 자체를 교체해야 한다.
- 공법은 최대 생명력·최대 영력·기반 방어를, 법술은 공격/방어·속도·관통·치명타·
  회피를 중심으로 높인다. 품질·숙련·이해가 실제 파생 속성과 표시 전투력에 모두
  들어가지만 두 계산식은 동일하지 않다.

## 8. 경쟁 활성화 규칙

- AI는 랭킹과 각 전투력 구성 요소를 비교해 가장 부족한 성장 행동을 선택한다.
- 도전자는 기본적으로 같은 지역에 있는 자신보다 높은 순위 중 승산이 있는 상대를 찾는다.
- 오랫동안 전투하지 않은 건강한 AI는 도전 욕구가 높아진다.
- 1위와 최상위권은 도전 대상으로 노출되는 빈도가 높다.
- 패배해도 전투 경험을 얻지만, 승리보다 적다.
- 부상, 영력 고갈과 연속 전투 제약으로 같은 인물의 무한 전투를 막는다.
- 반복 대전에는 일시적 기피를 적용해 상대 다양성을 유지한다.

## 9. 도시 임무·경제·법보·단약

초기 경제는 하나의 공용 도시와 도시가 중개하는 공동 시장을 중심으로 작동한다. AI는
도시가 실제로 부족한 법보 재료나 단약 재료가 있을 때만 해당 재료 조달 임무를
선택적으로 수주한다. 납품한 재료는 공동 시장 재고에 들어가며, 플레이어는 거래나
임무·생산 결과를 관찰만 한다.

- 재료는 법보 재료와 단약 재료 2종으로 간략화한다. 완제품은 성장 단약·돌파 단약·
  방어 법보·공격 법보이며 각 10개 대경지마다 별도 상품이다. 더 높은 대경지에
  진입하면 해당 대경지용 완제품을 새로 구매해야 한다.
- 법보는 본명법보·방어 법보·공격 법보의 총 3개 독립 슬롯에 하나씩 장착한다.
  본명법보는 시장 완제품이 아니며 본인이 법보 재료와 영석을 사용해 직접 만든다.
  소유자와 동기화되어 대경지 돌파 시 본명법보의 대경지 등급도 함께 올라간다.
- 방어/공격 법보와 공법서·법술서는 품질을 가진다. 새 세계의 공법·법술 품질은
  0.00~79.99 범위에서 시작한다. 79.99→80.00 가격은 두 배이며, 80.00 이상은
  품질이 1.00 높아질 때마다 가격이 다시 두 배가 된다.
- 성장 단약은 수행 진척을 늘리고 돌파 단약은 병목 돌파를 돕는다. 수선자가 직접
  단약 완제품을 제작하지 않으며 현재 대경지에 맞는 도시 상품을 구매한다.
- 한 수선자가 시장에 판 재료·법보·공법서·법술서는 공동 재고에 쌓여 다른 수선자가
  살 수 있다.
  각 상품은 도시 기준가, 현재 재고, 최근 12개월 공급·수요와 감사용 누적 공급·수요를
  가진다. 최초에는 기준가로 시작하고 첫 실수급 뒤 최근 공급 증가는 가격을 낮추며
  구매·가공 소비에 의한 최근 수요 증가는 가격을 높인다. 구매력이 없는 시도는 수요가
  아니고, 구매력이 있으나 실물 재고가 부족한 경우만 미충족 수요로 기록한다. 현재가는 도시 기준가의
  25%~400% 범위에서 정수 계산으로 결정하고, 품질 상품은 그 위에 품질 가격을
  적용한다. 도시 매입가는 판매가의 80%로 두어 무한 차익을 막는다.
- 구매·판매·임무 납품은 `Offer → 재고/자금/품질/용량 preflight → 도시·수선자 자산
  이전 → SourceResultId와 거래 원장 기록` 순서의 원자 정산이다. 성공 정산과 재고
  부족 수요 기록만 source를 소비하며, 상태가 바뀌지 않은 실패는 조건 해결 뒤 같은
  source로 재시도할 수 있다. 최근 실물 거래 100건은 sequence·source·시각·인물·종류·
  상품·수량·단가·총액·품질을 보존한다.
- 도시는 미충족 수요가 있고 재료·영석이 모두 있을 때만 생산 대기열을 시작한다.
  법보/단약은 해당 재료와 영석, 공법서/법술서는 영석만 소비한다. 생산 시작 시 자원을
  예약하고 3개월 뒤 공급하며 진행 중 품목·기간·투입 자원을 도시 UI에서 관찰한다.
  가장 큰 수요 상품의 재료가 없어도 생산 가능한 다음 상품을 찾아 대기열 정체를 막는다.
- 영석은 도시의 유한 광맥에서만 새로 생산된다. 도시 금고나 생산 자금이 부족할 때
  채굴 인력 임무가 열리고 수선자가 지원해 광석을 채굴하며 일부를 보상으로 받는다.
- 경제 상태는 개인 영석·임무·재료 2칸·대경지별 단약·장착 법보 3칸뿐 아니라 도시
  금고·유한 광맥, 44개 시장 상품의 재고·품질 합계·현재가·공급·수요와 최대 4개
  생산 대기열을 명시적으로 저장한다.
  도시의 구매·판매 거래 수, 임무 납품, 가공 재료, 단약·법보·공법서·법술서 생산,
  최근 12개월 수급 bucket·인물별 source watermark·최근 거래 원장
  및 채굴 누계도 저장해 도시 상세 화면에서 확인할 수 있다.

### 세계 지도·요수

초기 지도는 3×3 고정 좌표다. 중앙 만상성, 숲 3곳, 평야 2곳, 산맥 3곳으로
구성한다. 각 야외 지형에는 그 지형에 속한 요수 3종이 있고 서로 다른 위험도와
전리품 재료를 가진다.

- 수선자는 현재 위치와 이동 목적지를 가지며 이동 거리는 맨해튼 좌표 거리로 계산한다.
- 도시에서는 수행·도전·임무·시장·제작을 선택하고, 일정 확률로 야외 탐색을 떠난다.
- 야외에서는 지형 요수를 사냥하거나 다른 지역/도시로 이동한다.
- 요수 사냥은 실제 전투 속성으로 승산을 계산하고, 승리 시 전투 경험과 재료를 얻는다.
  패배하면 생명력과 누적 부상을 잃고 치명상일 경우 사망·윤회한다.
- 각 야외 칸은 요수 개체수를 권위 상태로 가지며 사냥 승리 시 감소하고 매월 한도까지
  재생한다. 지도 칸을 클릭하면 지형·위험도·요수 종별 개체수와 현재 수선자 목록을
  확인하고 그 수선자를 곧바로 선택할 수 있다.
- 지도별 인구, 서식 요수, 세계/개인 사냥 누계는 관찰 DTO로 제공하며 조회는 AI 행동과
  난수에 영향을 주지 않는다. 선택한 지도 칸만 상세 인물 목록을 만든다.

## 10. 랭킹·전체 탐색·수치 표기

- 공식 랭킹은 전투력·경지·자질·보유 영석(부자 순위)의 네 범주이며 각각 1위부터
  1,000위까지 공개한다.
- 경지 랭킹은 대경지, 소경지, 현재 수행 진척 순으로 비교한다.
- 자질 랭킹은 여섯 수행자질 대표값의 합을 비교 지표로 사용한다.
- 부자 순위는 현재 개인 보유 영석을 비교하고 동률은 안정 Agent ID로 결정한다.
- 공식 랭킹에 들지 않은 수선자도 전체 탐색에서 안정 ID 순으로 모두 찾아볼 수 있으며,
  이름이나 `A00001` 형식의 ID로 검색할 수 있다.
- 1만 이상의 큰 표시 수치는 만·억·조·경 단위로 축약하고 필요한 경우 소수 둘째
  자리까지 보여 준다. 저장값과 공식 계산에는 축약 문자열을 사용하지 않는다.
- 전체 통계는 미입문과 10개 대경지별 인원, 고정 전투력 구간별 인원과 비율,
  사망·승리·패배·윤회·임무·영석 누계를 제공한다.
- 전투력 랭킹 변동률은 직전 공식 갱신과 비교해 순위가 달라진 인원 비율이다. 같은 표에
  상승·하락·유지 인원과 변동 인원의 평균 절대 이동 순위를 함께 표시한다.
- 상위 1위·3위·5위·10위·100위·500위·1,000위의 전투력·경지·부자 순위는
  1년·10년·100년·1,000년·1만년·전체 기준점과 현재 위치가 다른 자리 수와 비율을
  표시한다. 비교 기간이 세계 나이보다 길면 실제 존재하는 가장 오래된 기준점을 쓴다.
- 우측 관찰 영역은 세계 통계, 도시 상세, 44개 상품 시장, 지도, 세계 기록 탭으로
  분리하고 3×3 지도 탭을 함께 제공한다. 인물 상세에는 수행 상태·행동 일정·위치·
  재료별 수량·실전 전투 속성·전투력 분해·입력별 상세 공식과 개인 로그/영구 연대기
  전용 `윤회 연속성` 내부 탭을 둔다. Soul/Body/Person 신원과 목표·판단 이유는
  기본/접힌 상세로 나누고,
  희소 관계와 `사제·가르침·전승 추적`은 각각 독립 Expander로 지연 관찰한다.
- 통계 분포는 필요할 때 펼친다. 시장은 분류 토글·검색과 상품 개요/가격·수급/도시
  생산/최근 거래 내부 탭, 지도는 선택 지역의 지역 개요/요수 생태/수선자 내부 탭으로 제공한다.
  수선자 목록은 100명씩 이동하며 현재 선택하지 않은 외부·내부 탭과 접힌 통계는 관찰
  결과에 영향을 주지 않을 뿐 아니라 조회 집계·UI 행·숨은 문구 갱신도 수행하지 않는다.

## 11. 실시간 전투

전투는 한 번의 승률 추첨이 아니라 단일 턴 소유자를 갖는 교대 행동 타임라인으로
진행한다. 각 참가자는 공격, 법술, 방어 또는 이탈을 선택하고 상대에게 턴을 넘긴다.
실제 피해는 공격·방어·명중/회피·관통/관통방어·치명타/치명타방어·영력과 방어 태세로
계산하며 표시 전투력 비율을 직접 피해식에 쓰지 않는다.

연기/축기경의 한 행동은 약 1개월, 이후 경지의 임시 기준은 3개월·1년·3년·10년·
50년·200년·1,000년·5,000년으로 길어진다. 최대 행동 수로 전투를 강제 종료하지 않아
상위 경지 교전은 수십 년부터 수천 년까지 이어질 수 있다.
다음 전투 행동은 양쪽 참가자의 남은 수명 경계보다 늦게 예약하지 않으므로 장기 전투가
자연사 판정을 건너뛰게 만들지 않는다.

피해는 0.00~100.00 누적 부상으로도 환산한다. 경상·중등상·중상·치명상·사망상으로
구분하며 중상부터 사망 확률이 생긴다. 전투 사망은 영구 연대기와 전체 사망 통계에
포함되고 윤회로 이어진다.

관찰되지 않는 전투도 같은 공식과 사건 순서로 계산한다. UI를 열거나 닫는 행동이
전투 정밀도나 결과를 바꾸지 않는다.

## 13. 릴리스 완료 조건

- 기본 세계에 정확히 10,000명의 AI가 생성된다.
- 모든 AI가 목표 순위 1위를 보유하고 실제 성장·도전 행동을 수행한다.
- 전투력 여섯 구성 요소의 합과 랭킹 정렬이 일치한다.
- 장시간 진행 시 도전자와 순위 변동이 지속해서 발생한다.
- 모든 재료 범주가 임무·판매·제작 순환에 참여하고 법보·단약 효과가 실제 계산에 반영된다.
- 동일 seed 재실행 결과가 동일하다.
- 저장 후 복원해도 랭킹, 진행 중 행동과 다음 사건이 보존된다.
- Soul/Body/Person 신원, 관계와 활성 Teaching을 저장 왕복해도 인과·방향·진행 상태가
  유지되고 일반 Teaching의 직접 수행 Work 증가는 0이다.
- Windows x64 Release 패키지가 새 PC에서 실행된다.
