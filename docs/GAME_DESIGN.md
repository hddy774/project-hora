# 게임 디자인 정본 0.1

## 1. 한 문장 정의

플레이어가 개입하지 않는 가운데 10,000명의 AI 수선자가 수행과 전투를 반복하며
전투력 랭킹 1위를 다투는 실시간 관찰 게임이다.

## 2. 플레이어 계약

플레이어는 세계에 능력치, 보상, 명령을 주지 않는다. 가능한 조작은 일시정지,
배속, 검색, 정렬, 인물 추적과 관찰 화면 이동뿐이다. 관찰 여부는 AI 판단,
전투 결과, 공식 통계와 난수 소비에 영향을 주지 않는다.

## 3. 핵심 순환

```text
현재 순위와 약점 평가
        ↓
수행·공법 숙련·법술 연마 또는 상위 상대 도전
        ↓
경지 돌파 / 실시간 전투
        ↓
경험·부상·숙련·전투력·랭킹 갱신
        ↓
1위와의 격차를 다시 평가
```

모든 AI의 최종 목표 순위는 1위다. 다만 현재 상태가 불리하면 회복하거나 성장한 뒤
도전한다. 상위권은 자주 도전받고, 중하위권은 자기보다 조금 높은 상대를 우선 선택해
전 인구에서 경쟁이 이어지게 한다.

## 4. 시간과 경지

- 1배속에서 현실 10초가 게임 시간 1년이다. 권위 시간은 `2,000 tick = 1년`이다.
- 지원 배속은 1×, 10×, 25×, 50×, 100×다.
- 소경지는 초기·중기·후기·대원만으로 표현하고 각 전환에 병목 판정을 둔다.

| 대경지 | 기본 최대 수명 | 기준 수행 기간 |
|---|---:|---:|
| 연기경 | 150년 | 50년 |
| 축기경 | 300년 | 100년 |
| 금단경 | 600년 | 200년 |
| 원영경 | 1,200년 | 400년 |
| 화신경 | 3,000년 | 1,000년 |
| 연허경 | 9,000년 | 3,000년 |
| 합체경 | 2만 년 | 6,666.67년 |
| 도겁경 | 10만 년 | 33,333.33년 |
| 대승경 | 10만 년(별도 수명 미확정으로 유지) | 33,333.33년 |
| 반선경 | 100만 년 | 333,333.33년 |

모든 대경지의 기준 수행 기간은 해당 경지 기본 최대 수명의 정확히 3분의 1이다. 권위
계산은 년 단위 소수값을 별도 저장하지 않고 4개 소경지 요구량을 tick으로 변환한 뒤 가장
가까운 정수 tick으로 반올림한다.

## 5. 자질

| 자질 | 수행에서의 역할 | 전투에서의 역할 |
|---|---|---|
| 영근 | 영기 흡수와 수행 진척 | 영력량과 영력 회복 |
| 근골 | 육체 단련과 동작 안정 | 물리 위력과 행동 회복 |
| 체질 | 장기 수행과 부상 회복 | 생명력과 피해 저항 |
| 오성 | 공법·법술 이해와 돌파 | 법술 운용과 대응 효율 |

자질은 모든 결과에 같은 백분율을 더하지 않는다. 각 자질은 명시된 파생 능력만
바꾸며, 경지로 이미 얻은 전투력을 다시 중복 증폭하지 않는다.

## 6. 전투력

전투력은 다음 다섯 구성 요소의 합으로 계산하고 UI에서 항상 분해해 공개한다.

1. **경지 전투력**: 대경지와 층계가 만드는 기본 격차
2. **자질 전투력**: 영근·근골·체질·오성의 전투 파생 능력
3. **공법 전투력**: 공법 품계와 숙련으로 얻는 기반 강화
4. **법술 전투력**: 장착 법술의 위력·숙련·상호 보완
5. **전투 경험 전투력**: 실제 교전과 승패에서 얻는 판단·대응 숙련

표시 전투력은 비교와 랭킹을 위한 예측치이며 승리를 보장하지 않는다. 현재 생명력,
영력, 부상과 행동 선택 때문에 낮은 전투력의 AI도 이길 수 있다. 전투 경험에는
체감 수익을 적용해 오래 산 승자가 무한히 독주하지 않게 한다.

## 7. 경쟁 활성화 규칙

- AI는 랭킹과 각 전투력 구성 요소를 비교해 가장 부족한 성장 행동을 선택한다.
- 도전자는 기본적으로 자신보다 높은 순위 중 승산이 있는 상대를 찾는다.
- 오랫동안 전투하지 않은 건강한 AI는 도전 욕구가 높아진다.
- 1위와 최상위권은 도전 대상으로 노출되는 빈도가 높다.
- 패배해도 전투 경험을 얻지만, 승리보다 적다.
- 부상, 영력 고갈과 연속 전투 제약으로 같은 인물의 무한 전투를 막는다.
- 반복 대전에는 일시적 기피를 적용해 상대 다양성을 유지한다.

## 8. 실시간 전투

전투는 한 번의 승률 추첨이 아니라 행동 타임라인으로 진행한다. 각 참가자는 공격,
법술, 방어, 회복 또는 이탈 중 다음 행동을 선택하며 행동마다 준비 시간과 회복 시간이
있다. 관찰 화면은 선택 이유, 목표, 예상 피해, 실제 결과와 다음 행동 시점을 보여준다.

관찰되지 않는 전투도 같은 공식과 사건 순서로 계산한다. UI를 열거나 닫는 행동이
전투 정밀도나 결과를 바꾸지 않는다.

## 9. 첫 릴리스 범위

포함:

- 연기경부터 반선경까지 10대경지와 초기·중기·후기·대원만
- 네 자질, 공법, 법술, 전투 경험, 부상과 회복
- 자율 수행·돌파·도전·전투·이탈 판단
- 전투력 랭킹, 순위 변동, 인물 상세와 세계 사건 기록
- 저장·불러오기, 일시정지와 배속

제외:

- 문파, 관계망, 경제, 제작, 인벤토리, 퀘스트, 플레이어 개입
- 대규모 지도 이동, 외교, 윤회와 혈통
- 네트워크 멀티플레이와 서버 권위

## 10. 릴리스 완료 조건

- 기본 세계에 정확히 10,000명의 AI가 생성된다.
- 모든 AI가 목표 순위 1위를 보유하고 실제 성장·도전 행동을 수행한다.
- 전투력 다섯 구성 요소의 합과 랭킹 정렬이 일치한다.
- 장시간 진행 시 도전자와 순위 변동이 지속해서 발생한다.
- 동일 seed 재실행 결과가 동일하다.
- 저장 후 복원해도 랭킹, 진행 중 행동과 다음 사건이 보존된다.
- Windows x64 Release 패키지가 새 PC에서 실행된다.
