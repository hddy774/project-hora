# 게임 디자인 정본 0.1

## 1. 한 문장 정의

플레이어가 개입하지 않는 가운데 10,000명의 AI 수선자가 수행과 전투를 반복하며
전투력 랭킹 1위를 다투는 실시간 관찰 게임이다.

## 2. 플레이어 계약

플레이어는 세계에 능력치, 보상, 명령을 주지 않는다. 가능한 조작은 일시정지,
배속, 검색, 정렬, 인물 추적과 관찰 화면 이동뿐이다. 관찰 여부는 AI 판단,
전투 결과, 공식 통계와 난수 소비에 영향을 주지 않는다.

## 3. 핵심 순환

```text
현재 순위와 약점 평가
        ↓
수행·공법 숙련·법술 연마 또는 상위 상대 도전
        ↓
경지 돌파 / 실시간 전투
        ↓
경험·부상·숙련·전투력·랭킹 갱신
        ↓
1위와의 격차를 다시 평가
```

모든 AI의 최종 목표 순위는 1위다. 다만 현재 상태가 불리하면 회복하거나 성장한 뒤
도전한다. 상위권은 자주 도전받고, 중하위권은 자기보다 조금 높은 상대를 우선 선택해
전 인구에서 경쟁이 이어지게 한다.

## 4. 시간과 경지

- 1배속에서 현실 10초가 게임 시간 1년이다. 권위 시간은 `2,000 tick = 1년`이다.
- 지원 배속은 1×, 10×, 25×, 50×, 100×다.
- 소경지는 초기·중기·후기·대원만으로 표현하고 각 전환에 병목 판정을 둔다.

| 대경지 | 기본 최대 수명 | 기준 수행 기간 |
|---|---:|---:|
| 연기경 | 150년 | 50년 |
| 축기경 | 300년 | 100년 |
| 금단경 | 600년 | 200년 |
| 원영경 | 1,200년 | 400년 |
| 화신경 | 3,000년 | 1,000년 |
| 연허경 | 9,000년 | 3,000년 |
| 합체경 | 2만 년 | 6,666.67년 |
| 도겁경 | 10만 년 | 33,333.33년 |
| 대승경 | 10만 년(별도 수명 미확정으로 유지) | 33,333.33년 |
| 반선경 | 100만 년 | 333,333.33년 |

모든 대경지의 기준 수행 기간은 해당 경지 기본 최대 수명의 정확히 3분의 1이다. 권위
계산은 년 단위 소수값을 별도 저장하지 않고 4개 소경지 요구량을 tick으로 변환한 뒤 가장
가까운 정수 tick으로 반올림한다.

## 5. 자질

| 자질 | 수행에서의 역할 | 전투에서의 역할 |
|---|---|---|
| 영근 | 영기 흡수와 수행 진척 | 영력량과 영력 회복 |
| 근골 | 육체 단련과 동작 안정 | 물리 위력과 행동 회복 |
| 체질 | 장기 수행과 부상 회복 | 생명력과 피해 저항 |
| 오성 | 공법·법술 이해와 돌파 | 법술 운용과 대응 효율 |
| 정신 | 수행 통제와 정신 부담 | 신식·정밀 제어와 복합 행동 |
| 영혼 | 수행 잠재와 영구 변화 | 영혼 강도와 고경지 부담 대응 |

자질은 모든 결과에 같은 백분율을 더하지 않는다. 각 자질은 명시된 파생 능력만
바꾸며, 경지로 이미 얻은 전투력을 다시 중복 증폭하지 않는다.

자질 랭킹을 위한 종합지수는 여섯 대표값의 합으로만 계산한다. 이는 비교용 지표이며
개별 수행·전투 공식에서는 각 자질이 맡은 입력을 따로 사용한다. 윤회할 때 영혼 자질은
동일 영혼에 남고, 오성·근골·체질·영근·정신은 새 육신 조건에서 다시 형성된다.

### 공통 품질 척도

자질·공법·법술은 모두 0.00~100.00의 같은 품질값과 다음 품질명을 쓴다. 경계를
0.01만 넘어도 범주 배율이 먼저 바뀌고, 같은 범주 안에서는 원래 품질값이 비교된다.

| 품질 | 값 범위 | 직전 경계 대비 효과 |
|---|---:|---:|
| 폐품 | 0.00~9.99 | 기준 |
| 극하품 | 10.00~29.99 | 약 5배 |
| 하품 | 30.00~39.99 | 약 2배 |
| 중품 | 40.00~59.99 | 약 1.5배 |
| 상품 | 60.00~79.99 | 약 1.5배 |
| 극상품 | 80.00~89.99 | 약 2배 |
| 천품 | 90.00~99.99 | 약 4배 |
| 무결품 | 100.00 | 약 10배 |

극하품→하품 문장에는 1.5배와 `29.99→30.00 약 2배`가 함께 제시되어 있으므로,
현재 정본은 더 구체적인 경계 수치인 약 2배를 적용한다. 배율은 정수 비율로 계산해
플랫폼에 따라 결과가 달라지는 부동소수점 연산을 권위 상태에 넣지 않는다.

## 6. 생애·일대기·윤회

- 모든 AI는 세계 0년에 0세로 태어나 제1생을 시작한다.
- 매 tick의 미세 변화는 기록하지 않고 탄생, 첫 병목 실패, 병목 돌파, 소경지 돌파,
  대경지 돌파, 공법·법술 깨달음, 기연, 사망, 윤회의 강 진입과 환생만 일대기에 남긴다.
- 현재 나이가 현재 경지의 기본 최대 수명에 도달하면 육신이 사망한다.
- 영혼은 1게임년 동안 윤회의 강 상태에 머문 뒤 제2생 이상의 새 인물로 태어난다.
- 새 생은 이름·육신 자질·경지·공법·법술·전투 경험을 새로 형성하지만 영혼 자질과
  모든 전생 일대기는 유지한다.
- 안정 `AgentId`는 영혼의 관찰 슬롯이며 각 생의 이름과 생 번호로 Person Identity를
  구분한다.

## 7. 전투력

전투력은 다음 다섯 구성 요소의 합으로 계산하고 UI에서 항상 분해해 공개한다.

1. **경지 전투력**: 대경지와 층계가 만드는 기본 격차
2. **자질 전투력**: 영근·근골·체질·오성의 전투 파생 능력
3. **공법 전투력**: 공법 품질과 숙련으로 얻는 기반 강화
4. **법술 전투력**: 법술 품질·숙련·상호 보완
5. **전투 경험 전투력**: 실제 교전과 승패에서 얻는 판단·대응 숙련

표시 전투력은 비교와 랭킹을 위한 예측치이며 승리를 보장하지 않는다. 현재 생명력,
영력, 부상과 행동 선택 때문에 낮은 전투력의 AI도 이길 수 있다. 전투 경험에는
체감 수익을 적용해 오래 산 승자가 무한히 독주하지 않게 한다.

## 8. 경쟁 활성화 규칙

- AI는 랭킹과 각 전투력 구성 요소를 비교해 가장 부족한 성장 행동을 선택한다.
- 도전자는 기본적으로 자신보다 높은 순위 중 승산이 있는 상대를 찾는다.
- 오랫동안 전투하지 않은 건강한 AI는 도전 욕구가 높아진다.
- 1위와 최상위권은 도전 대상으로 노출되는 빈도가 높다.
- 패배해도 전투 경험을 얻지만, 승리보다 적다.
- 부상, 영력 고갈과 연속 전투 제약으로 같은 인물의 무한 전투를 막는다.
- 반복 대전에는 일시적 기피를 적용해 상대 다양성을 유지한다.

## 9. 도시 임무·경제·법보·단약

초기 경제는 하나의 공용 도시를 중심으로 작동한다. AI는 도시에서 30종 재료 중 하나를
요구하는 임무를 받고 2개를 모아 납품한다. 임무 보상으로 영석을 얻고, 남는 재료는
상점에 판매하거나 제작에 쓴다. 플레이어는 거래나 임무 결과를 관찰만 한다.

- 법보 재료 10종, 단약 재료 10종, 기타 재료 10종을 안정 `MaterialId`로 정의한다.
- 모든 재료는 임무 대상이 될 수 있고 상점 판매가 가능하다. 초기 판매가는 법보 12,
  단약 8, 기타 4영석이며 정의표에서 독립적으로 조정할 수 있다.
- 법보는 본명법보 1칸, 방어구 I~III, 무기 I~III의 총 7개 독립 슬롯에 한 개씩
  장착한다. 품질은 공통 8단계 척도를 쓰며 전투력과 실제 공격·방어에 반영한다.
- 법보 제작은 법보 재료 2개, 단약 제작은 단약 재료 2개를 소비한다.
- 수행단은 수행 진척을 늘리고 돌파단은 병목 돌파 확률을 높인다. 도시 가격은 각각
  50영석과 100영석이며 AI가 필요에 따라 구매하거나 제작한다.
- 경제 상태는 영석, 임무, 재료 30칸, 단약, 장착 법보 7칸을 명시적으로 저장한다.
  이후 도시·상점·제작법을 추가해도 재료 ID와 장착 슬롯의 의미는 바뀌지 않는다.

## 10. 랭킹·전체 탐색·수치 표기

- 공식 랭킹은 전투력·경지·자질의 세 범주이며 각각 1위부터 1,000위까지 공개한다.
- 경지 랭킹은 대경지, 소경지, 현재 수행 진척 순으로 비교한다.
- 자질 랭킹은 여섯 수행자질 대표값의 합을 비교 지표로 사용한다.
- 공식 랭킹에 들지 않은 수선자도 전체 탐색에서 안정 ID 순으로 모두 찾아볼 수 있으며,
  이름이나 `A00001` 형식의 ID로 검색할 수 있다.
- 1만 이상의 큰 표시 수치는 만·억·조·경 단위로 축약하고 필요한 경우 소수 둘째
  자리까지 보여 준다. 저장값과 공식 계산에는 축약 문자열을 사용하지 않는다.
- 전체 통계는 10개 대경지별 인원, 고정 전투력 구간별 인원과 비율, 사망·승리·패배·
  윤회·임무·영석 누계를 제공한다.
- 전투력 랭킹 변동률은 직전 공식 갱신과 비교해 순위가 달라진 인원 비율이다. 같은 표에
  상승·하락·유지 인원과 변동 인원의 평균 절대 이동 순위를 함께 표시한다.

## 11. 실시간 전투

전투는 한 번의 승률 추첨이 아니라 행동 타임라인으로 진행한다. 각 참가자는 공격,
법술, 방어, 회복 또는 이탈 중 다음 행동을 선택하며 행동마다 준비 시간과 회복 시간이
있다. 관찰 화면은 선택 이유, 목표, 예상 피해, 실제 결과와 다음 행동 시점을 보여준다.

관찰되지 않는 전투도 같은 공식과 사건 순서로 계산한다. UI를 열거나 닫는 행동이
전투 정밀도나 결과를 바꾸지 않는다.

## 12. 첫 릴리스 범위

포함:

- 연기경부터 반선경까지 10대경지와 초기·중기·후기·대원만
- 여섯 수행자질, 공법, 법술, 전투 경험, 부상과 회복
- 자율 수행·돌파·도전·전투·이탈 판단
- 도시 임무, 영석, 30종 재료, 재료 판매, 법보·단약 제작과 단약 구매·사용
- 본명법보 1칸·방어구 3칸·무기 3칸과 법보 전투력
- 전투력·경지·자질 랭킹, 전체 인물 탐색, 인물 상세와 생애 일대기
- 수명 판정, 사망, 윤회의 강과 영혼 연속 환생
- 저장·불러오기, 일시정지와 배속

제외:

- 문파, 관계망, 플레이어 개입
- 복수 도시, 가격 변동 시장, 경매장, 전문 제작 직업
- 대규모 지도 이동, 외교와 혈통
- 네트워크 멀티플레이와 서버 권위

## 13. 릴리스 완료 조건

- 기본 세계에 정확히 10,000명의 AI가 생성된다.
- 모든 AI가 목표 순위 1위를 보유하고 실제 성장·도전 행동을 수행한다.
- 전투력 다섯 구성 요소의 합과 랭킹 정렬이 일치한다.
- 장시간 진행 시 도전자와 순위 변동이 지속해서 발생한다.
- 모든 재료 범주가 임무·판매·제작 순환에 참여하고 법보·단약 효과가 실제 계산에 반영된다.
- 동일 seed 재실행 결과가 동일하다.
- 저장 후 복원해도 랭킹, 진행 중 행동과 다음 사건이 보존된다.
- Windows x64 Release 패키지가 새 PC에서 실행된다.
