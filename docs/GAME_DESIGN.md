# 게임 디자인 정본 0.1

## 1. 한 문장 정의

플레이어가 개입하지 않는 가운데 10,000명의 AI 수선자가 수행과 전투를 반복하며
전투력 랭킹 1위를 다투는 실시간 관찰 게임이다.

## 2. 플레이어 계약

플레이어는 세계에 능력치, 보상, 명령을 주지 않는다. 가능한 조작은 일시정지,
배속, 검색, 정렬, 인물 추적과 관찰 화면 이동뿐이다. 관찰 여부는 AI 판단,
전투 결과, 공식 통계와 난수 소비에 영향을 주지 않는다.

## 3. 핵심 순환

```text
현재 순위와 약점 평가
        ↓
수행·공법 숙련·법술 연마 또는 상위 상대 도전
        ↓
경지 돌파 / 실시간 전투
        ↓
경험·부상·숙련·전투력·랭킹 갱신
        ↓
1위와의 격차를 다시 평가
```

모든 AI의 최종 목표 순위는 1위다. 다만 현재 상태가 불리하면 회복하거나 성장한 뒤
도전한다. 상위권은 자주 도전받고, 중하위권은 자기보다 조금 높은 상대를 우선 선택해
전 인구에서 경쟁이 이어지게 한다.

## 4. 시간과 경지

- 1배속에서 현실 10초가 게임 시간 1년이다. 권위 시간은 `2,000 tick = 1년`이다.
- 1년은 12개월, 1개월은 30일인 360일 달력으로 표시한다. 월·일은 2,000 tick을
  정수 비율로 환산하므로 월 경계는 166 또는 167 tick 간격이지만 누적 오차는 없다.
- 모든 AI는 같은 달에 최대 한 번만 행동한다. 전투·윤회 때문에 행동 시점이 다시
  예약돼도 마지막 행동 월 다음 달보다 앞당겨지지 않으며, 쉬었던 달의 행동을 몰아서
  처리하지 않는다.
- 지원 배속은 1×, 10×, 25×, 50×, 100×다.
- 각 대경지는 1층~9층을 가지며 UI에서 1~3층은 초기, 4~6층은 중기,
  7~9층은 후기로 함께 표기한다. 9층 Work를 완성한 뒤 대원만을 별도로 판정한다.

| 대경지 | 기본 최대 수명 | 기준 수행 기간 |
|---|---:|---:|
| 연기경 | 150년 | 50년 |
| 축기경 | 300년 | 100년 |
| 금단경 | 600년 | 200년 |
| 원영경 | 1,200년 | 400년 |
| 화신경 | 3,000년 | 1,000년 |
| 연허경 | 9,000년 | 3,000년 |
| 합체경 | 2만 년 | 6,666.67년 |
| 도겁경 | 10만 년 | 33,333.33년 |
| 대승경 | 10만 년(별도 수명 미확정으로 유지) | 33,333.33년 |
| 반선경 | 100만 년 | 333,333.33년 |

모든 대경지의 기준 수행 기간은 **선천 수행자질 6종 산술평균 50.00**인 수선자가
그 대경지 **1층 수행을 시작해 9층 Work를 마치고 대원만에 도달하기까지의 전체
기준 기간**이며, 해당 경지 기본 최대 수명의 정확히 3분의 1이다. 각 층마다 최대 수명의
3분의 1을 따로 적용하지 않는다. 권위 계산은 월 Work를 쓰며
50.00에서 월 1,000 Work가 쌓인다. 9층의 현재 임시 가중치는
`80/90/100/105/110/115/125/135/140`이고 합계 1,000이므로 대경지 전체 기간을
보존한다.

### Notion 수행 정본 적용

수행 구조의 구현 기준은 [Alpha 1 1 3](https://app.notion.com/p/3ccacc9e6175811b9d9afd1e9e916c1b)과
[선로만상록 세계관·게임 기획·개발 정본](https://app.notion.com/p/3acacc9e617580278373c8114c7a9ebb)의
`P09. 수행·자질·윤회` 계약이다. PC판은 다음 의미 경계를 적용한다.

```text
현재 Realm Profile / 소경지
→ 단계별 누적 Work
→ 돌파 준비
→ Preflight
→ 돌파 시도
→ 성공 시 원자적 경지 전이와 안착
   또는 실패 시 원인이 명시된 병목
```

- 권위 진행값은 현재 단계의 누적 Work이며 UI 백분율은 Work/요구량에서 파생한다.
- 모든 수선자는 0세에 태어나 5세까지 준비기를 거친다. 5세부터 입문 Work 30,000과
  영근·근골·오성 중심의 3개 Gate를 검증하고 모두 통과해야 연기경 1층에 입문한다.
- 돌파 확률 RNG는 Work가 찬 순간이 아니라 준비와 Preflight가 끝난 별도 월 행동에서만
  소비한다. 화면 조회와 예상값 표시는 RNG를 소비하지 않는다.
- 병목 원인은 공법·법술 지식, 육신, 영근·영력, 돌파 자원, 정신·영혼 안정성으로
  구분한다. AI는 원인에 맞춰 수련·회복·임무·시장 행동을 선택한다.
- 성공 뒤에는 새 경지 안착 행동을 거친다. 안착과 부상 회복은 같은 상태로 저장하지
  않는다.
- 각 경지는 안정 ID와 revision을 가진 Realm Profile로 조회한다.

Notion에서 수치가 열려 있는 범위보다 이후 사용자 대화에서 직접 확정한 PC판의
10대 경지, 최대 수명, `선천 수행자질 50.00에서 최대 수명의 3분의 1` 수행 기간을
우선한다. 미확정 수치는 게임 진행이 막히지 않는 임시값으로 구현하되 안정 ID,
formula revision과 `RequiresReview` 표식을 붙여 후속 기획 검토에서 교체한다.

## 5. 자질

| 자질 | 수행에서의 역할 | 전투에서의 역할 |
|---|---|---|
| 영근 | 영기 흡수와 수행 진척 | 영력량과 영력 회복 |
| 근골 | 육체 단련과 동작 안정 | 물리 위력과 행동 회복 |
| 체질 | 장기 수행과 부상 회복 | 생명력과 피해 저항 |
| 오성 | 공법·법술 이해와 돌파 | 법술 운용과 대응 효율 |
| 정신 | 수행 통제와 정신 부담 | 신식·정밀 제어와 복합 행동 |
| 영혼 | 수행 잠재와 영구 변화 | 영혼 강도와 고경지 부담 대응 |

자질은 전투력에 직접 더하지 않는다. 각 자질은 명시된 파생 능력과 공법·법술·전투
성장 보정만 바꾸며, 경지로 이미 얻은 전투력을 다시 중복 증폭하지 않는다. 역할별
원시 자질 가중평균 0.00은 50%, 50.00은 100%, 100.00은 200%로 변환되고 이 범위를
벗어나지 않는다. 품질 등급의 큰 경계 배율은 이 보정률에 적용하지 않는다.

| 보정 대상 | 자질 가중치 | 범위 |
|---|---|---:|
| 공법 효과·수련 경험·이해 성장 | 근골 35%·체질 35%·정신 15%·영혼 15% | 50%~200% |
| 법술 효과·수련 경험·이해 성장 | 영근 40%·오성 35%·정신 15%·영혼 10% | 50%~200% |
| 전투 숙련 효과 | 근골 20%·오성 30%·정신 30%·영혼 20% | 50%~200% |
| 전투 이해 효과·성장 | 오성 45%·정신 35%·영혼 20% | 50%~200% |
| 전투 경험 획득 | 오성 25%·정신 35%·영혼 25%·체질 15% | 50%~200% |

역할별 가중치는 미확정 수치를 채운 revision 2 임시값이며 실제 분포와 장기 회귀를
검토하면서 변경할 수 있다.

자질 랭킹을 위한 종합지수는 여섯 대표값의 합으로만 계산한다. 이는 비교용 지표이며
개별 수행·전투 공식에서는 각 자질이 맡은 입력을 따로 사용한다. 윤회할 때 영혼 자질은
동일 영혼에 남고, 오성·근골·체질·영근·정신은 새 육신 조건에서 다시 형성된다.

### 공통 품질 척도

자질·공법·법술은 모두 0.00~100.00의 같은 품질값과 다음 품질명을 쓴다. 경계를
0.01만 넘어도 범주 배율이 먼저 바뀌고, 같은 범주 안에서는 원래 품질값이 비교된다.

| 품질 | 값 범위 | 직전 경계 대비 효과 |
|---|---:|---:|
| 폐품 | 0.00~9.99 | 기준 |
| 극하품 | 10.00~29.99 | 약 5배 |
| 하품 | 30.00~39.99 | 약 2배 |
| 중품 | 40.00~59.99 | 약 1.5배 |
| 상품 | 60.00~79.99 | 약 1.5배 |
| 극상품 | 80.00~89.99 | 약 2배 |
| 천품 | 90.00~99.99 | 약 4배 |
| 무결품 | 100.00 | 약 10배 |

극하품→하품 문장에는 1.5배와 `29.99→30.00 약 2배`가 함께 제시되어 있으므로,
현재 정본은 더 구체적인 경계 수치인 약 2배를 적용한다. 배율은 정수 비율로 계산해
플랫폼에 따라 결과가 달라지는 부동소수점 연산을 권위 상태에 넣지 않는다.

## 6. 생애·일대기·윤회

- 모든 AI는 세계 0년에 0세로 태어나 제1생을 시작한다.
- 매 tick의 미세 변화는 기록하지 않고 탄생, 첫 병목 실패, 병목 돌파, 소경지 돌파,
  대경지 돌파, 대원만, 공법·법술 신규 획득, 기연, 수명/전투 사망,
  윤회의 강 진입과 환생만 일대기에 남긴다.
- 현재 나이가 현재 경지의 기본 최대 수명에 도달하면 육신이 사망한다.
- 영혼은 1게임년 동안 윤회의 강 상태에 머문 뒤 제2생 이상의 새 인물로 태어난다.
- 새 생은 이름·육신 자질·경지·공법·법술·전투 경험을 새로 형성하지만 영혼 자질과
  모든 전생 일대기는 유지한다.
- 안정 `AgentId`는 영혼의 관찰 슬롯이며 각 생의 이름과 생 번호로 Person Identity를
  구분한다.

### 로그와 연대기

- 전체 세계 로그에는 1위 교체, 대경지 돌파, 죽음·윤회·환생, 천품 이상 성취,
  최상위권 전투 결과처럼 세계적으로 중요한 사건만 표시한다.
- 세계 로그와 개인 최근 로그는 각각 최대 100줄을 유지한다.
- 개인 최근 로그에는 월 행동과 전투·거래·임무 등 해당 인물의 사건을 기록한다.
- 같은 장기 행동이 여러 달·여러 해 계속되면 새 줄을 매달 추가하지 않고 기존 줄의
  지속 개월과 `N년 차` 표시만 갱신한다.
- 연대기는 탄생·병목·소/대경지 돌파·기연·죽음·윤회·환생의 중요 기록이며
  100줄 제한을 적용하지 않는다. 모든 생의 연대기는 저장 파일에 영구 보존한다.
- 최근 로그는 전체·수행·전투·경제·이동·생애·죽음 내부 탭으로, 영구 연대기는
  사건 종류 내부 탭과 제1생·제2생 같은 생별 토글로 필터링한다. 깨달음은 이해도
  성장 사건이지만 영구 연대기에는 기록하지 않는다.

## 7. 전투력

전투력은 다음 여섯 행으로 UI에 분해해 공개하되, 자질 행은 직접 합산값이 아닌 간접
보정임을 명시한다.

1. **경지 전투력**: 대경지와 층계가 만드는 기본 격차
2. **자질 간접 보정**: 직접 전투력 0, 역할별 50%~200% 효과만 표시
3. **공법 전투력**: 공법 품질·숙련·이해와 자질 보정으로 얻는 기반 강화
4. **법술 전투력**: 법술 품질·숙련·이해와 자질 보정
5. **전투 성장 전투력**: 전투 경험·숙련·이해의 제한된 합산 기여
6. **법보 전투력**: 본명법보·공격 법보·방어 법보의 품질과 장착 효과

표시 전투력은 비교와 랭킹을 위한 예측치이며 승리를 보장하지 않는다. 현재 생명력,
영력, 부상과 행동 선택 때문에 낮은 전투력의 AI도 이길 수 있다. 전투 경험에는
체감 수익을 적용해 오래 산 승자가 무한히 독주하지 않게 한다. 전투 숙련도는 누적
전투 경험의 제곱근 곡선에서 0.00~100.00으로 파생하고, 전투 이해도는 별도
0.00~100.00 권위 상태로 전투·사냥 결과에서 성장한다.

### 공법·법술 성장

- 공법과 법술은 불변 품질, 누적 수련 경험, 0.00~100.00 숙련도, 0.00~100.00
  이해도를 각각 가진다.
- 반복 수련은 경험과 숙련도를 높인다. 숙련도는 누적 경험의 제곱근 곡선을 사용해
  수치가 높을수록 같은 0.01을 올리는 데 더 많은 경험이 필요하다.
- 공법/법술 수련 경험과 깨달음 이해 증가량은 각 역할 자질 보정률 50%~200%를
  적용한다. 자질은 공법/법술의 불변 품질을 바꾸지 않는다.
- 깨달음은 이해도만 높인다. 기존 공법/법술 품질을 올리지 않으며, 더 높은 품질은
  새 공법서/법술서를 얻어 기술 자체를 교체해야 한다.
- 공법은 최대 생명력·최대 영력·기반 방어를, 법술은 공격/방어·속도·관통·치명타·
  회피를 중심으로 높인다. 품질·숙련·이해가 실제 파생 속성과 표시 전투력에 모두
  들어가지만 두 계산식은 동일하지 않다.

## 8. 경쟁 활성화 규칙

- AI는 랭킹과 각 전투력 구성 요소를 비교해 가장 부족한 성장 행동을 선택한다.
- 도전자는 기본적으로 같은 지역에 있는 자신보다 높은 순위 중 승산이 있는 상대를 찾는다.
- 오랫동안 전투하지 않은 건강한 AI는 도전 욕구가 높아진다.
- 1위와 최상위권은 도전 대상으로 노출되는 빈도가 높다.
- 패배해도 전투 경험을 얻지만, 승리보다 적다.
- 부상, 영력 고갈과 연속 전투 제약으로 같은 인물의 무한 전투를 막는다.
- 반복 대전에는 일시적 기피를 적용해 상대 다양성을 유지한다.

## 9. 도시 임무·경제·법보·단약

초기 경제는 하나의 공용 도시와 도시가 중개하는 공동 시장을 중심으로 작동한다. AI는
도시가 실제로 부족한 법보 재료나 단약 재료가 있을 때만 해당 재료 조달 임무를
선택적으로 수주한다. 납품한 재료는 공동 시장 재고에 들어가며, 플레이어는 거래나
임무·생산 결과를 관찰만 한다.

- 재료는 법보 재료와 단약 재료 2종으로 간략화한다. 완제품은 성장 단약·돌파 단약·
  방어 법보·공격 법보이며 각 10개 대경지마다 별도 상품이다. 더 높은 대경지에
  진입하면 해당 대경지용 완제품을 새로 구매해야 한다.
- 법보는 본명법보·방어 법보·공격 법보의 총 3개 독립 슬롯에 하나씩 장착한다.
  본명법보는 시장 완제품이 아니며 본인이 법보 재료와 영석을 사용해 직접 만든다.
  소유자와 동기화되어 대경지 돌파 시 본명법보의 대경지 등급도 함께 올라간다.
- 방어/공격 법보와 공법서·법술서는 품질을 가진다. 새 세계의 공법·법술 품질은
  0.00~79.99 범위에서 시작한다. 79.99→80.00 가격은 두 배이며, 80.00 이상은
  품질이 1.00 높아질 때마다 가격이 다시 두 배가 된다.
- 성장 단약은 수행 진척을 늘리고 돌파 단약은 병목 돌파를 돕는다. 수선자가 직접
  단약 완제품을 제작하지 않으며 현재 대경지에 맞는 도시 상품을 구매한다.
- 한 수선자가 시장에 판 재료·법보·공법서·법술서는 공동 재고에 쌓여 다른 수선자가
  살 수 있다.
  각 상품은 도시 기준가, 현재 재고, 누적 공급과 누적 수요를 가지며, 공급 증가는 가격을
  낮추고 구매·가공 소비에 의한 수요 증가는 가격을 높인다. 현재가는 도시 기준가의
  25%~400% 범위에서 정수 계산으로 결정하고, 품질 상품은 그 위에 품질 가격을
  적용한다. 도시 매입가는 판매가의 80%로 두어 무한 차익을 막는다.
- 도시는 미충족 수요가 있고 재료·영석이 모두 있을 때만 생산 대기열을 시작한다.
  법보/단약은 해당 재료와 영석, 공법서/법술서는 영석만 소비한다. 생산 시작 시 자원을
  예약하고 3개월 뒤 공급하며 진행 중 품목·기간·투입 자원을 도시 UI에서 관찰한다.
  가장 큰 수요 상품의 재료가 없어도 생산 가능한 다음 상품을 찾아 대기열 정체를 막는다.
- 영석은 도시의 유한 광맥에서만 새로 생산된다. 도시 금고나 생산 자금이 부족할 때
  채굴 인력 임무가 열리고 수선자가 지원해 광석을 채굴하며 일부를 보상으로 받는다.
- 경제 상태는 개인 영석·임무·재료 2칸·대경지별 단약·장착 법보 3칸뿐 아니라 도시
  금고·유한 광맥, 44개 시장 상품의 재고·품질 합계·현재가·공급·수요와 최대 4개
  생산 대기열을 명시적으로 저장한다.
  도시의 구매·판매 거래 수, 임무 납품, 가공 재료, 단약·법보·공법서·법술서 생산
  및 채굴 누계도 저장해 도시 상세 화면에서 확인할 수 있다.

### 세계 지도·요수

초기 지도는 3×3 고정 좌표다. 중앙 만상성, 숲 3곳, 평야 2곳, 산맥 3곳으로
구성한다. 각 야외 지형에는 그 지형에 속한 요수 3종이 있고 서로 다른 위험도와
전리품 재료를 가진다.

- 수선자는 현재 위치와 이동 목적지를 가지며 이동 거리는 맨해튼 좌표 거리로 계산한다.
- 도시에서는 수행·도전·임무·시장·제작을 선택하고, 일정 확률로 야외 탐색을 떠난다.
- 야외에서는 지형 요수를 사냥하거나 다른 지역/도시로 이동한다.
- 요수 사냥은 실제 전투 속성으로 승산을 계산하고, 승리 시 전투 경험과 재료를 얻는다.
  패배하면 생명력과 누적 부상을 잃고 치명상일 경우 사망·윤회한다.
- 각 야외 칸은 요수 개체수를 권위 상태로 가지며 사냥 승리 시 감소하고 매월 한도까지
  재생한다. 지도 칸을 클릭하면 지형·위험도·요수 종별 개체수와 현재 수선자 목록을
  확인하고 그 수선자를 곧바로 선택할 수 있다.
- 지도별 인구, 서식 요수, 세계/개인 사냥 누계는 관찰 DTO로 제공하며 조회는 AI 행동과
  난수에 영향을 주지 않는다. 선택한 지도 칸만 상세 인물 목록을 만든다.

## 10. 랭킹·전체 탐색·수치 표기

- 공식 랭킹은 전투력·경지·자질의 세 범주이며 각각 1위부터 1,000위까지 공개한다.
- 경지 랭킹은 대경지, 소경지, 현재 수행 진척 순으로 비교한다.
- 자질 랭킹은 여섯 수행자질 대표값의 합을 비교 지표로 사용한다.
- 공식 랭킹에 들지 않은 수선자도 전체 탐색에서 안정 ID 순으로 모두 찾아볼 수 있으며,
  이름이나 `A00001` 형식의 ID로 검색할 수 있다.
- 1만 이상의 큰 표시 수치는 만·억·조·경 단위로 축약하고 필요한 경우 소수 둘째
  자리까지 보여 준다. 저장값과 공식 계산에는 축약 문자열을 사용하지 않는다.
- 전체 통계는 미입문과 10개 대경지별 인원, 고정 전투력 구간별 인원과 비율,
  사망·승리·패배·윤회·임무·영석 누계를 제공한다.
- 전투력 랭킹 변동률은 직전 공식 갱신과 비교해 순위가 달라진 인원 비율이다. 같은 표에
  상승·하락·유지 인원과 변동 인원의 평균 절대 이동 순위를 함께 표시한다.
- 상위 1위·3위·5위·10위 경계는 전투력과 경지 랭킹에서 각각 변동 횟수와 변동률을
  누적해 최상위 경쟁의 안정성과 교체 빈도를 별도로 보여 준다.
- 우측 관찰 영역은 세계 통계, 도시 상세, 44개 상품 시장, 중요 세계 로그 탭으로
  분리하고 3×3 지도 탭을 함께 제공한다. 인물 상세에는 수행 상태·행동 일정·위치·
  재료별 수량·실전 전투 속성·전투력 분해·입력별 상세 공식과 개인 로그/영구 연대기
  내부 탭을 둔다.
- 통계 분포와 시장·지도 상세 목록은 필요할 때 펼치는 구조로 제공한다. 현재 선택하지
  않은 외부 탭, 내부 로그 탭과 접힌 상세 목록은 관찰 결과에 영향을 주지 않을 뿐 아니라
  조회 집계와 UI 행 생성도 수행하지 않는다.

## 11. 실시간 전투

전투는 한 번의 승률 추첨이 아니라 단일 턴 소유자를 갖는 교대 행동 타임라인으로
진행한다. 각 참가자는 공격, 법술, 방어 또는 이탈을 선택하고 상대에게 턴을 넘긴다.
실제 피해는 공격·방어·명중/회피·관통/관통방어·치명타/치명타방어·영력과 방어 태세로
계산하며 표시 전투력 비율을 직접 피해식에 쓰지 않는다.

연기/축기경의 한 행동은 약 1개월, 이후 경지의 임시 기준은 3개월·1년·3년·10년·
50년·200년·1,000년·5,000년으로 길어진다. 최대 행동 수로 전투를 강제 종료하지 않아
상위 경지 교전은 수십 년부터 수천 년까지 이어질 수 있다.

피해는 0.00~100.00 누적 부상으로도 환산한다. 경상·중등상·중상·치명상·사망상으로
구분하며 중상부터 사망 확률이 생긴다. 전투 사망은 영구 연대기와 전체 사망 통계에
포함되고 윤회로 이어진다.

관찰되지 않는 전투도 같은 공식과 사건 순서로 계산한다. UI를 열거나 닫는 행동이
전투 정밀도나 결과를 바꾸지 않는다.

## 12. 첫 릴리스 범위

포함:

- 연기경부터 반선경까지 10대경지와 초기·중기·후기·대원만
- 각 대경지의 1층~9층, 5세 입문 Work와 3개 Gate
- 여섯 수행자질, 공법, 법술, 전투 경험, 부상과 회복
- 자율 수행·돌파·도전·전투·이탈 판단
- 수요형 도시 임무, 유한 영석 광맥, 2종 재료, 시장 판매와 도시 법보·단약 생산
- 대경지별 성장/돌파 단약·방어/공격 법보와 본명법보 1칸·방어/공격 법보 각 1칸
- 전투력·경지·자질 랭킹, 전체 인물 탐색, 인물 상세와 생애 일대기
- 수명 판정, 사망, 윤회의 강과 영혼 연속 환생
- 저장·불러오기, 일시정지와 배속
- 3×3 지도, 도시·숲·평야·산맥, 지형별 요수와 이동·사냥

제외:

- 문파, 관계망, 플레이어 개입
- 복수 도시, 경매장, 전문 제작 직업

- 네트워크 멀티플레이와 서버 권위

## 13. 릴리스 완료 조건

- 기본 세계에 정확히 10,000명의 AI가 생성된다.
- 모든 AI가 목표 순위 1위를 보유하고 실제 성장·도전 행동을 수행한다.
- 전투력 여섯 구성 요소의 합과 랭킹 정렬이 일치한다.
- 장시간 진행 시 도전자와 순위 변동이 지속해서 발생한다.
- 모든 재료 범주가 임무·판매·제작 순환에 참여하고 법보·단약 효과가 실제 계산에 반영된다.
- 동일 seed 재실행 결과가 동일하다.
- 저장 후 복원해도 랭킹, 진행 중 행동과 다음 사건이 보존된다.
- Windows x64 Release 패키지가 새 PC에서 실행된다.
