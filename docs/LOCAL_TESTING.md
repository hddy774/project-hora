# PC 로컬 실행 및 테스트

## 가장 쉬운 실행 방법

저장소 루트의 `로컬_빌드_및_실행.cmd`를 두 번 클릭합니다. 스크립트가 다음 작업을
순서대로 수행합니다.

1. Release 빌드
2. 전체 자동 테스트
3. .NET 설치가 필요 없는 Windows x64 독립 실행본 생성
4. 바탕화면에 `선로만상록 PC` 바로가기 생성
5. 게임 실행

완성된 실행 파일은
`artifacts/Chronicles-<VERSION>-win-x64/Chronicles.exe`에 있습니다. 이후에는 바탕화면
바로가기를 사용하면 다시 빌드하지 않고 바로 실행할 수 있습니다.

## 수동 명령

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-local.ps1 -CreateDesktopShortcut -Launch
```

코드 변경 없이 기존 실행본만 시험할 때는 바탕화면 바로가기 또는 `Chronicles.exe`를
직접 실행합니다.

## 기본 점검표

- 초기 인구가 10,000명인지 확인
- 세계 시간이 `년 월 일`로 표시되고 매 AI의 누적 행동이 같은 달에 두 번 증가하지 않는지 확인
- 1x, 10x, 25x, 50x, 100x와 일시정지가 동작하고 100x에서도 월 수치가 빠르게
  달라지는지 확인
- 전투력·경지·자질 랭킹이 각각 TOP 1,000까지 표시되는지 확인
- 전체 탐색에서 10,000명을 페이지로 이동하고 이름 또는 `A00001` 검색이 동작하는지 확인
- 모든 목록과 상세창에서 `연기경 · 초기 · 1층`처럼 대경지·초/중/후기·1~9층이 함께
  표시되고 대원만 달성 시 `대원만 · 9층`으로 바뀌는지 확인
- 인물 상세의 경지 `N층`과 `나이 / 수명` 값이 서로 겹치거나 하나의 숫자처럼 이어
  보이지 않는지 확인
- 인물을 선택했을 때 6대 자질·경지·공법·법술·법보·단약·임무·영석·재료별 수량,
  현재 위치와 요수 사냥 전적이 표시되는지 확인
- 수행 Work가 찬 뒤 준비→Preflight→시도→안착 또는 원인별 병목으로 월마다 진행되고,
  선천 수행자질 종합·기준 기간·입문 Gate·경지 구성요소가 상세 패널에 표시되는지 확인
- 공법/법술 수련은 숙련도를, 깨달음은 이해도만 올리며 품질은 새 서적을 얻을 때만
  바뀌는지 확인
- 실제 공격·방어·속도·관통·치명타·회피·판단력·집중력·효율·누적 부상이 인물
  상세에 표시되는지 확인
- 전투가 양쪽 교대로 진행되고 중상/치명상에서 전투 사망과 윤회가 발생하는지 확인
- 인물의 `최근 개인 로그`가 최대 100줄이고 `영구 연대기`는 별도 탭에서 이전 생까지 유지되는지 확인
- 전체 경지·전투력 분포, 랭킹 변동률, 승리·패배·사망 통계가 갱신되는지 확인
- 우측 `통계·도시·시장·지도·세계 로그` 탭이 각각 독립적으로 표시되는지 확인
- 외부 탭과 인물의 `최근 개인 로그·영구 연대기` 내부 탭에서 선택 항목만 강조되고,
  통계 분포·시장 상세·지도 상세의 접기/펼치기가 정상 동작하는지 확인
- 1,000위 랭킹과 긴 연대기를 스크롤할 때 화면 밖 행이 재활용되어 UI가 멈추지 않는지 확인
- 도시 탭의 거래·납품·가공·생산 누계가 증가하는지 확인
- 시장의 35개 상품 기준가·현재가·변동률·재고·공급·수요가 거래에 따라 바뀌고,
  상품 선택 시 용도·생산 방식·법보 평균 품질 상세가 표시되는지 확인
- 지도 3×3 칸의 도시·숲·평야·산맥 인구가 합계 10,000명이며 각 야외 지형에 고유
  요수 3종이 표시되고 사냥 누계가 증가하는지 확인
- 세계 로그에는 반복 공격·일반 거래가 아닌 중요한 세계 사건만 최대 100줄 표시되는지 확인
- 저장 후 `%LocalAppData%\ChroniclesOfMyriadImmortalPaths\world.cmip`이 생성되는지 확인
- 진행한 뒤 불러오면 저장한 tick과 상태로 돌아가는지 확인

로컬 산출물과 저장 파일은 GitHub Release에 업로드되지 않습니다.
