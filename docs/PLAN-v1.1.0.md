# v1.1.0 — 경쟁하는 시장

## 개발 및 배포 절차

이 계획을 먼저 Draft PR에 등록한다. 같은 PR에서 구현과 검증을 완료하고 main에 병합한 후, 병합 커밋을 v1.1.0으로 태그하여 APK와 소스 ZIP을 최신 GitHub Release에 배포한다. 이후 기능 업데이트도 1.2.0, 1.3.0처럼 가운데 버전을 올린다.

## 구현 범위

- C# 오프라인 관찰 게임을 유지한다. 플레이어는 주문에 참여하지 않는다.
- 1배속은 실제 5초 = 게임 1시간, 120초 = 1일이다. 1/2/5/20배속과 일시정지를 제공한다.
- 기관 100개와 개인 10,000명의 현금, 주식, 체결 및 장부를 독립적으로 유지한다. 개인의 초기 자산은 기관의 1/100이다. 개인은 시장 흐름에 반응하며 일부가 매시간 유동적으로 참여한다.
- 가격·시간 우선의 지정가 호가 경쟁을 구현한다. 주문의 현금/주식을 예약하고, 상대 주문과 실제 체결될 때 주가를 변경한다. 미체결 주문, 매수/매도 잔량, 기관/개인 구성, 최근 체결을 표시한다.
- 기관별 포트폴리오와 재무상태표, 손익계산서, 현금흐름표를 표시한다. 개인은 전체/1인 평균 재무제표와 활동 통계를 제공하고 개인별 순위는 만들지 않는다.
- 전체 시장 및 분야별 가격 변화, 거래량/거래대금, 유동성, 참가자 통계를 표시한다.
- 30일 시즌은 자동으로 다음 시즌으로 이어진다. 자산과 시장은 이어지고 시즌 시작 자산 대비 수익률로 기관 순위를 기록한다. 시즌별 100개 순위와 각 기관의 과거 순위를 조회한다. 완료 시즌은 별도 파일에 보관하고 화면에는 페이지 단위로 불러온다.
- 대표 인물은 성인 여성 70명, 성인 남성 30명으로 고정한다. 제공된 참고 이미지의 정교한 애니메이션 화풍, 빛과 색감을 참고하되 현대 복장과 도시 배경의 서로 다른 인물을 생성한다. APK에서는 100개의 독립적인 인물 ID를 텍스처 아틀라스의 각 그림에 연결하여 메모리를 절약한다.
- 기존 v1.0 저장은 원본을 보존하고 기관 자산/기록을 새 형식으로 이전한다. 저장은 원자적으로 교체하며 20배속에서 매 틱 디스크를 쓰지 않는다.

## 검증 기준

1. 기관 100개, 개인 10,000명, 여성/남성 그림 70/30개를 검사한다.
2. 가격·시간 우선, 부분 체결, 주문 취소/만료, 예약 현금/주식, 자금/주식 부족 거부를 검사한다.
3. 실제 체결만 주가를 바꾸는지, 거래 전후 주식 수와 현금+수수료가 보존되는지 검사한다.
4. 재무상태표와 손익/현금흐름 장부가 일치하는지 검사한다.
5. 20배속 시간, 여러 시즌 자동 전환, 순위 동률 처리, 시즌별/기관별 기록, 저장 복원과 이전을 검사한다.
6. 장시간 시뮬레이션 및 20배속 처리 성능을 측정하고 화면/기록 버퍼가 제한되는지 확인한다.
7. Release APK를 동일한 서명키로 빌드·검증하고 Android 에뮬레이터에서 화면 및 실행을 확인한다.
8. PR 병합 후 릴리스 APK/소스와 SHA-256을 게시하고 다운로드 파일을 검증한다.
