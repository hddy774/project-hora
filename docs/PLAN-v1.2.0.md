# v1.2.0 — 판단하는 기관과 시즌 경제

이 계획을 Draft PR에 등록한 뒤 같은 PR에서 개발·검증한다. main 병합 커밋을 v1.2.0으로 태그하고 최신 GitHub Release에 APK, 소스 ZIP, 검증 보고서와 체크섬을 배포한다. 앱 ID와 기존 배포 서명을 유지한다. 오프라인 관찰 게임과 100개 기관·10,000명 개인, 30일 연속 시즌을 유지한다.

## 구현 계획

1. 대표에게 가치 분석, 기술 분석, 뉴스 해석, 위험 관리, 분산 설계, 주문 집행, 단타, 초단타, 거시 판단, 협상 능력(각 1~100)과 성향을 부여한다. 모든 기관은 시장 상황과 능력에 따라 가치·추세·역추세·뉴스·단타·초단타를 혼합하고 종목·분야별 비중을 제한한다. 하락·변동성 확대 시 현금을 늘리고 손절·헤지·대출 축소를 판단한다.
2. 투자 방식별 순위 분류를 제거한다. 수익률, 순수익, 자산, 현금, 거래량, 거래금액 기준 정렬과 전체/현재 시즌/10일/5일/전일 기준을 제공한다. 동일 점수는 기관 ID로 결정한다.
3. 50배속·100배속을 추가한다. 시간 누적과 자동 저장을 유지하고 100배속 처리 예산(시간당 50ms)을 측정한다.
4. 일별 시장·기관 통계, 시즌 요약, 전체 누적 기준을 저장한다. 통계와 재무 화면에 선 그래프·막대·원형표와 비교 표를 제공한다. 이전 시즌 기록은 기존 시즌 파일을 통해 조회하고 일별 화면 기록은 제한된 버퍼를 사용한다. 비교 기준의 실제 시작/끝과 데이터가 부족한 경우를 표시한다.
5. 기관 전용 공매도를 추가한다. 대여 가능 수량, 현금 담보, 수수료·대여료, 공매도 부채, 상환 매수, 담보 부족 청산을 회계와 호가에 통합한다. 개인은 공매도하지 않는다. 현금·주식·부채 보존과 미체결 담보 해제를 검사한다.
6. 종목을 8개에서 10개로 늘린다(클라우드 기업 CLUD, 헬스케어 기업 CARE). 각 기업에 재무상태표, 손익계산서, 현금흐름표, 자본변동표, 주요 재무비율 5개 재무 화면을 제공한다. 매 30일 시즌마다 실적을 갱신하고 해당 시즌에 축적한 뉴스 영향과 정책을 반영한다.
7. 정부가 매 시즌 세금, 거래 수수료, 공매도/대출 규제, 기준금리, 주식 보조금을 결정한다. 정책 변경 이력과 시장·기업·기관에 미치는 효과를 UI에 표시한다.
8. 은행·대출을 추가한다. AAA/AA/A/BBB/BB/B/CCC/CC/C의 9개 등급, 자산 대비 100/90/80/70/60/50/40/35/30% 한도와 등급별 금리를 적용한다. AI가 차입·상환을 판단하고 이자, 부채, 한도 초과 시 대응을 장부에 기록한다.
9. 대표 간 상호작용과 가상 시장 작전을 구현한다. 참여 기관, 대상 종목, 진행·종료·실패, 벌금과 규제 적발 기록을 별도 UI에 표시한다. 자전거래 금지를 유지하고 벌금·정책 계정을 회계에 반영한다.
10. 기존 v2/v3 저장을 원본 보존하며 새 v4로 이전한다. 기존 기관 ID·현금·주식·성적을 유지하고 신규 종목·대표 능력·기업 실적·은행·정부 상태를 초기화한다.

## 검증과 배포 기준

- 가격·시간 우선, 부분 체결, 일반 주문/공매도/상환 예약, 취소·만료, 자전거래 금지와 현금·주식·부채 회계 불변식.
- 등급별 한도·금리, 대출·상환·이자, 공매도 손익과 담보 부족, 정부 세금·보조금·벌금, 작전 종료를 직접 검사.
- 능력과 성향에 따른 의사결정 차이, 분산 비중과 하락장 대응을 검증하고 장시간 연속 시즌 실행.
- 시즌 기업 실적과 뉴스 영향, 비교 기간 계산과 거래량/거래금액 순위, 50/100배속, 저장 복원 결정성, v2/v3 이전과 손상 복구.
- Android Release 빌드와 가능한 에뮬레이터 검증. 기존 APK와 서명 인증서 비교, APK 실제 설치/화면 확인은 수행한 범위만 보고한다.
- PR CI 통과 후 병합. 병합된 태그에서 소스 ZIP 생성, 릴리스 다운로드와 SHA-256 확인. 서명키 등 배포 자격이 없으면 그 차단 원인과 완료 범위를 명시한다.
