# v1.3.0 시장 시스템 개선 계획

이번 PR은 현재 시장의 축소 원인을 기록하고 다음 구현의 설계·검증 기준을 정한다. 현재 앱 동작을 변경하거나 릴리스를 배포하는 PR은 아니다. 후속 구현은 이 계획을 기준으로 진행한다.

## 목표

1. 기업의 생산·이익·투자·배당이 투자자와 실물경제의 자금 흐름으로 이어지는 시장을 만든다. 주가를 강제로 올리는 보정 대신 성장·불황·회복이 모두 가능한 모델을 설계한다.
2. 현재 6개 분야마다 회사 5개를 배치해 기본 상장 구성을 30개로 확장한다. 기존 10개 회사·투자자 자산을 보존하고 신규 20개 회사의 사업 특성을 구분한다.
3. 발행주식·유통주식·자사주·시가총액·배당·EPS/PER/PBR·액면분할·주식병합·기업합병을 회계와 가격·차트·공매도에 일관되게 적용한다.
4. 통계를 매 게임 시간 파일에 영구 기록하고 과거 시즌까지 이어서 조회한다. 제한된 메모리 버퍼와 영구 보관 정책을 구분하며, 기록을 버리는 저장 병합은 금지한다.
5. 원인 분석, 회사 구성표, 상세 설계, 단계별 구현 과제, 완료 조건과 재현 가능한 분석 자료를 같은 Draft PR에 정리한다.

## 조사 기준

- 코드 기준: main `e11579ac794f043c7b2cec10052746af9e5e6adf`. 엔진은 배포 태그 v1.2.0과 동일하다.
- 기본 시드 5개와 수수료 제거 비교 1개를 각각 36시즌 실행한다.
- 주가 평가액, 투자자 현금/순자산, 거래소 수수료, 정부/은행 현금, 기업 이익과 배당 표시액을 분리한다.
- 현금·실물 주식 보존을 월말마다 검사하고 원자료를 보관한다. 개입 실행은 이후 난수 소비 경로가 달라질 수 있으므로 인과효과의 정밀 추정으로 취급하지 않는다.

## 구현 우선순위

1. 원인 계측과 현재 시즌 파일을 이용한 전체 기간 통계 조회.
2. 기업·실물경제·거래소·정부 현금 장부와 가치 창출/자금 순환.
3. 실제 배당 정산과 가격수익률/총수익률 구분.
4. 안정적인 종목 ID와 분야별 회사 5개, 초기 자산 배분·유동성 재설계.
5. 발행/유통 주식과 액면분할·병합·기업합병의 원자적 처리.
6. 통계 파일의 연속성·복구·장기 조회와 저장 이전, 100배속 성능 검증.

상세 과제·완료 조건은 조사 자료와 함께 이 PR에서 보완한다.
