# Windows PC 전환 개발 계획 · v1.8.0

요청: 기존 게임 기능을 Windows PC에서 실행하도록 이어 개발하고, 완료한 PR만 병합한다. 병합 이후의 개발 대상은 PC뿐이다. 배포·릴리스·설치 프로그램·APK·배포 ZIP을 만들지 않는다.

기준: 열린 PR이 없으며 PR #9와 v1.7.0은 이미 main에 병합되었다. 최신 main에서 같은 경제 엔진과 모든 관찰 화면을 Windows 실행 파일로 이식한다.

- [ ] .NET 10 Windows 데스크톱 앱과 마우스·휠·키보드 조작 추가
- [ ] 시장·자산·랭킹·인물·통계·시즌·뉴스 및 상세 화면과 원본 200개 그림 보존
- [ ] Windows 파일 선택, ZIP 기록 가져오기/내보내기, 로컬 SQLite 저장·재개
- [ ] 소스 `개발/`과 실행에 필요한 파일만 있는 `빌드/` 분리, 로컬 PC 빌드 스크립트
- [ ] 활성 솔루션·CI·개발 지침을 PC 전용으로 변경, 자동 배포 제거
- [ ] 기존 회계·매칭·저장 회귀, 그림 무결성, 실제 Windows 화면·실행·저장/재개 검증
- [ ] 측정한 검증 결과와 한계 기록, 동일 PR 완료 후 병합

로컬 구조: `project-hora/개발`은 저장소와 빌드 도구, `project-hora/빌드`는 `AlphaExchange.exe`와 런타임·SQLite·그림 파일이다. 게임 저장은 사용자 LocalAppData 아래에서 보관해 빌드를 갱신해도 이어한다. Android의 전체 기록 ZIP은 PC에서 가져오기로 이어한다.
