# v1.8.0 성능 최적화 계획

요청: 기존 경제 관찰 게임의 성능을 최적화하고 설치 가능한 APK를 제공한다.

- 기준 소스: main `0ed09dc1d42572541d7c75668de4faa006009fe9`.
- 동일한 최대 인구 체크포인트와 고정 시드로 계산·저장·장기 조회를 측정한다.
- 실행 비용을 확인한 뒤 반복 계산, 할당, 화면 작업의 병목을 개선한다.
- 게임 분, 시간별 통계, 난수 순서, 현금·주식 원장과 기존 저장 호환성을 보존한다.
- 전후 최종 상태와 체결 결과를 대조하고 회계·저장·모바일 검사를 실행한다.
- Android ARM64/x86_64 APK를 빌드하고 네이티브 실행 검증과 서명을 확인한다.
- 앱 ID `com.alphaexchange.offline`과 등록된 정식 서명 인증서를 유지한다. 기존 개인키가 사용 가능한지 먼저 검증하며 정식 배포키 생성이나 등록 인증서 교체는 이 최적화 작업에 포함하지 않는다. 기본 SDK 테스트 빌드는 정식 릴리스와 구분한다.
- 결과와 한계를 원시 측정 자료 및 릴리스 안내에 기록한다. Linux 처리량을 휴대전화 FPS로 표현하지 않는다.

구현과 검증은 Draft PR에서 진행한다. 개발 브랜치에 APK나 서명 비밀을 커밋하지 않는다.

결과: 저장 시 할당 약33% 감소, 저장 포함100배속 처리량 약9% 증가. 동일 입력의 전체 상태·체결·난수 일치, 전체16시즌과 네이티브 Android 검사 및 합성5년 저장 검사를 통과했다. 장기 저장 검사 도구의 분 시계와 선거 예정 시간을 합성 시간에 맞춰 수정했으며 실제 게임의 검증 규칙은 유지한다. 사용자는 기존 서명키를 GitHub에 설정한 뒤 정식 APK를 받기로 선택했다. [최신 서명 확인](https://github.com/hddy774/project-hora/actions/runs/38129368694)에서는 설정이 비어 있어 정식 배포가 기존 키 등록을 기다리고 있다. 세부 지표와 한계는 `docs/performance/v1.8.0/README.md`에 기록한다.
