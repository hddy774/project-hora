# v1.8.0 새 서명키와 APK 제공

사용자는 기존 개인키가 없음을 확인한 뒤 새 서명키의 직접 생성·파일 전달·APK 생성을 요청했다. 기존 설치본은 필요 없으며 새 APK에서 새 게임으로 시작한다. 이 요청에 따라 이전 공개 인증서를 새 키의 인증서로 교체한다.

- 이미 검증한 v1.8.0 최적화 소스 `eb8e4f8`을 사용한다. 앱 ID `com.alphaexchange.offline`, 버전 1.8.0/코드9, 게임 규칙과 저장 형식을 유지한다.
- 새 RSA3072/SHA256 서명키를 PKCS12로 한 번 생성한다. 비밀번호는 안전한 난수로 만들고 명령행이나 로그에 출력하지 않는다.
- 개인키·비밀번호·GitHub Secrets 등록용 bundle을 사용자에게 제공할 비공개 ZIP으로 묶는다. 저장소·PR·Actions artifact·공개 릴리스에 포함하지 않는다.
- 공개 인증서 지문을 Draft PR에서 기록한다. 개인키로 CSR 서명이 가능한지 확인하고 APK의 실제 서명과 등록된 지문을 대조한다.
- 같은 소스로 Android ARM64/x86_64 APK를 빌드한다. 서명·패키지 ID·버전·ABI·최소 Android 버전·체크섬을 검사한다.
- 검증된 공개 설정을 main에 반영한 뒤 빌드 소스의 변경 불가능한 태그로 APK만 GitHub Releases에 게시하고, 게시한 파일의 체크섬을 다시 확인한다.
- GitHub에 서명 Secrets가 등록되었다고 주장하지 않는다. 사용자는 ZIP의 bundle을 직접 등록하거나 개인키를 보관해 이후 같은 키로 업데이트할 수 있다.
