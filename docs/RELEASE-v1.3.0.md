# v1.3.0 · 기업 가치와 이어지는 통계

기업의 생산과 현금 배당, 정부·거래소의 지출이 투자자에게 돌아오는 시장을 구현했습니다. 분야별 5개 회사, 총 30개 종목을 제공하고 매 게임 시간의 통계를 파일에 계속 보관합니다.

- 실제 배당·배당락·공매도 대체배당, 시즌 손익통산·손실 이월·세금 환급.
- 발행/상장/유동 주식·자사주·시가총액·액면가·EPS/PER/BPS/PBR·배당수익률, 분할·병합·주식 교환 합병, 납입 IPO/증자·자사주 매입/소각.
- 기업 이익·배당·거래 비용을 읽는 기관/개인 AI. 기존 10개 능력·성향·하락장 방어·공매도·대출·정책·작전 UI와 50/100배속 유지.
- 전체·시즌·전일·5/10/30/90일·1년·직접 지정 기간. 실제 시간 축의 가격/총수익 지수·시총·현금 그래프, 표·원형표와 기업 재무 5종.
- SQLite의 같은 트랜잭션으로 시간 기록·복원 상태·기업행동·결산·시즌 확정. 저장 병합에도 중간 시간 보존, 쓰기 실패 시 일시정지, 정상 백업 복구와 구버전 일별 파일 이전.
- 사용자 선택 위치에 게임·전체 통계·시장 CSV를 ZIP으로 내보내고 다른 설치에서 가져오기.

**설치 안내:** 요청하신 기존 서명키 없는 배포로 GitHub Actions가 새 일회용 키를 생성합니다. 이전 릴리스에 덮어쓸 수 없어 재설치가 필요하고 앱 삭제 시 내부 기록이 삭제됩니다. v1.3부터 파일 내보내기를 제공합니다. **v1.2에는 이 기능이 없으므로 별도로 확보하지 않은 이전 기록을 삭제 후 복구할 수 없습니다.** 생성 키는 실행 종료 시 제거되며 다음 새 키 빌드 역시 재설치가 필요합니다.

Android 8.0 이상 ARM64/x86_64, 완전 오프라인 관찰 게임입니다. 앱이 닫힌 동안 진행하지 않으며 강제 종료 시 미확정 진행과 기록은 함께 마지막 확정 시점으로 되돌아갈 수 있습니다. 긴 기간 그래프는 표시 지점만 축약하고 원기록은 보관합니다. 과거 구버전의 없는 시간 기록은 만들어 채우지 않습니다.

GitHub Actions가 병합 태그에서 APK를 빌드·서명하고 앱 ID/버전/인증서를 검사합니다. APK·소스·검증 보고서를 업로드한 뒤 다시 다운로드하여 SHA-256을 확인하고 최신 릴리스로 공개합니다. 실제 CI 결과는 CORE-CHECKS.txt, 서명 지문/빌드 소스는 SIGNING-INFO.txt, 검증 범위와 실제 기기 제한은 VERIFICATION.txt에 포함됩니다.
