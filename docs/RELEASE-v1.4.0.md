# v1.4.0 · 지분 구조와 성능 개선

회사별 지분 구성과 주요 기관 주주를 살펴볼 수 있습니다. 종목 상세의 **지분 구조** 버튼 또는 기업 재무 화면에서 열고, 회사 선택/이전/다음 버튼으로 다른 회사도 조회할 수 있습니다.

- 기관·개인·창업자·은행 보유·자사주 원형표와 보유 수량/보유자 수. 원형표는 발행 주식 기준, 표의 상장 지분율은 자사주를 제외한 상장 주식 기준입니다.
- 주요 기관 주주를 보유 주식 순으로 표시하고 대표 상세로 연결합니다. 개인은 합계로 표시합니다. 공매도 대여/예약은 별도 표시하여 지분에 이중 계산하지 않습니다.
- 재무 집계의 반복 객체 생성과 포지션 순회를 줄였습니다. 저장용 상태를 분리 복사하고 전체 JSON 직렬화는 백그라운드에서 수행합니다. 변화가 없는 자동 저장과 화면 밖 그래프 처리를 생략합니다.
- 전체 기간 통계의 극값 선택 쿼리에서 반복 범위 스캔을 줄였습니다. 원기록·실제 시간 축·누락 구간·구버전 일별 이력은 유지합니다.
- 기존 30개 회사, 100개 기관/10,000명 개인, 기관 능력·혼합 AI·공매도·은행·정책·기업행동·100배속과 ZIP 기록 내보내기/가져오기를 이어서 제공합니다.

첨부 파일은 **AlphaExchange-v1.4.0.apk 하나**입니다. APK 검사 로그와 성능 원자료는 저장소/Actions에 기록하며, APK 체크섬과 공개 인증서 지문은 이 릴리스 본문에 표시합니다.

**설치 안내:** 앞선 기존 서명키 없이 배포하라는 지시에 따라 새 임시 키로 서명합니다. 기존 앱에 덮어쓸 수 없습니다. **v1.3에서 기록을 ZIP으로 내보낸 뒤 앱 삭제·새 설치 후 가져오세요.** 앱 삭제는 내부 기록을 지우며, v1.2에는 내보내기 기능이 없습니다. Android 8.0 이상 ARM64/x86_64이며 완전 오프라인 게임입니다.
