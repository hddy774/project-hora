# v1.7.0 · 분 단위 경제와 200명의 인물

- 신규 시장은 시가총액1조, 투자사100곳 각10억, 개미1000집단에서 시작합니다. 개미 한 집단은1000명을 대표하고 실제 유입 자금에 따라 최대10000집단까지 성장합니다. 자사주50%/은행50%의 실제 주식을 거래합니다.
- 투자자100·경영자30·정치인50·금융인20명의 직무별 프로필과 개인 지갑을 제공합니다. 운영 법인·정부·은행의 자금과 개인 자금은 별도입니다. 기존100개 그림을 유지하고 원본 일러스트100개를 추가해 총200개를 제공하며 프로필에서 확대합니다.
- 기관 화면은 랭킹으로 바뀌고 하단에 인물 탭을 추가했습니다. 종합과 각 분야 상위3명을 표시합니다. 시즌 상대 투자 순위로1~10포인트를 지급하며51~100위도1포인트를 받습니다.
- 대표가 수석 분석가로6업종 기밀 리포트를 만들고 애널리스트·집행·포트폴리오·위험·준법·재무·거시·퀀트8직무 직원이 보조합니다. 투자 계획은 기간·상하한 가격·종목 예산과 위험 성향을 가지며 실제 호가·뉴스·가치에 따라 재평가합니다. 경쟁 기관 AI는 기밀 자료를 조회하지 못합니다.
- 시간 내 실제 분 시각에 체결하고 분 이내 진행·대기 시간·참여자 순서까지 저장합니다. 초단기1시간~1일 미만, 단기1~10일 미만, 장기10일 이상 계획은20일·30일 이상 보유도 허용합니다. 현금 목표5~30%, 실제 자금·담보·왕복 비용과 양방향 호가 원칙을 유지합니다.
- 기업은 실제 예산으로 사업을 진행하며 성과를 월 결산에 반영합니다. 자사주·은행·개미를 포함한 발행 지분의 상위3대 보유 투자사가 내부 사업을 봅니다. 모든 새 뉴스에는 실제 인물과 원인 활동이 있습니다.
- 양당 각25명이 경제 정부를 구성합니다. 정부·은행 수장은10~30일 간격의 선거로 바뀌며 새 정책·후원 법률은200명의 표결로 결정합니다. 종합 시즌 순위로1~10표를 받습니다. 개인 후원·법률 위반 벌금은 실제 개인 지갑에서 정산합니다.
- 통계의 개미 재무 옆에 기관 재무를 추가하고 전체 수치와 만·억·조 표기를 제공합니다. 과거 시간 통계·활동·표결·사업·개인 자금·기밀 계획을 파일과 ZIP에 보존합니다. 구형 시장의 잔액·주식 수·원기록과 향후 재출자 규모도 유지합니다.
- 장기 검사에서 발견한 재고 소진 뒤 과열을 수정했습니다. 은행은 공개 기업 가치로 실제 재고/현금 호가를 공급하고 개미는 평가차익에 단순 차익 실현으로 반응합니다. 모든 신규 현금과 실물 주식을 대조하며 특정 집단의 손실/이익을 강제로 만들지 않습니다.
- 시뮬레이션과 자동 저장 준비를 화면 밖 작업자로 옮기고 분마다 상태 잠금을 해제합니다. 주문 만료 큐, 열·희소 포지션 저장, 제한된 이미지/그래프 캐시와 장기 통계 조회를 개선했습니다. 같은 최대 인구 입력의 원장·난수·전체 상태 일치와 작업별 성능을 검증합니다. 전체10배 성능 개선을 달성했다고 주장하지 않으며 처리량·측정 조건과 남은 병목을 기록합니다.

공개 파일은 **AlphaExchange-v1.7.0.apk 하나**입니다. Android8.0 이상 ARM64/x86_64, 완전 오프라인입니다. [개발표](DEVELOPMENT-v1.7.0.md), [금융 조사](FINANCE-RESEARCH-v1.7.0.md), [저장 설계](STATISTICS-STORAGE-v1.7.0.md), [성능 근거](performance/v1.7.0/README.md)를 제공합니다.
