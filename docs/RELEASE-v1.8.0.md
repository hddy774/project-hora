# v1.8.0 · 저장 메모리와 기관 계산 최적화

- 자동 저장은 UTF-8 바이트를 직접 검증·압축·저장해 큰 문자열의 중복 생성을 줄입니다. 같은 최대 인구 입력의 저장 시 메모리 할당이 약 33% 감소했습니다.
- 기관의 투자 계획 반복 탐색과 보고서·직원 검사 중 임시 할당을 줄였습니다. 개미 저장의 빈 포지션과 능력 검사 비용도 줄였습니다.
- 같은 입력에서 저장을 포함한 100배속 처리량은 약 9% 높아졌습니다. 모든 처리 시간이 개선된 것은 아니며 [전후 원자료와 한계](performance/v1.8.0/README.md)를 공개합니다.
- 720시간 뒤 전체 상태·체결·난수를 대조했고, 16시즌 회계·저장 검사와 합성5년 기록의 쓰기·조회·복원·내보내기를 통과했습니다. Android에서 구형 통계·200명 그림·모달·백그라운드 정지·100배속을 검증했습니다.

앱 ID는 `com.alphaexchange.offline`, Android 버전 코드는 9입니다. Android 8.0 이상 ARM64/x86_64를 지원하며 저장 형식은 그대로 유지합니다.

## APK와 설치

정식 파일 이름은 **AlphaExchange-v1.8.0.apk**입니다. 사용자가 새 키의 직접 생성과 새 APK로 시작하는 것을 요청해 RSA3072/PKCS12 서명키를 생성했습니다. APK는 이 키로 서명하고 서명·앱 ID·버전·ABI·체크섬을 검사한 뒤 GitHub Releases에 게시합니다. 앱 ID는 그대로입니다.

이전 앱이 설치되어 있으면 삭제한 뒤 설치하세요. 처음 실행하면 새 게임으로 시작합니다. 이후 이 새 키를 계속 사용하면 v1.8.0 위에 업데이트할 수 있습니다. 이전 기록을 별도로 유지하려는 사용자는 삭제 전에 지원되는 버전의 **통계 → 전체 기록 ZIP 내보내기**를 사용해야 합니다.

새 인증서 SHA-256: `0832f24441f1caf335166fbc16ae0b9536e262ca48f258926a8027fc31dca25a`.

개인키·비밀번호·Actions 등록용 bundle은 사용자에게 별도 비공개 ZIP으로 전달합니다. 공개 릴리스에는 APK만 제공하며 ZIP을 공개 저장소에 올리지 않습니다. GitHub Secrets 등록은 별도이며 [같은 키 설정 안내](ANDROID-SIGNING-SETUP.md)를 따릅니다.
