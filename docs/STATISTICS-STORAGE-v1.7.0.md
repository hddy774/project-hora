# v1.7.0 분 상태·인물 기록 저장

게임 체크포인트는 버전 8이며 기존 SQLite 파일/ZIP 컨테이너 버전 5를 유지한다. 완료된 `CompletedHours`와 실제 `CompletedMinutes`를 함께 저장하고, 분 이내 진행·받아둔 미처리 분·현재 시간의 참여자 순서를 저장한다. 재시작은 같은 난수와 체결 순서를 이어간다. 과거 시간 통계를 분별 통계로 새로 만들지 않는다.

`runs.minute`는 같은 시간 안에서 더 오래된 분 체크포인트가 최신 상태를 덮어쓰지 못하게 한다. `hours`의 확정 JSON/해시는 다시 쓰지 않는다. 부분 시간에 새로 연결할 때 현재 미완료 시간을 확정 시간으로 저장하지 않으며, 초기·일별 원기록과 앞으로 완료되는 시간을 보존한다.

`activities`와 `world_votes`는 인물 활동과 200명 각각의 표결을 체크섬과 함께 보관한다. 화면 목록의 240개 활동/32개 표결 제한과 파일의 영속 기록은 별도다. 보고서·투자 계획·고용 직무·개인 자금 흐름·사업 상태·투표권은 체크포인트와 함께 동결한다. 동결한 객체에 이후 게임 변경이 침투하지 않는지 검사한다.

ZIP은 전체 데이터베이스를 포함하므로 새 테이블과 부분 분, 기존 기업행동·주총·파산·재무제표·시즌·시간 통계가 함께 이동한다. 외부 파일 해시·크기·앱 ID와 체크포인트를 검사하고 원본을 보존하며 가져온다. 분이 아닌 시간 단위 시장 CSV의 형식은 유지한다.

버전 2~7을 불러올 때 잔액·실물 주식·이전 손익과 확정 통계를 확대하거나 초기화하지 않는다. 이전 시간 진행과 대기 시간은 미처리 분으로 옮긴다. 새 인물의 개인 지갑은 0원부터 시작해 이후 실제 보수를 받는다. 신규 게임의 1조 시장과 10억 투자사 자금은 신규 게임에 적용한다.

## 저장·조회 최적화

개미 집단은 `retail-columns-1` 형식으로 저장한다. 같은 열의 동일 값은 한 번, 그 외 값은 타입별 배열로 보관하며 주식/원가/예약은 집단·종목·값 좌표로 기록한다. 모든 금융 값과 체결 재현 정보를 유지한다. 기존v8 행 배열과v2~v7도 읽는다. 잘못된 집단 수, 알 수 없는 열, 중복/범위 밖 포지션은 거부한다.

긴 그래프는 경량 헤더를 한 번 읽어 구간 경계와 각 지표의 최초 최솟값/최댓값을 선택한다. 선택 원본을 체크섬 검증 후 읽으며 원본 행은 삭제하지 않는다. 완전한 시간별 구간은 주키·행 수로 증명하고, 누락/혼합 해상도는 정밀 검사를 수행한다. 제한된3개 조회 캐시는 DB/WAL 파일 변경과 미저장 기록 변경에 무효화되며 호출자에는 별도 복사본을 돌려준다.

구형 시장의 향후 파산 재출자는 기존 초기 자산 규모를 사용한다. 신규 게임의10억 출발 자금으로 구형 시장의 다음 세대를 확대하지 않는다.
