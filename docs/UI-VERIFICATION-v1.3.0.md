# v1.3.0 Android 실행 검증

API 26 x86_64 소프트웨어 에뮬레이터에 개발 서명 Release APK를 설치했다. 실제 남아 있던 v1.2/v4 저장을 읽어 30개 회사로 이전하고 기존 시즌 1의 DAY 2를 이어서 열었다. 시작 화면, v1.3.0 배지, 30개 회사 표시, 기관 자산과 호가 목록, 일시정지 화면을 확인했다.

SQLite의 ARM64/x86_64 네이티브 라이브러리가 APK에 포함되어 있으며, 코어에서 파일 내보내기/다른 설치 가져오기·해시·전체 시간 기록·상태 일치를 검증했다. 기기의 파일 선택과 추가 화면 조작 결과는 최종 확인 뒤 아래에 기록한다.

소프트웨어 에뮬레이터의 부팅/화면 크기 변경 때 System UI ANR이 발생하여 닫고 재개했다. 이는 실기기 처리량 측정이 아니다. 물리 ARM64 기기 및 최신 Android에서 전체 화면·FPS·RAM·커밋 지연은 이번 검증에 포함하지 않았다.
