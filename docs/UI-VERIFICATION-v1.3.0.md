# v1.3.0 Android 실행 검증

API 26 x86_64 소프트웨어 에뮬레이터에 개발 서명 Release APK(버전 1.3.0, 코드 4)를 설치했다. 실제 남아 있던 v1.2/v4 저장을 읽어 30개 회사로 이전하고 기존 시즌 1의 DAY 2를 이어서 열었다. 시작 화면, 버전 배지, 30개 회사 표시, 기관 자산과 호가 목록, 일시정지 및 통계 화면을 확인했다.

통계 화면에서 시즌·전체·전일·5/10/30/90일·1년·지정 기간의 9개 선택 버튼과 시장 지표를 확인했다. 시작 화면의 가져오기 버튼으로 Android DocumentsUI의 기본 파일 선택 화면(OpenDocument)이 열리는 것을 확인했다. 파일 선택을 취소하고 앱으로 돌아왔다. 이 실행 확인에서 파일 선택 후 실제 ZIP 복원이나 모든 화면의 조작을 자동화하지는 않았다.

SQLite의 ARM64/x86_64 네이티브 라이브러리가 APK에 포함되어 있다. 코어 검사에서는 일관된 DB/매니페스트/전체 CSV 내보내기, 다른 설치 디렉터리로 가져오기, 해시·전체 시간 기록·상태 일치, 가져오기 직후 복구용 백업, 원본 보존, 실패 시 기존 기록 유지까지 검증했다.

소프트웨어 에뮬레이터의 부팅/화면 크기 변경 때 System UI ANR이 발생하여 닫고 재개했다. 이는 실기기 처리량 측정이 아니다. 물리 ARM64 기기 및 최신 Android에서 전체 화면·FPS·RAM·커밋 지연은 이번 검증에 포함하지 않았다.
