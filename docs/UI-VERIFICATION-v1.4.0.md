원형표에서 0인 범주를 걸러낸 뒤 색상 순번을 다시 정하는 표시 문제를 발견하여, 원래 범주 순번을 유지하도록 수정했다. 원형표와 보유 유형 표는 같은 범주의 색을 사용한다. 수정 후 Android Release 빌드도 0오류로 통과했다. 수정 APK를 같은 테스트 인증서로 다시 설치해 기존 시장 이어하기를 확인했고, S1 D2 15시의 NOVA 원형표에서 은행 보유가 표와 같은 주황색으로 표시되는 것을 재확인했다.

이 환경에서는 에뮬레이터 부팅 중 SystemUI 응답 지연 팝업이 발생했고 닫은 뒤 확인을 진행했다. 앱 crash 버퍼는 비어 있었다. 소프트웨어 에뮬레이터의 부팅/렌더링 지연은 물리 기기 FPS나 저장 지연의 측정값으로 사용하지 않는다. ARM64 실제 기기, 다른 화면 크기와 최신 API의 전체 UI 검증은 이번 관찰 범위에 포함되지 않는다.

분할/병합/증자/자사주/공매도가 발생한 지분 계산, 저장용 복사 분리와 동시 월말 정산, 조회 극값·누락 구간, 과거 저장 형식 호환성은 엔진 표적 검사와 전체 CI에서 별도로 검증했다. 에뮬레이터에서 해당 경제 이벤트를 모두 재현했다는 뜻은 아니다.
