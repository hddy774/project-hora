업그레이드 실행에서 이전 통계 JSON을 새 필드가 포함된 형식으로 재기록하여 체크섬 충돌이 발생하는 문제를 발견했다. `GameStore.Attach`가 이미 확정된 시간별·일별 키를 한 번 조회하고 빠진 초기 기록만 대기열에 넣도록 수정했다. 서로 다른 통계를 같은 키에 쓰려는 명시적 요청의 차단은 유지한다.

수정 APK를 다시 설치하고 같은 기존 시장을 이어 진행했다. 실제 Android 파일의 체크포인트가 **39→45시간**으로 진행하며 **기존 통계 12개의 체크섬이 모두 유지**되고 40~45시간 6개 기록이 추가됐다. 파일 복사본의 `PRAGMA integrity_check=ok`, 상태 1개/통계 18개의 Brotli 해제 SHA-256 일치, 현금 차이 0, 4,902개 매칭을 확인했다. 원래 없던 1~23/25~29시간 기록을 만들어 채우지 않는다. 같은 문제가 발생하는 v5 SQLite와 v5/v6 혼합 ZIP의 즉시 저장·연속 저장·충돌 롤백을 자동 회귀에 추가했다.

분야 선택 시 스크롤을 0으로 초기화해 목록이 가려지는 동작도 발견하여, 탭/목록을 보던 위치를 유지하도록 수정했다. 회사별 선택은 기존처럼 새 회사의 첫 내용을 보여준다.

새 시장의 최종 Android DB도 검사했다. 이전 시장 50시간과 새 시장 349시간의 체크포인트 2개, 통계 **389행**(이전 24/신규 365), 마감 72시간의 주총 **90건**이 보존된다. 두 체크포인트와 모든 통계의 Brotli 해제 SHA-256이 일치하고 무결성은 `ok`, 현재 시장 시스템 현금 차이는 0, 실제 매칭은 63,280건이다. 새 시장의 0~349시간 시간별 기록 350개와 15개 일별 기록은 모두 남는다.

에뮬레이터 부팅 중 SystemUI/시스템 응답 지연 팝업이 발생해 닫은 뒤 진행했다. 앱 crash 버퍼는 비어 있었다. 이 환경의 로딩/렌더링/저장 지연은 물리 기기 FPS·RAM·100배속 처리량의 측정값으로 사용하지 않는다. ARM64 실제 기기와 여러 화면 크기의 전체 UI 검증은 이번 범위에 포함되지 않는다. 파산 72건, 의결 가결/부결·실제 월말 경영 효과, 원본 기록 극값·누락 검출은 엔진/SQLite 검사로 별도 검증한다.
