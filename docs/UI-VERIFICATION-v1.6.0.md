# v1.6.0 Android 화면·이전 기록 검증

2026-10-05 UTC, API26 x86_64 소프트웨어 에뮬레이터(1080×1920). 최종 코드 `c1d9e063`, 앱 ID `com.alphaexchange.offline`, 버전 1.6.0/코드7. 기존 개발용 서명으로 로컬 APK를 덮어써 앱 데이터 이전을 검사했다. 공개 릴리스는 요청대로 새 임시 키이므로 사용자는 ZIP 내보내기·재설치·가져오기를 해야 한다. 이 실행은 ARM64 실기기 FPS 측정이 아니다.

## 기존 저장의 실제 Android 이어하기

원본 v1.5 DB에는 두 시장이 50시간/351시간과 총391행(시간별/일별)으로 보관돼 있다. v1.6으로 이어하기 후 실제 기기 실행으로 408시간까지 진행했다. 100배속 선택·관찰 재개/일시정지·화면 이동·홈 이동 저장을 확인했다.

- **두 시장 모두 보존:** 50시간/408시간, 총451행. 기존391행의 `(run,hour,resolution)`과 SHA-256 모두 동일하다. 새57시간과3일별 기록, 총60행이 추가됐다.
- 두 체크포인트와451행을 Brotli로 복원해 SHA-256을 검증했다. SQLite `integrity_check=ok`.
- 모든 투자자의 현금흐름·자본변동 대조 통과, 시스템 현금 차이0, 누적 체결75,339건.
- 실제 직원200명, 현재 성장 포인트0(첫 시즌 진행 중), 지급 급여/채용비 합계1,586,800원. 현재 목표7.8~25.2%, 실제 양방향 종목17개.
- 확정된 과거 JSON을 새 형식으로 덮어쓰지 않았다. 과거 능력/기록 없는 매수 시각은 이전 표시로 보관한다. 원본은 별도 호스트 복사본으로 유지했다.

검증 복사본은 `/workspace/toolchain/v160-device-before-files`와 `v160-device-final-native`, 결과는 `v160-final-native-verify.log`다. 이 경로는 작업 환경의 확인 자료이며 앱이나 공개 릴리스에 포함하지 않는다.

## 시즌 성장 확인용 분리된 데스크톱 자료

실제 Android 저장352시간의 별도 복사본을 최종 Core로730시간까지 진행하고 SQLite에 저장했다. **Android가730시간을 직접 시뮬레이션한 결과로 표현하지 않는다.** 두 시장·786행, 기존391해시 보존, 현금 차이0, 직원200명·배분334P, 시즌1의 실제 보상100건/양수50건을 검사했다. 이 복사본을 같은 에뮬레이터로 읽어 시즌 후 화면을 확인한다. 원본 Android 진행451행은 별도로 보존한다.

## 범위와 개선 기록

양방향 주문은 실제 현금·실물 주식을 필요로 한다. 장기 분석에서 유통 물량 부족으로 한쪽 잔량과 현금 목표가 충족되지 않는 경우는 [경제 분석](analysis/v1.6.0/README.md)에 기록했다. 이번 확인은 정상 공급의 화면·실제 예약·기존 기록 이전을 검증한다. 저장용 복사/직렬화 비용 증가와 동일 입력 성능 수치는 [성능 결과](performance/v1.6.0/README.md)에 따로 남겼다.
