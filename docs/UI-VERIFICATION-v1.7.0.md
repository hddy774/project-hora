# v1.7.0 Android 화면·복원 검증

GitHub Actions의 KVM 가속 Android API26/AOSP/x86_64 에뮬레이터에 실제 Release APK를 설치했다. [실행 37312498876](https://github.com/hddy774/project-hora/actions/runs/37312498876)의 Android 작업 111771084005이 통과했으며, 검증 대상 커밋은 `0b79cd5aaad9e172285c77cd3a82bb7b870dab65`다. [기기 결과 JSON](verification/v1.7.0/native-smoke.json)에 원기록/화면 영역/실제100배속 결과를 보관한다. 화면 원본 15장과 원 SQLite는 해당 실행의 `v170-native-smoke` Actions 아티팩트에14일 보관한다. 공개 릴리스는 APK만 제공한다.

실제 v1.6.0 태그의 엔진으로 만든 **Version7/완료168시간/개미10000개/통계177행** 파일을 기기에 옮겼다. 로비의 기존 시즌을 이어가 **Version8/200명/완료522시간**까지 실제 앱에서 진행하고 저장했다. 기존177행의 해시와 RunId가 모두 같고 새 시간 기록이 연속이다. 현재 엔진으로 기기 SQLite를 다시 불러와 원장 현금 차이0, 개미10000개, 기존 기관 초기1000만원의 이전 규모와 전체 시간 연속성을 확인했다. 새 시장 생성으로 구형 복원을 대체하지 않았다.

실제100배속 시험은 41.306초 일시정지 후 재개했고 19.013초 측정 구간에서 게임21,095분을 완료했고 대기는265분이었다. 입력/체크포인트 경계에2초의 여유를 둔 최소1200게임분/초와 대기1200분 이하 조건을 검사했다. 이 짧은 기기 시험은 장기 최대 인구의 [저장 포함100배속 처리량](performance/v1.7.0/README.md)과 별도다. 가속 x86_64 에뮬레이터 결과이며 물리 휴대전화 FPS나 모든 기기의 속도를 보장하지 않는다.

실제 시뮬레이션과 자동 저장 준비/큰 파일 불러오기는 화면 밖에서 처리하고 분마다 상태 잠금을 해제한다. 불러오는 동안 새 시장 생성/덮어쓰기를 막고 실패 시 원본을 보존한다. 시험 도구는 실제 앱 뷰의 화면 영역을 읽어 상태/탐색 바가 다른 기기도 다루며 시작 중 화면 정보가 없으면 제한 시간 내 다시 확인한다. 일시정지 시간이 저장 지연으로 오인되는 문제를 실제 쓰기 시작 시각의 감시로 고쳤고, 입력/저장 복사도 같은 상태 잠금으로 보호한다. 장기 일시정지 후 재개·진짜 쓰기 지연·완료/새 체크포인트의 감시 회귀8개와 네이티브 재개 조건을 추가했다. 게임 로직이나 시스템 서비스를 우회해 통과시키지 않는다.

이 작업 공간의 KVM 없는 소프트웨어 에뮬레이터에서도 별도로 v1.6 기기 원본(완료408시간/451행)을 보관하고 DAY18/분00:30·03:32 표시를 확인했다. 그 환경은 Android System UI/시스템 프로세스 응답 지연이 있어 최종 전체 화면 통과 근거로 쓰지 않았다. 위 완료 검사는 독립된 GitHub 가속 에뮬레이터의 실제 파일/화면 결과다. 기기 초기화나 네트워크 비활성화는 시험 도구의 시험 기기 설정이며 사용자 기기의 서비스를 바꾸는 앱 기능은 없다.
