# v1.7.0 Android 화면·복원 검증

Android API26/x86_64 소프트웨어 에뮬레이터에 실제 Release APK를 설치하고 v1.6.0 기기의 저장 파일과 통계를 복사해 검사한다. 새 일회성 키의 공식 APK는 GitHub Actions 태그 소스로 별도 검증한다. 로컬 기기 APK의 개발용 서명과 공식 배포 서명을 혼동하지 않는다.

v1.6.0 기기 원본은 완료408시간/통계451행이며 그대로 별도 보관했다. 초기 실행에서 기존 DAY18 시장을 읽고 분00:30,03:32 등 부분 시간 거래/저장을 표시했다. 새 시장을 초기화한 결과로 구형 기록 이어가기를 대체하지 않는다. 원행 해시 대조와 재시작은 최종 기기 파일에서 확인해 아래 표를 완료한다.

| 확인 항목 | 상태 |
|---|---|
| 실제 APK 설치·오프라인 실행·기존 DAY18 시장 이어가기 | 1차 확인 |
| 기존 시간 원행 해시 보존·새 시간 추가·부분 시간 재시작 | 최종 대조 중 |
| 7개 하단 탭·인물200·4분야·상위3명 | 최종 화면 확인 중 |
| 신규 경영자/정치인/금융인 그림·비율 유지 확대 | 최종 화면 확인 중 |
| 기밀 계획/직원·기관 재무/기간 그래프·양방향 호가 | 최종 화면 확인 중 |
| 최종 태그 APK의 버전/ABI/자산/권한/서명 | Actions 배포 단계에서 확인 |

실제 시뮬레이션과 자동 저장 준비를 화면 밖에서 처리하고 분마다 잠금을 해제한다. 큰 저장 불러오기도 화면 밖으로 옮겨 불러오기 표시를 제공한다. 불러오는 동안 새 시장 생성/파일 덮어쓰기를 막으며 실패 시 원본을 보존하고 복원 파일을 가져올 수 있다. 인물/정부/사업 등의 하위 화면에서 뒤로 가면 관련 목록으로 돌아간다.

이 환경에는 KVM이 없어 소프트웨어CPU/GPU로 실행한다. Android System UI/시스템 프로세스 자체가 응답하지 않는 부팅이 있었고 첫 시작/기기 입력도 느렸다. 시스템 서비스 대기를 앱의 FPS/ANR로 오인하거나 실제 휴대전화100배속을 보장하는 근거로 사용하지 않는다. 깨끗한720×1280 시험 기기로 기존 파일을 다시 옮기고, Google 백그라운드 앱을 비활성화·네트워크를 끈 시험 조건으로 기능 확인을 계속한다. 사용자 기기의 서비스 설정을 바꾸는 기능은 APK에 없다.
