## 이전 버전과 범위

v1.10(`43c61d4`)의 동일 시드 20261004·42, 12시즌 관측에서는 기관 파산이 각각 807회·371회였고 기관 매매손익은 −28,284.39억·−9,028.28억 원이었다. 세대 교체를 포함한 누적 파산 횟수다. 원자료는 `v1.10-summary.json`, `v1.10-monthly.csv`이다. v1.11 최초 구현 `0cd7a25` 자료도 별도로 보존했다.

초기 기관 자산이 10억에서 100억으로 바뀌었고 가격 제한·호가·회사 사건·포트폴리오 정책도 함께 변경됐다. 따라서 이전 버전과의 손익 차이를 캐시 최적화 또는 특정 AI 변경 하나의 효과라고 해석하지 않는다. 반복 시드의 파산 감소가 모든 시드·장기 수익을 보장하지 않는다.

이전 도구의 `zero-fee` 시나리오는 월말에 수수료를 0으로 재설정하지만 중간 정책 사건이 수수료를 바꿀 수 있다. 이번 결론에는 그 시나리오를 사용하지 않았으며 최종 실행은 `--standard-only`로 제외했다. 원자료의 `baselineReferenceCommit`은 과거 도구에 고정된 역사 메타데이터다. 이번 실행의 실제 소스·명령은 `provenance.json`을 기준으로 한다.
