저장소의 `tools/MarketAudit`를 .NET SDK 9.0.318로 Release 컴파일하고 다시 실행했다. 원자료 CSV가 바이트 단위로 일치했고 JSON 요약의 모든 재무/종목 값이 실행 시간 필드를 제외하고 일치했다. 재실행 로그의 6개 시나리오 합산 시간은 97.10초, 최초 실행은 79.69초였다. 성능 비교 실험은 아니므로 Android의 100배속 지원 근거로 사용하지 않는다.

두 실행 모두 222개 시점의 현금·실물 주식 대조를 통과했다. 시간마다 모든 장부·주문 조건을 검사하지는 않았다. 분석 도구는 디스크 시즌 보관을 생략하고 UI·종료 복구·향후 SQLite 저장 기능은 검증하지 않는다.

회사 제안 CSV는 30개 고유 ID/심벌, 6분야 각각 5개, 기존 10개 이름·심벌·분야 보존을 검사했다. 문서의 내부 파일 링크와 그래프 생성, 변경 파일 공백 검사를 통과했다. CLI 실행 출력과 빌드 결과는 gitignore 대상 `artifacts/`·`bin/`·`obj/`에 두고 PR에 APK·키·빌드 출력을 넣지 않는다.
