# v1.5.0 2년 시장 분석

24시즌(게임 720일), 기본 세 시드와 첫 시드의 수수료 0 대조군이다. 기관/개인의 **투자 손익**은 실현/평가·배당·비용·세금·이자·보조금·벌금을 포함하고 임금/소비/재출자를 제외한다. 이전 세대의 확정 손실을 더한다. 거래 이익을 강제로 배분하지 않고 실제 호가 체결로 결정한다.

세 기본 시드 모두 기관 손익은 양수, 개인은 음수였다. 은행·기업·거래소·정부와도 현금이 이동하므로 개인 손실 전부가 기관 이익은 아니다. 이 시드/기간 결과를 모든 시장의 수익 보장으로 일반화하지 않는다. 자연 파산은 0이며, 회사·기관·개인의 파산/교체는 별도 72건 스트레스 회귀에서 검사한다.

시가총액에는 자사주 확대에 따른 상장 주식 감소가 포함된다. 상장·증자·자사주 변화 효과를 조정한 가격 지수와 배당 포함 총수익 지수를 함께 보관하므로 시가총액만으로 투자 수익을 판단하지 않는다. 일부 하락 시즌과 순자산 손실은 정상 경제 사건이다.

모든 완료 시간의 기관/개인 손익 유한값, 월말 투자자별 현금흐름/자본 대조, 전체 시스템 현금 차이 0, 물리 주식 보존을 검사했다. 실행 시간은 동시 빌드/소프트웨어 에뮬레이터 준비가 섞여 있으므로 성능 측정에 사용하지 않는다.
