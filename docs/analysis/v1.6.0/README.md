## 남은 개선 대상

1. **현금 목표와 실제 비중:** 최종 월말 목표는 약 9~28%로 5~30% 범위 안이지만 12시즌 끝의 실제 비중은 네 시나리오 모두 100개 기관이 30%를 초과했다. 신규 투자자 현금 20억 원과 초기 실물 유통 주식 약 9.8억 원의 규모 차이, 회사 자사주 매입과 장기 보유, 가격 안전 기준 때문에 전 기관의 동시 저현금 배치가 어렵다. 이번 버전은 목표/실제와 주문 가능 현금을 구분한다. 다음 작업은 충분한 실제 납입 수요가 있는 증자/공모와 유통 물량·기관별 배치율을 함께 평가하는 것이다. 현금이나 주식을 만들어 강제로 비중을 맞추지 않는다.
2. **장기 시장의 호가 공급:** 자금이 있는 은행도 보유 주식이 없으면 매도 잔량을 제공할 수 없다. 기본 세 시나리오의 최종 월말 양방향 종목은 0개, 수수료 0은 1개다. 초기 정상 시장과 기존 Android 이어하기에서는 양방향 호가가 확인되지만 항상 양쪽을 보장하지 않는다. 회사의 합법적인 신주 공급·유통 부족과 자사주 정책의 상호작용을 후속 검증하고, 양방향 시간 비율·최장 잔량 공백을 지표로 추가할 필요가 있다.
3. **기관의 순수익:** 기본 수수료 시나리오는 기관도 손실이므로 기관 이익을 보장한다고 표현하지 않는다. 가치·보유 기간·급여 예산 판단은 개선했고 개인의 기초 분석은 추가하지 않았다. 후속 작업은 거래 회전·스프레드·수수료·배당·직원 비용을 나눠 기관의 거래별 순기대손익과 장기 가격 발견을 보정하는 것이다.
4. **범위:** 12시즌·세 시드 결과가 모든 정책/경기/초기 조건의 안정성을 보장하지 않는다. 회계 정확성을 유지하면서 더 긴 시나리오·급락/공급 제한 조건을 조사해야 한다. 성능 비용과 저장/복원 정확성도 함께 검토한다.
