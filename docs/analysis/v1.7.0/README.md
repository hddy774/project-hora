# v1.7.0 경제 검증

기능을 모두 구현한 뒤 검증에서 은행 재고 소진·추격 매수의 양의 피드백을 발견했다. 보정 전 12시즌 시총은 시드20261004/42/17에서 각각108.36/74.05/90.86조 원까지 늘었지만 기업 월 순이익은 약90~100억 원이었다. 개미의 거대한 평가이익은 사업 성장으로 설명되지 않았고 호가 양쪽이 사라졌다. [보정 전 원자료](feature-first/summary.json)와 [월말 표](feature-first/monthly.csv)를 보관한다.

은행의 과열 호가를 마지막 거래 가격의 일정 할인에서 공개 기업 가치에 근거한 가격으로 바꿨다. 실제 재고·대여 예약·현금 완충을 사용하는 지정가 주문이며 시장 가격을 직접 덮어쓰지 않는다. 시간 종료 후 보충은 계속 수동 호가로만 처리해 이미 계산한 결산·수익률을 뒤바꾸지 않는다.

개미는 가격·거래량과 자기 매수 원가에 대한 단순 차익 실현으로 반응한다. 재무제표·기밀 보고서·기관의 포트폴리오 분석을 읽지 않는다. 상승에도 일부 보유자가 실제 매도하므로 은행이 재고를 회수하고 시장에 다시 공급한다. 반응 강도·차익 실현 기준은 `world-v1.json`에 기록하며 현금·재고가 없으면 주문을 만들지 않는다.

## 12시즌 보정 검사

[요약](balanced-12-seasons/summary.json), [월말 CSV](balanced-12-seasons/monthly.csv). 시작 개미1000집단은 실제 경제 자금으로 최대10000집단까지 증가한다. 각 시작/월말마다 시스템 현금 차이0, 실물 주식 수 차이0, 투자자 현금흐름/손익 등식을 검사했다. 월말0시의 계절 교체와 회사 자사주 정책이 포함된다.

| 수수료0·20261004 | 9735억 | 1236.34 | 1259.13 | 261.03억 | 1247.73억 |

시총은 가격×(발행 주식−자사주)다. 자사주 매입/소각으로 유통 주식이 줄면 가격/배당 포함 지수가 상승해도 시총은 줄 수 있다. 시총만을 투자자의 손익으로 해석하지 않는다. 기관 초기 자본은1000억, 개미는 초기5000억에 최대4.5조의 실제 신규 납입이 더해진다. 집단 전체 순이익의 크기를 자본 규모가 다른 집단의 수익률처럼 비교하지 않는다. 급여·신규 납입·소비·후원·직원 비용을 수익과 구분한다.

기관 수익을 보장하거나 개미의 현금·주식을 빼앗는 코드가 없다. 표는 특정 시드의 결과이고 하락 구간과 손실도 존재한다. 배당·사업·임금·정책·자금 유입의 회계 경로가 작동하며 주식 거래만을 제로섬 전체 경제로 취급하지 않는다. 수수료0 사례는 시즌마다 정책 수수료를0으로 설정하는 대조 실험이며 난수 경로가 바뀌므로 차이를 수수료의 순수 인과 효과로 주장하지 않는다.

36시즌·3시드/수수료0 장기 검사도 진행하고 완료 원자료를 이 경로에 추가한다. 전체 회귀·저장 복원·성능 검사는 별도 근거이며 이 도구의 종료 코드만으로 모든 기능이 검증됐다고 표현하지 않는다.
