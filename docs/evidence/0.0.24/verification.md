## 저장·메모리

- 전체 suite의 10,000명 SQLite 표본은 payload 6.06MiB, 저장/복원 중앙값
  1,312/1,347ms였다. 1초 권고는 **FAIL**이며 기능 차단 기준은 아니지만 후속 streaming
  codec 최적화 대상으로 유지한다.
- 저장 live managed peak는 기존 container 400.75MiB 대비 SQLite 17.33MiB로
  **95.7% 감소**해 30% 절감 예산을 통과했다.
- 개인 최근 로그는 100행 뒤 10,000회 덮어쓰기 allocation 0이며, 비관심 연대기는
  100건·종합본 100권으로 보관량이 제한된다.
- 완결 종합본 목록은 초기 capacity 4에서 필요할 때만 8·16·32·64·100으로 확장한다.
- 저장·복원 후 heap 768MiB 또는 fragmentation 256MiB 이상에서만 조건부 LOH 압축을
  실행한다. 경계는 `PC_TEMP_REVIEW-024`로 유지한다.
