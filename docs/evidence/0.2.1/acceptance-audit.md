# 0.2.1 수용 감사 갱신

감사 기준은 `codex/v0.2.1`의 `f9c574a13ac73416ea517bea5e60845b29799194`다. 개정6 로컬 Notion 원문·개정7 결정·111개 작업과55개 V020 대응을 실제 소스·공개 명령 시험·기존 보고서에 대조했다. 원장/Notion 상태를 수정하지 않았으며 새 게임·성능·성장·장기 실행 시험을 실행하지 않았다.

최신 저장된 전체 기능 보고서는 [functional-integration-9724d5f.json](functional-integration-9724d5f.json)의 **195/195**, 정확한 소스 `9724d5f`다. 후속 기능 PR의 선택 통과를 이 숫자에 합쳐 최신 전체 통과로 부르지 않는다.

## 남은 실제 기능과 통합 조건

- **M05 비경 입장:** 정본259–279행은 현지 탐색과 별도 입장, 개방/자격/수용·경쟁/준비/진척/귀환·실패/유한 선점을 요구한다. 현재 `Explore`의 이웃 공개·봉인 가능성·일회 약초3개만으로 이 계약을 충족하지 못한다. root가 실제 Exploration 모듈·공통 hook·UI를 배정했다. 100지점을 늘리거나 별도 전투 엔진을 만들 요구는 아니다.
- **F04/개인 수신 기록:** PR127 `e649506`은 실제 출생→식량/시간 돌봄→양측 수업→재원/합의 입양→성년 분가→자연사 후 개인 유산·채권과 옛 가계 직책의 다른 승계를 포함해 선택27/27이다. 감사 기준에는 아직 병합되지 않았다.
- **H10:** 엄격한 typed action 소유/몸/예약 검증과 이전 무료 진척 경로 제거·보관이 진행 중이다. 담당 focused4/4 보고는 있으나 새 비경 prefix까지 병합·연결 후 대조해야 한다.
- **UI:** PR124의 실제 세션+compat자산1280/390 전체 사회 흐름과 query9/9는 있다. 숫자 enum 표기, 실제 수행 선택/취소/완료, 법칙 export/잘못된 import, save→play→load scope 확인은 작은 후속 작업이다. native bridge replay는 실제 Android/Windows 패키지 실행과 구별한다.

그 뒤 남는 것은 최신 한 소스의 전체 기능/불변식/저장·결정론, 실제 플랫폼 실행, 최종 측정/개발 보정,111/55 원장·문서·Notion·VERSION·서명/릴리스 근거 대조다. 이 감사는 M05까지 구현되기 전에 기능 전체 완료를 선언하지 않는다.

## 성능 기준의 정본 해석

V021-T04는 인구 단계별 측정·분포/장기 안정·장치/런타임 구분을 요구한다. 정본1936행은10,000규모 검증을 요구하지만1940행은 “허용 회귀율·메모리·저장 크기는 실제 기준선과 인구 단계별 측정 뒤 정”하며2072행도 “숫자 예산은 측정 후 명시”라고 한다.2205행의 T04 수용에는7200개월/60초/100배속 고정값이 없다. 정확한100배속60초는2292행의 보존된 **V020-G03 제목**과 T04 대응에 있고, 대응 설명은 “초기2명, 성장후대규모성능시나리오”다.

따라서 이 숫자는 보존할 이전 비교 목표이며 개정6에서 새로 확정한 수치 합격 조건으로 격상하지 않는다. 현재 `verify-v021-release.py:186`이10000생존·7200개월·60초이내·100배속을 강제하는 것은 더 엄격한 구현 정책이다. root가 실제 최종 측정과 명시한 한계/채택·기각 근거로 정합화해야 한다. 기존 실패는 숨기지 않는다: `soak.json`은131/7200개월,60.343초,1.809배속,`passed:false`이며 출생·식량·재해를 끈 합성 fixture다. 새 세계/Android 통과가 아니다.

H04/H06/H09의 정확성/비용·인덱스·배치/연구 판단과 성장 분포는 사용자 지시대로 모든 기능 뒤 최종 단계다. Unity 실행·네이티브/SIMD 채택·프로젝트 전면 재분리를 새 선행 조건으로 만들지 않는다.
