[cognition-review.json](cognition-review.json)에 원문 SHA256·고정 URL·실제 법칙/개수·10개 검토 파일의 SHA/blob/호출 줄·기능 검사 29개의 정확한 Name이 있다. 인지 투영은 개인 명제/관측/결정/계획/요청/습성/일지/숙련 미러, 원천 관측/감정, 개인 관측 이력과 지식/실습의 비압축 UTF-8 JSON 길이다. 육신·유전체·실물·세계 연대기는 제외하며 객체별 heap 크기로 바꾸지 않는다. 전체 저장은 `GameCodec.Encode`의 값으로 실제 파일 봉투·디스크 압축 측정과 구분한다.

통합 예산은 명제+현재 평판 주장+인물 관측+지점 관측+원천 관측의 합이다. `KnownPeople/KnownPlaces` 식별자와 실제 학습/이력 전체는 이48칸과다르다. 실제10,000명 표에서 KnownPeople 최대68도보존했다. 모든필드가48개이하라거나12개월측정이평생메모리상한을증명한다고쓰지않는다.

명제는 논리월 만료, 원천 관측은 개인별 최신값과 TTL을 사용한다. 통합 퇴출은 월·우선순위·종류·ordinal key의 안정 순서다. 실제 결과의 `plan:completed/lastFailure` 요약, 완료 습성 집계와 상세 최근 창을 분리하며 source를 남긴다. 네규모 표의원천관측은0이므로, 이표자체가대규모paid탐색·모든TTL경계를실행했다는근거는아니다. 별도공개관측/교정/저장·비간섭기능사례를함께연결한다.

기본성능예산에서확인된N100 p95와10k query FAIL은없애지않는다. 이표는L04의실제인지/저장근거이며고정비용예산합격표가아니다. 이후PGOoff·새4규모·장기결과는root의별도소스/보고서로판정한다.

## L05의 실제 공개 경로와 남는 입력

af91 전체314원문에서다음 실제경로를확인했다. 정확한 Name은cognition-review의functionalEvidence에있다.

- `AgentCultivationIntegrationScenarios.cs` 공개5개: entry실제전수·토납→감응, 정책이해도까지반복전수→상위공법/돌파, 실제오독/준비거절뒤동일판본재독해, 실제감응실패·회복뒤새시도, 숨은타인재고/지식비간섭.
- `CultivationPreparationEvidenceScenarios.cs` 공개3개: 실제전수Qi의준비/조회무변화·동결저장·단일해소난수, 실제Qi학습·토납뒤두AI caller, 실제Qi오독거부·같은판본재학습. 앞의순수selector/contract2개를공개교습·실제시간근거로세지않았다.
- `ecology recovery` 공개4개+`ecology failure law`1개: 실제전량예약거부→유료food재관측→알려진이동·저장/제어, 숨은잔량·무급조사/총자원추정거부, 실제배운농사·관측물/종자·유료노동, tinybelief1퇴출무예외, 저장법칙에따른재확인기간/TTL상한.

실물책을사용한오독재독해는선언된실물소유/보관/매체권한에서수동공개study10개월로오독을만든뒤AI가같은판본을재독해한검사다. 이를기억0AI의자발적초회독서·실물획득까지증명한것으로쓰지않는다. 반복전수검사도실제teacher요청→1%→정책10%전수경로이며책study검사로바꾸지않는다.

L05의남은입력은 **root/성장담당의최종remote7ce9 전체SHA, 원문/provenance 경로, 실제완료범위와성공·실패판정**이다. 진행중이면그상태를유지하며결과를예상하지않는다. 기존926성장이나중단b0원문으로대체하지않고, 새seed/기간/무료자산/성공강제fixture를추가하지않는다.
