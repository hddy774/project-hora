# H06/H09 자체 수용과 EX-01~06 채택 결정

루트는 [실제 여섯 비교의 원본·표본·권고](README.md)를 검토하고 H06/H09 자체 수용 근거가 충족됐음을 승인했다. 승인 원문 범위·상태 차이·선행 조건·출처는 [기계 판독 기록](acceptance-approved.json)에 있다.

| 실험 | 승인한 결정 |
| --- | --- |
| EX-01·02 | 추가 기본 채택 보류·재검토. 검증된 현재 실행 인프라의 비교이며 일관된 속도 우위를 주장하지 않는다. |
| EX-03 | 추가 기본 채택 보류·재검토. 재사용 커널과 권한 캡처·거래 전체 비용을 구분한다. |
| EX-04 | 현재 SIMD 기본 채택 기각, 스칼라 유지. 네이티브 도입을 새 의무로 만들지 않는다. |
| EX-05 | 추가 기본 채택 보류·재검토. 크기 이득과 전체 중앙값·할당 악화를 함께 보존한다. |
| EX-06 | 추가 기본 채택 보류·재검토. 캐시 재열기와 생성·전체 DTO 비용을 구분한다. |

이 결정에 따른 추가 런타임 변경·롤백은 없다. 실측 소스174/제품 지문4e228과 .NET10.0.14의 원문·수치·표본·부정 결과를 유지한다. 각각 다른4CPU VM, 작은2명·32매물 범위, EX-04의 표본 수, 숨김 중간 파일4개/ZIP 누락, VM 사이 DLL bytes 차이도 그대로 남긴다. 후속 PGOoff 소스의 검증을 이 원본에 소급 적용하지 않는다.

최신 원장 기준은 [4f1c083](https://github.com/hddy774/project-hora/commit/4f1c083f043b85a0449d0204253e8b0292ee0b35)이다. H06/H09만 `in_progress → validated`로 자체 수용을 반영한 뒤 기존 선행 닫힘을 계산했다.

| 작업 | 선행 조건 | 결과 |
| --- | --- | --- |
| V021-H06 | H04/H03/K08 모두 done | done |
| V021-H09 | H04와 이번에 닫힌 H06 모두 done | done |

나머지109개 작업 행과 정본 요구·선행관계를 보존했다. 전체 진행률은 **52/111(46.8%)**, 자체 수용은 **107/111(96.4%)**, `validated`55개·진행 중4개(L05/Z04/T04/T06)다. 초기 README/review의49/111은 승인 전 수집·검토 당시의 기록이다.

이 두 작업의 자체 수용은 T04·T06의 최종 제품 성능·릴리스 수용을 대신하지 않는다. 루트가 별도로 통지한 후속94/528 네규모32지표 고정예산 통과도 별도 소스 근거로 다룬다. 원장을 임의로 더 닫거나 기존 불합격 원본을 대체하지 않는다.

새 게임·성능·성장 실행, 큰 원시 자료 재분석·해시 순회·압축·컴파일은 하지 않았다. [계획 validator](plan-validation.json) 한 번과 기존 진행도 생성만 수행한다.
