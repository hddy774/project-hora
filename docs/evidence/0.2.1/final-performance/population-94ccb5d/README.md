## 실행·메모리·후속 판정의 범위

Release/.NET10.0.14, Debian13 X64, Linux 호스트의 CPU0 한 개 affinity다. 다른 CPU의 기존 성장 실행 및 작은 문서 작업과4CPU 할당을 공유했고 물리 호스트 독점 실행이 아니다. 실행에는 EventPipe/프로파일러를 붙이지 않았다. 열·전원·Android 실기기 성능은 미측정이다. 실제 runtimeconfig는 `System.Runtime.TieredPGO=false`이며 root가 기록한 두 환경 override는 null이다.

같은 프로세스에서 창세 선택 뒤 규모를 순차 측정했고 규모별 예열2개월·실측12개월·반복1회다. 각 규모의 초기 인구는 두 실제 시조와 명시적 합성 편입 fixture이며 자연 출산/500년 성장 결과가 아니다. JIT/공유 캐시·이전 작은 결과 행과 외부 부하의 범위는 원문 환경에 기록돼 있다.

할당은 각 실제 `AdvanceTo` 전후의 프로세스 누적 차이이며 월별 진행 JSON/콘솔 기록을 제외한다. 수집 보유 관리힙은 강제 수집 후의 실제 세계·공유/runtime 캐시·이전 결과 행을 포함하며 RSS/native/peak 메모리가 아니다. 인지 직렬화 bytes는 원문이 정의한 인지 투영 범위다.
