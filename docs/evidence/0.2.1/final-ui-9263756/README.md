200%는 CSSOM의 실제 글꼴 크기를 두 배로 만든 추가 검수 조건이고 DPR은 1이다. 새 정본 최소 조건을 추가하지 않는다. [소스 지문](source.json), [호스트 일치](host-proof.json), [방법·범위](provenance.json), [파일 해시](sha256.json)에 출처를 남겼다. 대표 화면 12개와 정확한 임시 진입점·검수 코드를 함께 보존하며, 나머지 원시 화면과 로그는 [scratch 파일 해시](raw-scratch-manifest.json)로 추적한다.
