# 창세 성장 보고 수용과 0.2.1 잠정값 판정

Codex 통합 담당이 원래 Z04의 유한 성장·타당성 보고를 수용했다. 실제 수용 시각은 verdict.json에 기록한다. Claude가 새 리뷰를 수행했다고 표시하지 않는다. 수용은 잠정값 유지와 관측 보고의 완결에 한정하며, 릴리스 준비 상태는 열지 않는다.

사용자가 선택한 기본 세계 **a(혈연 후손 간 허용·양친 모두 금단 이상·자동 외부 유입 없음)**를 유지한다. 비교 세계 b/c는 기본 정책으로 채택하지 않는다. 0.2.1의 잠정값은 시조 수명 1,200,000개월(10만 년), 시작 나이 1,200개월, 출산 후 회복 간격 120개월을 유지한다. `cultivation.foundation`은 1,200개월을 유지한다. 이 키는 새 축기 구조의 전체 수행 목표이며, 출생부터 금단까지 실제로 걸리는 시간을 보장하는 값이 아니다.

기본값 1,200을 900 또는 1,500으로 바꿀 개선 효과가 현재 관측에서 식별되지 않았다. 900의 완주 세 조건은 기본 1,200과 보고된 비시간 성장 표본이 같았고 후손 축기 형성도 관측되지 않았다. 이 키는 시조의 초기 절대 구조와 상위 목표에도 영향을 주므로 순수한 후손 성장 실험은 아니다. 따라서 우월성이 확인되지 않은 변경을 하지 않는 결정을 내린다. 이는 현재 값을 균형의 최적점으로 입증했다는 주장이 아니다. 시조의 10만 년 수명 경계도 500년 관찰창 밖이므로 전체 수명의 타당성을 입증하지 않는다. 나머지 채택 법칙과 People 모델 계수도 실제 채택 값·출처·revision을 유지한다.

## 보고 수용 범위

정본 Z04는 a/b/c별 세대 시간, 인구·금단·범인·무인 범위, 성립 시점과 유한기간 미성립 분포, 배속·플레이 시간, 가정·불확실성의 보고를 요구한다. 기존의 기본 성장 9조건은 각 6,000개월·51표본을 끝내 이 항목을 모두 보고한다. 모든 시드의 후손 금단·2세대·왕조 성립이나 민감도 여섯 조건의 완주를 별도의 의무 조건으로 추가하지 않는다.

| 요구 항목 | 실제 근거와 해석 |
| --- | --- |
| 기본 a, 비교 b/c | a/b/c × 시드 42/98/2026의 9조건·459표본. b/c는 혈연을 제한한다. b만 240월에 무자산 범인 2명을 명시 편입하고 c는 유입이 없다. |
| 세대와 몸나이 | 첫 후손 출생은 a 2/3, b 3/3, c 2/3에서 관측됐다. 실제 2세대가 없어 세대 간 간격은 미관측이다. 개인의 Born이 없는 몸나이를 타인의 첫 출생월로 계산하지 않는다. |
| 인구·경지 범위 | 120월 표본의 인구는 a 2~7, b 2~8, c 2~7명이다. 금단 이상은 a/b 2명, c 2~3명, 범인 경지는 a 0~2, b 0~4, c 0~2명이다. 무공 보유는 보존 표본 모두 0명이다. 범인 경지와 무공 보유는 별개 축이며 표본 사이 연속 극값은 측정하지 않았다. |
| 성립·미성립 | 종문은 각 3/3에서 1월, 시장 활동은 10월에 성립했다. 공방은 a 2/3(30~1,059월), b 2/3(30~5,786월), c 3/3(30~5,524월)이다. 후손 금단은 a/b 0/3, c 1/3(시드 2026의 4,326월)이다. 추가 가문·왕조·정착은 6,000월 안에 관측되지 않았다. 부재를 영구 불가능이나 0월 성립으로 바꾸지 않는다. |

| 가정과 불확실성 | 고정 세 시드의 유한 관찰이며 확률·무한 생존·장치 성능을 추정하지 않는다. 모든 선언 종족·기예·법칙이 실행됐다고 세지 않는다. 생애·수행·생식의 실제 채택 값과 선언 카탈로그를 구분한다. |

## 민감도와 추가 관측

원래 실행 41131479924는 실패다. 900의 세 시드와 1,500의 시드 98만 완주했고, 1,500의 시드 42/2026은 각각 실제 진행 2,574/5,443월에 240분 상한으로 중단됐다. 마지막 120월 표본은 2,520/5,400월이다. 이 두 부분을 6,000월 미성립으로 쓰지 않는다.

순서만 바꾼 보충 실행 41159864831의 시드 98은 실제 종료 0으로 완주했고, 기존 98의 102개 표본 전체와 모든 비시간 사례 필드·최종 해시가 일치한다. 중복이므로 고유 완주 추가는 0이며 현재 4/6을 유지한다. 시드 42/2026과 전체 배치는 아직 실행 중이다. 이후 원문은 별도 출처로 보존하고 판단에 실질적인 새 정보가 있으면 이 결정을 재검토한다. 서로 다른 계획의 조건을 같은 계획·전체 완주·종료 0의 PASS로 합성하지 않는다.

## 소스와 최종 검증의 경계

성장 실측은 소스 7ce6694 / 제품 지문 4e228e에서 수행했다. 이후 Game/Core의 18개 변경 경로는 기능별 파일 분리, 정준 해시·JSON 바이트 보존, 저장 봉투 선택 경계 변경, 독점 소유 지식 상태 최적화로 각각 검토했다. 기본 JSON 경계를 128MiB에서 16MiB로 낮춘 부분은 초과 저장의 물리 형식을 기존 이진 schema3로 바꾸며, 모든 크기의 이전 저장 바이트가 같다는 주장은 하지 않는다. 바뀌지 않은 94개 기존 경로와 법칙·시간·RNG·AI 선택 경계도 대조했다. 7ce의 성장을 최신 소스에서 새로 6,000개월 실행했다고 표시하지 않는다.

최신 동결 소스 2464337 / 지문 0eaf05는 전체 기능 323개와 단기 성능 지표 32개를 실제 통과했다. 120개월 안정성 실행 41170302565는 진행 중이다. 이 성장 보고 수용은 T04의 시간·메모리·저장 상한, 공식 동일 서명 APK, 업그레이드 또는 릴리스 합격을 대신하지 않는다. 원장 의존 마감은 자체 수용 근거를 이미 가진 validated 작업에만 적용하며, T04/T06은 진행 중으로 둔다.
