## 실제 조건과 중단

기본 계획은 a/b/c 각각 seed 42·98·2026, 6,000개월, 120개월 관측이었다. a는 기본 법칙, b는 혈연 제한과 240개월의 명시적 외부인 두 명, c는 혈연 제한 조건이다. a/b/c 각 프로세스가 seed 42만 시작했으며 seed 98·2026은 시작하지 않았다. 각 실행의 실제 법칙 112개는 동결 소스의 기본값 및 b/c의 명시적 `birth.kinship=0` 조건과 대조해 기록했다. 음식·화폐·수행 조건을 완화하지 않았다.

기존 Release DLL을 직접 실행했고 `dotnet run`이나 빌드를 하지 않았다. 다음 명령의 `{cpu,scenario}`는 각각 `{1,a}`, `{2,b}`, `{3,c}`였다.

```text
taskset -c {cpu} /workspace/.dotnet/dotnet /workspace/seonro-projection-b0f3aec/tests/Chronicles.Game.Tests/bin/Release/net10.0/Chronicles.Game.Tests.dll --filter INV-001/002/011 --report /workspace/scratch/growth-b0f3aec-{scenario}-genesis.json --growth /workspace/scratch/growth-b0f3aec-{scenario}.json --growth-scenario {scenario}
```

세 프로세스는 13:55:55 UTC에 시작했다. 실제 CPU affinity는 a=1, b=2, c=3, cgroup `cpu.max`는 `400000 100000`, 유효 cpuset은 `0-4`였다. 동시에 실행한 세 보정 프로세스의 경과 시간이므로 순수 성능 기준선이나 기기 속도로 해석하지 않는다. SIGTERM 요청까지 실제 벽시계 경과는 각각 약 1,283.34초다. 마지막 관측의 `caseElapsedMs`와 이 중단까지의 벽시계 시간은 다르다.

통합 담당자는 별도 동일-seed 0~1,200개월 진단에서 입문 작업이 상한에 도달해도 입문 시도를 생성하는 AI 경로가 없고, 음식 고갈 경합 뒤 회복 경로도 없다는 결함을 확인해 중단을 지시했다. 이 디렉터리의 성장 DTO에는 입문 시도 횟수·음식 관측 횟수·상세 사인이 없으므로 성장 집계만으로 해당 원인을 추정한 것으로 읽어서는 안 된다. 원인 진단과 수정의 상세 근거는 별도 기능 수정에서 검증해야 한다.

2026-10-30 **14:17:18.497845 UTC**, 소유 PID 84249/84236/84242의 실제 DLL·시나리오·출력 경로와 부모를 확인한 뒤 SIGTERM으로 종료했다. 세 자식 모두 exit code `-15` / signal `15`가 확인됐다. 실행 메타데이터 writer인 검증된 부모도 원본을 다시 쓰기 전에 중단·종료했다. 별도 [중단 기록](growth-b0f3aec-interruption.json)에 시각·PID·마지막 관측·종료 상태·원본 SHA256을 기록했다.

## 실제 부분 관측

세 조건 모두 마지막 보존 관측은 seed 42의 **3,240개월**이다. 0개월부터 120개월 간격인 각 28개 관측 행이 남아 있다.

| 조건 | 누적 출생 | 누적 사망 | 생존 인구 | 생존 시조 후손 | 후손 금단 이상 | 종문 | 왕조 | 활성 시장 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| a 기본 | 2 | 2 | 2 | 0 | 0 | 3 | 0 | 0 |
| b 혈연 제한 + 외부인 | 2 | 4 | 2 | 0 | 0 | 2 | 0 | 1 |
| c 혈연 제한 | 2 | 2 | 2 | 0 | 0 | 3 | 0 | 0 |

모든 조건의 첫 후손 출생은 실제 `Person.Born` 기록상 30개월이며 누적 두 후손의 출생 범위는 30~181개월이다. 모든 조건에서 첫 종문은 1개월, 첫 시장 활동은 105개월의 실제 영속 기록으로 확인됐다. 마지막 시점의 활성 시장 수와 과거 시장 활동 성립은 별개다. 세 조건 모두 활성 작업장·정착지는 0이다. 후손 금단·추가 가문·왕조는 이 부분 실행에서 관측되지 않았다. 중단한 기간 밖의 부재나 성립 가능성은 판정하지 않는다.

생존 인구 2는 원래 두 시조이며, b의 누적 사망에는 240개월에 명시적으로 투입한 외부인 두 명이 포함된다. 숨은 인구·대체 후손·자산·화폐를 투입하지 않았다. 위 관측을 성장 성공으로 재명명하거나 빈 seed를 0으로 채우지 않는다.

## 원본과 확인 범위

[파일 목록과 해시](manifest.json)는 scratch 원본에서 복사한 14개 파일의 byte 수·SHA256 및 원래 경로를 담는다. 각 a/b/c의 성장 JSON, 로그, 선택 기능 결과, 실행 메타데이터와 중단 기록을 byte-exact로 복사했다. 원본 성장 JSON의 `status=partial`, 개별 case의 `status=running`, `requested_complete=false`, `complete=false`는 수정하지 않았다. 원본 실행 메타데이터의 `status=running`도 그대로다. 실제 생명주기 종료 사실은 별도 중단 기록을 따른다.

각 프로세스가 성장 전에 실행한 기능 선택은 `INV-001/002/011` 한 사례이며 결과는 각각 1/1 통과다. 전체 기능 시험 통과를 뜻하지 않는다. 이 문서 보존 작업에서는 빌드·기능·성장·성능 실행을 새로 하지 않았다.

중단 후 같은 동결 소스의 `scripts/aggregate-v021-growth.py`로 원본 세 개를 검사했다. 검사기는 exit code 1과 `성장 원본 통합 거절: 부분/다른 기간/조건/미완료 성장 원본`을 반환했고 통합 결과 파일을 생성하지 않았다. [거절 로그](growth-b0f3aec-aggregate-rejection.log)는 추가 시뮬레이션 없이 확인한 부정 검사 결과다. 기존 최종 경로 `docs/evidence/0.2.1/growth.json`은 덮어쓰지 않았다.

최종 성장은 결함 수정과 기능 검증을 마친 동일한 새 소스로 원래 a/b/c × seed 42·98·2026의 6,000개월 조건을 다시 실행하고, 서로 다른 9개 완주 원본을 검증해야 한다. 이번 부분 실행은 그 완주 수에 포함하지 않는다.
