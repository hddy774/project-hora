# M05 비경의 실제 공개 기능 검증

대상 소스는 `88c57f4d012bd9c2ba08fdd64f7f3ba59daa4c76`이며, 통합 기준
`ca4e3a5`에 비경 후속 소스와 UI의 조회 경계 `09adc54`를 병합했다.
[후속 PR #136](https://github.com/hddy774/project-hora/pull/136)의 선택 검증은 **34/34 통과**다.
공개 명령·조회 경로가 33건이고, 허가 매체를 페이지보다 먼저 거르는 순수 모듈 조회가 1건이다.
최신 전체 기능이나 성능·플랫폼·릴리스의 통과를 뜻하지 않는다.

| 선택 범위 | 결과 | 실제 확인한 계약 |
| --- | --- | --- |

비경은 기존 100개 전략 지점을 유지하고, 그중 10개 입구에 실제 참여자의 하위 공간을 둔다.
개인에게는 자신이 지불한 탐색의 날짜·개방 조건과 자기 진척만 보인다. 현재 내부 참가자·잔량·위험 추첨은 관찰 권한에서만 볼 수 있다.
일반 현지 탐색의 이웃 발견·유한 약초·고대 금제는 비경의 별도 유한 선점 원천과 구분되어 유지된다.

입장은 실제 휴대한 도구를 예약하고 준비 식량을 소비한다. 외부 바닥 도구·진행 중 실물 계약·출생 예정·현재 육신 이동/도구 자격을 검사하며, 거절은 비용·ID·RNG를 바꾸지 않는다.
진척은 실제 월별 행동을 점유하고, 시작 때 채택한 법칙과 한 번 뽑은 위험을 저장한다.
중도 귀환도 한 달을 점유하고 이미 쓴 준비물을 환급하지 않는다. 사망·몸 상실은 자리를 한 번만 해제한다.

완료 시 유한 원천을 한 번만 차감하고 실제 물품·추출 흐름·선점 영수증을 남긴다.
실물 소비 영수증을 다른 입장에 재사용하거나 선점 생성 영수증을 위조한 저장은 거절한다.
내부 생활은 실제 휴대한 식량만 사용하며 바깥 바닥 재고나 바깥 자녀의 보호자 공유를 관통하지 않는다.
AI도 자기 입구 관측과 개인 입문 지식이 있어야 같은 준비·입장 어댑터를 선택한다.

Release 빌드는 경고·오류 0개다. 실행 명령과 원본 선택 결과는
[검증 JSON](m05-secret-realms-functional.json)에 저장했다.
성능·대량 인구·성장·장기 실행·프로파일링은 실행하지 않았다.
111개 작업 원장과 Notion 상태는 변경하지 않았다. 최신 통합 전체 기능, 실제 플랫폼, 최종 측정·보정과 릴리스 대조는 담당 검증으로 별도 종료한다.
