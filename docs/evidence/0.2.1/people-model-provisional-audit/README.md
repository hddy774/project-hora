# 인물 생애 모델의 잠정값·보고 범위 읽기 감사

이 자료는 제품 `de7a296cc647368dae7b6343943382438787a660`와 PR174의 민감도 보고 소스 `8e13f7e5ad2670fdd2b779d5c22b0d793c8d1158`를 읽은 결과다. 관련 People·민감도 소스는 후속 `068ecef`에서도 같다. 제품·CLI·기존 원본을 수정하지 않았고 성장·비용 측정은 **0건**이다. [audit.json](audit.json)에 모델 16범주, 실제 호출 위치·단위·값·소스 파일 SHA256 및 기존 보고서 경계를 기록했다. 전수 요청 회귀 PR180은 별도 작업이다.

Laws는 **113개**, 이 중 잠정값은 103개다. 이것이 인물 영역의 모든 조절 수식 113개라는 뜻은 아니다. 저장되는 `PeopleState` 정책, 정적 종족·재능·특성 정의와 호스트 수식도 있다. 0~10000 척도, 여섯 기반·24재능·10인지 같은 구조, 결정론적 RNG salt를 모두 민감도 보정 계수로 세지는 않는다. 혈연 후손 허용·양친 금단은 사용자 확정 정책이며 보정 대상이 아니다. b/c의 혈연 제한은 명시된 비교 조건으로만 읽는다.

종족 카탈로그의 수명/성숙/임신 단위는 모두 개월이다. 영호는 1440/144/6, 석원은 1800/240/12, 영송은 3600/600/12, 수령은 2400/240/12이다. 실제 비인간 생성·출생에는 해당 몸의 값이 적용된다. 원형 a/b/c는 인간 시조 두 명과 b의 인간 편입 두 명만 생성한다. 비인간 정의가 UI나 빈 평가 범위에 참조돼도 그 수명·생식 모델을 채택한 실제 몸으로 세지 않는다.

현재 production 소스에서 People의 `MartialAptitude.Assess`·`CombatAssessment.Assess` 직접 호출은 찾지 못했다. 실제 무예는 수행 엔진과 `CultivationActorFor.Body/Mind`를 사용한다. 민감도 소스도 이 둘을 `formulaOnlyReferencesForSeparateReview`로만 둔다. 정의·테스트·정책 ID의 존재를 실제 성장 실행에서 그 수식을 사용한 증거로 바꾸지 않는다. 이번 감사는 이 분류를 설명하며 새 기능 수용 조건을 만들지 않는다.

원형 성장 보고서의 `usedLaws`는 당시 Laws 전량이고 `provisionalPolicies`는 ID·값·기본값·단위·근거를 출력한다. People 정책이나 모든 호스트 수식의 별도 숫자 사본은 아니다. 기존 limitations의 “모든 사용 잠정계수 공개”라는 문구는 이 실제 필드 범위로 좁혀 읽는다. 과거 `growth.json`에는 Laws62개, 중단된 b0 원본에는 Laws112개·잠정목록102개가 있다. 두 원본을 현재113개 입력의 완주·민감도 결과로 대체하지 않는다.

PR174 민감도 소스는 이 차이를 이미 구분한다. `sourceDeclaredPeoplePolicyDefaults`에는 Tuning·평가·명성·사회·유전·생식의 선언 기본과 종족/특성 카탈로그를 둔다. `adoptedPeoplePolicies`에는 실제 체크포인트 정책, 실제 종족 ID, 인물별 body 생식/능력/출처와 실제 잉태 모델의 수·최초 월·law revision을 둔다. 민감도 법칙 목록에는 범위·잠정 여부·revision도 포함된다. 선언 기본과 실제 채택값을 서로 대체하면 안 된다. 활성 특성 전체, 개인별 현재 수명·유전자 선택·흔적 전체와 호스트 건강/생리/수명 수식은 이 필드의 전체 상태 덤프가 아니다. source commit/fingerprint와 본 감사의 호출 위치가 해석 근거다.

6000개월은 500년이며 기본 시조는 창 말에 7200개월, 즉600세다. 다음은 **실행 결과가 아니라 정수 경계 계산**이다. 시작 나이는 고정1200개월, 기본 가임 비율은80%로 놓았다.

민감도는 같은 실제 기본 a의 세 seed와 한 잠정 LawId의 두 비교값을 대조하는 반사실 관측이다. 비법칙 People 정책 전체를 독립 변경하지 않는다. 금단 미도달 후손이 창 종료에도 살아 있으면 우측 검열이며, 그전에 사망/이탈한 경우는 별도 결과다. 개별 수명 전구간이나 확률 신뢰구간을 추정한 것으로 표시하지 않는다. 이 설명은 보고 해석을 보완하며 **불필요한 전계수 sweep·추가 측정 의무를 만들지 않는다**.
