# 감응 준비의 실제 지식 출처 회귀와 수정 근거

원본 검토 대상은 PR169의 동결 소스 `728d2a6751d22d2f8fa94894d0c8144600217e1f`다.
`original-probe.cs.txt`는 그 소스만 참조한 작은 순수 도메인 probe 원본이며,
`original-probe.json`은 실제 출력 그대로다. 세계 장기 진행·성장·성능·프로파일링은 실행하지 않았다.

| 입력 | 원본 준비 결과 | 동결 출처 / 형성 품질 |
| --- | --- | --- |
| 유효한 Qi만 | 수락 | `path.1.0`, 개인 revision7, 5833 |
| 같은 Qi + 이해도5% entry | `knowledge` 거부 | 없음 |
| 같은 Qi + 오류8000 entry | `interpretation` 거부 | 없음 |
| 같은 Qi + 기억/열람 불가 entry | `knowledge` 거부 | 없음 |
| 약한 신체, 유효한 Qi만 | 수락 | `path.1.0`, 개인 revision7, 3000 |
| 같은 약한 신체 + 이해도10% entry | `formation` 거부 | 없음; 당시 조회에는 이 거부 누락 |

원본 probe는 이해도5000·실습5000·오류0의 실제 Qi 증거와 완료한 EntryWork180000을 명시했다.
중립 신체의 오행 자질·운기·육신·신식은5000이다. 약한 신체는 오행 자질1·운기0·육신0·신식3000이다.
추가한 entry가 기존에 유효한 Qi 준비를 가린 것이 회귀다. entry-only 입문 허용 자체는 유지한다.

## 선택 규칙

Mortal의 비전환 감응에만, 선택한 Qi 경로의 최신 개인 증거와 최신 entry 증거 두 개를 비교한다.
각 증거는 실제 기억 또는 현재 열람 가능, 법칙의 최소 이해도 이상, 오류5000 이하를 모두 충족해야 후보가 된다.
자격 있는 후보의 기존 정수 형성 계산 결과가 큰 것을 고르고, 결과가 같으면 명시 Qi 경로를 고른다.
최소 형성 품질조차 못 채우면 준비를 거부한다. 자격 있는 후보가 하나도 없으면 종전의 entry 우선 거부 증거를 유지한다.
이전 판본으로 되돌아가거나 지식·숙련·자원을 추가하지 않는다.

기존 형성식은 다음과 같다. `/`는 해당 양의 항에 대한 정수 나눗셈이다.

```text
C = 부모 형성 품질 + 운기 + 육신 + 신식 + 오행 성장 조화
품질 = clamp((C + 증거.이해도) / 6 - 현재피해 / 2 - 증거.오류 / 2, 0, 10000)
```

같은 신체·상태·선택 경로·법칙에서 `C`와 현재피해는 후보 둘에 공통이다.
차이는 본인이 실제 학습한 두 증거의 이해도·오류뿐이다. 장소 공급/혼잡/권한·타인 지식·성공 난수는 순위에 쓰지 않는다.
정수 나눗셈·오류 손실·clamp 뒤의 동률까지 그대로 비교하므로 다른 근사 점수로 품질을 바꾸지 않는다.

동일 selector를 실제 Preflight·Prepare·호출자가 제공한 knownContext의 조건부 조회에서 사용한다.
선택 work/edition/personal revision/source는 시도에 동결되고 완성 형성에도 그대로 남는다.
AI는 동일 근거를 current/requiredWork와 관측한 준비 거부·재학습 대상으로 사용한다.
옛 거부가 다른 work/edition/revision에 관한 것이면 새 출처의 준비를 계속 막지 않는다.

개인 DTO의 미관측 공급·권리·품질 필터는 바꾸지 않는다. 실제 형성 품질이나 숨은 외부 조건을 개인 조회에 새로 노출하지 않는다.
일반 플레이어 cultivate는 한 달 작업만 완료하며, 기존 1% 실습 허용과 상위 경지·전환의 경로/실습 자격은 유지한다.
AI의 정보원 존재 판정은 준비의10% 자격과 분리해, 기초 지식이 있으면 실제 추가 학습을 계속 선택할 수 있다.

## 기능 검사 범위

새 `CultivationPreparationEvidenceScenarios.cs`는 낮음/반박/접근 불가 entry, 약한 기반,
정수 동률, 오류 손실, 음수 형성 경계, entry-only, 모두 부적격, 최신 판본만 사용, 최소 품질 거부를 검사한다.
전환 실습 자격과 상위 경지의 고유 공법, 1% 일반 실습, 개시 때 원래 열람 판본이 사라진 경우도 유지한다.

공개 세계 검사는 실제 전수·독서와 토납 후 준비 명령을 실행한다. 실물 책의 초기 보관자와 유한한 식량만 시험 초기조건으로 명시한다.
개인 기억·숙련·경지·EntryWork는 검사 준비 단계에서 주입하지 않는다.
실제 Qi 단독 학습자가 entry 요청으로 우회하지 않고 AI 준비에 도달하며,
실제 오독한 Qi의 거부·재독해는 같은 개인 판본을 가리키고 과거 해석을 보존한다.
중간 저장/복원, 조회 해시·RNG 무변화, 준비 RNG 미소비, 실제 해소의 단일 RNG 소비와 형성 출처를 함께 확인한다.

검사 명령:

```sh
dotnet run --project tests/Chronicles.Game.Tests -c Release -- --filter '감응 출처 선택'
dotnet run --project tests/Chronicles.Game.Tests -c Release -- --filter 'AI 수행 연결'
```
