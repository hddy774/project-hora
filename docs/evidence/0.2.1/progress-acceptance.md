# 0.2.1 수용 완료율 제안 — 42.3%

기준 소스는 `324e601c20c7920b5a2f8df59aae321c915336f3`다. 이 문서는 원장 변경 제안이며 제품 코드·정본 원장·Notion을 수정하지 않았다.

**선행 작업까지 완료한 수용 완료 권고는 47/111개(42.3%)**다. 자체 조건 통과 후보는 89/111개(80.2%)이며, 이 중 42개는 정본 선행 작업을 기다린다. 자체 수용 미완료는 22개다.

이 비율은 작업 개수에 따른 수용 완료율이다. 작성된 코드량·남은 공수·출시 준비율이 아니다. 진행 중 작업에50%를 주거나 항목별 임의 가중치를 만들지 않았다. 원장에 현재 기록된 완료3개와 실제 근거에 따른 완료 권고47개도 구분한다.

## 두 완료율이 다른 이유

`Z04`의 창세 추정/분포 측정이 `P02`의 선행 조건이므로, 현재 구현과 기능 증거가 있는 후속 수행·가계·경제 작업도 정본 의존 관계상 완료 처리를 보류한다. `M02/M05`는 비경 공존과 관련 지도/시설 후속을 막는다. `L04` 명시 측정과 `R06` 기능 대조, 정책 화면/명령 연결도 해당 후속 작업에 전파된다. 이 의존 관계를 완료율을 높이기 위해 바꾸지 않았다.

초기 잠정 자체수용92개에서 L04의 규모별 메모리/저장 측정, R06의 짧은 전략 대조, X03의 정책 명령 화면 미완료를 확인해89개로 보수 조정했다. R06은 별도 보정표나 장기 성능 검사를 새 의무로 요구한 것이 아니라 정본의 총기간·품질·위험·전략 차이 기능 검사가 남아 있는 것이다.

## 한계와 다음 갱신

새 비경 모듈과 공유 훅, H10 정리, 정책 화면/정치 명령이 통합되면 관련 자체 수용 근거를 갱신한다. R06의 짧은 기능 비교를 별도로 완료하고, 전체 기능 완료 후 명시된 규모별 측정과 최종 통합/화면/결정론 감사, 문서 접근 확인, 릴리스 결과를 순서대로 반영해야 한다.

희귀 체질/혈맥은 실제 저장 원형이 있어야 각성한다는 현재 입력 한계를 유지한다.40종 예시가 초기 세계에 모두 자연 발생한다고 주장하거나 정본에 없는 추가 출시 조건을 만들지 않았다. 향후 Unity는 설계/후속 검증 조건만 있으며 실행 호환을 증명한 것이 아니다.

과거55개 요구의 대응표는 보존되어 있으나 이를111개와 중복 합산하지 않는다. 원장 갱신은 루트 담당자가 이 제안을 검토한 뒤 수행한다.
