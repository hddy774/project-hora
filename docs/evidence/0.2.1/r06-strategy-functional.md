# R06 짧은 수행 전략 기능 비교

동일한 전체 상태에서 공개 명령으로 세 전략을 실행한 기능 검사다. 실제 시간·성능·인구 성장·장기 실행은 측정하지 않았다. 정수 결과와 이벤트·저장 파일 해시는 [기계 판독 근거](r06-strategy-functional.json)에 저장했다.

공통 준비 과정은 시드 42의 실제 세계에서 약초와 목재를 채집하고 단약을 제조한다. 제조 작업 `2088`은 약초 3개와 목재 1개를 소비해 품질 5,000의 실물 단약 `2089` 하나를 만들었다. 세 전략은 이 단약을 포함한 월 3의 동일한 상태·RNG에서 분기한다. 공통 초기 상태 해시는 `da878f6800f90c8edc5e25c314221de43aa5db19e0762e64a76ef1e30acf1cb0`이다.

시험용 공개 법칙은 기초 기간을 짧게 명시한다. 입문·연기·축기 기간은 각각 1개월, 상위 기간은 100개월, 원천 비용은 2, 기본 돌파 위험은 300bps다. 채집 작업과 제조 기간도 각각 1개월이다. 자연 기 재생·자동 회복·재난·식량 소비·부패·출산은 이 경계 검사에서 0으로 둔다. 다른 시조는 월 100까지 대기한다. 두 시조의 기본 창세는 유지되며, 전체 법칙 값은 JSON에 있다.

공통 경계 조건은 명시적인 테스트 도우미로 구성한 연기 9단계 대원만·건강 50·현재 구조 손상 500/10,000이다. 구조와 뿌리 성장은 해당 짧은 법칙의 실제 요구량을 채운다. 이 선언은 과거 수행·획득 이벤트를 만들지 않는다. 이후의 회복, 준비, 예약, 원천 차감, 형성, 안착은 실제 명령과 엔진이 처리한다.

| 전략 | 비교 구간 개월 | 소비한 실제 기 | 소비한 미개방 원천 기 | 소비 단약 | 최종 형성 품질 /10,000 | 채택 위험 bps |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 바로 형성 | 5 | 20,000 | 8 | 0 | 5,243 | 900 |
| 현재 손상 회복 후 형성 | 6 | 25,000 | 10 | 0 | 5,493 | 780 |
| 회복 후 실제 단약을 예약해 형성 | 6 | 25,000 | 10 | 1 | 5,493 | 530 |

기간은 공통 준비 이후부터 새 축기 구조의 안착 완료까지이며, 세 번의 안착 월을 모두 포함한다. 실제 기 소비는 장소의 미개방 기와 개방된 원소 기 잔량을 함께 대조해 계산한다. 단약은 세 전략 모두 같은 시작 재고를 가지므로 마지막 전략만 예약한 실물 1개를 소비하고, 나머지는 그대로 보유한다. 공통 준비에 필요한 3개월과 약초·목재는 세 전략에 동일하게 먼저 지불했다.

바로 형성하는 전략은 기간과 기를 아끼고 현재 손상으로 인한 낮은 품질과 높은 위험을 감수한다. 회복은 실제 1개월과 기 5,000을 더 지불해 현재 손상과 건강을 개선한다. 단약은 추가 실물 비용을 지불해 위험을 더 낮추며 이 사례의 형성 품질을 올리지는 않는다. 위험 값은 준비 시 확정해 채택한 정수 위험이며 반복 실험으로 추정한 실패 빈도가 아니다. 명시한 동일 RNG 표본에서는 세 전략 모두 실제 성공했다.

각 전략은 준비 뒤 `Started` 단계에서 `GameSaveStore.SaveAtomic`으로 파일을 쓰고 다시 읽는다. 복원본과 원본을 남은 모든 월 경계까지 별도로 진행해 상태 해시 일치를 검사했다. 이전 형성 품질은 그대로 보존되며 새 축기 구조에 무료 성장이 생기지 않는다. JSON은 각 준비·형성·회복·안착 이벤트 ID, 예약 실물 ID, 저장 파일 SHA-256, 중간 및 최종 상태 해시를 포함한다.

검사: `dotnet run --project tests/Chronicles.Game.Tests -c Release -- --filter 'R06 short functional' --report artifacts/r06-functional-tests.json` → 선택한 기능 검사 **1/1 통과**. 제품 소스 기준 커밋은 `01e4cc745626cb52a171a7b6c7914204cac2586d`이며 검사 파일의 SHA-256은 JSON에 기록했다. 기본 법칙의 장기 기간이나 최종 성능 수용 결과를 주장하지 않는다.
