# 실제 입문 기억의 감응 준비 연결 검수

검수한 앱 소스는 `5c10b9603797b673f5c1ed99047336a12aa317c7`이다. 통합 `0a33b68`와 입문 권위 PR169 최종 `728d2a6`를 모두 포함한다. 개인 조회가 domain의 권한 제한 `KnownNextRoutes`를 사용하도록 연결하고, 화면은 배운 공법 목록에 없는 기본 감응 동작도 선택할 수 있게 했다. 미학습 연기 공법을 지식 목록에 넣거나 이해도를 올리지 않는다.

실제 화면 검수에서 입문 토납의 정상 데이터 `Data=""`가 필수 선택란 검사에 막히는 문제도 찾았다. 입문 토납 선택란만 빈 값을 허용하고, 준비 명령은 기존 `Target=보조 실물 또는 0`, `Data=path.1.0` 계약을 유지했다.

[새 조회 검사](entry-query.json) 3/3와 [기존 rich query](rich-query.json) 12/12가 통과했다. 새 검사는 미학습 감응 선택 차단, 실제 entry만 가진 선택과 연기 지식 부재, 조회의 권위·RNG 무변경, 준비 부족 거부, 일반 토납의 범인 유지, 실제 준비·개시 공급 소비, 저장·불러오기와 미관측 현장 공급·사용권 비간섭을 확인한다. 이는 공개 query/command·codec 검사이며 네이티브나 UI 클릭 검사로 분류하지 않는다.

실제 새 GameSession 호스트에서 1280/390px와 일반/200% 글자의 네 조건을 모두 통과했다. 공개 생성·법칙 명령으로 구성한 인물이 실제 10개월 전수를 받고, 화면에서 준비 부족 거부→토납 4회→감응 준비→저장·불러오기→개시를 진행했다. 전수 시작은 기존 공개 명령으로 설정했고, 화면에 없는 10개월 기간 선택기를 클릭했다고 주장하지 않는다. 준비 대화창은 Tab·Enter와 실제 터치 탭을 사용했으며 선택란·제출 버튼은 44px 이상, 200%에서는 60px 이상이다. 문서·body와 준비 대화창에서 가로 넘침이 없었다.

[출처·범위](provenance.json), [일반1280](entry-ui-normal-1280.json), [일반390](entry-ui-normal-390.json), [200%1280](entry-ui-text200-1280.json), [200%390](entry-ui-text200-390.json), [재검수 세션 코드](entry-ui-check.py)를 보존했다. 200%는 CSSOM의 실제 글자 크기를 두 배로 만든 검수 조건이며 DPR 대체나 새 정본 최소 조건이 아니다. [일반 전체 회귀](full-normal.json)와 [200% 전체 회귀](full-text200.json)는 각 두 폭에서 9메뉴·실제 알려진 수행 경로 제출·법칙 검증과 원자 적용·저장·범위 전환·정책·사회·비경을 모두 통과했다. [실제 폰트·터치 기록](text200-fonts.json)은 CSSOM 글자 2배와 DPR1을 확인한다. 두 어댑터의 실제 응답 재생 결과는 별도 행에 있으며 domain_integration_claim=false로 유지한다.

임시 Shell은 정확 소스의 Game/Hosting Release 빌드와 배포 compat 자산을 사용했다. 제품 Program.cs를 바꾸지 않고 URL·same-origin 포트만 5223으로 분리했으며 API 응답은 모의하지 않았다. 실제 네이티브 API24/35·Windows, 성능·장기 성장, 최종 T05 완료를 주장하지 않는다. 최종 통합 소스 수용과 원장 마감은 별도다.
