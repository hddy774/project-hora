# v1.11.0 고정 입력 성능

Linux x64, .NET 9.0.20, 논리 CPU 4개에서 기관 100곳·개미 10,000명·15종목을 측정했다. 시드 20261004의 168시간 체크포인트를 모든 비교에 사용했다. 개별 미세 측정은 준비 실행 후 5회 또는 9회 중앙값이다. 시뮬레이션은 같은 입력에서 720시간 전체를 실행했다.

| 항목 | 캐시 전 | 캐시 후 1회 | 캐시 후 반복 |
|---|---:|---:|---:|
| 720시간 시뮬레이션 | 7,749.5 ms | 6,632.9 ms | 7,219.0 ms |
| 시간별 실행 중앙값 | 9.84 ms | 8.55 ms | 9.13 ms |
| 시간별 p95 | 13.99 ms | 12.11 ms | 13.93 ms |
| 시간별 p99 | 20.73 ms | 17.21 ms | 21.38 ms |
| 저장 포함 100배속 입력 처리 | 11,695.4 ms | 10,802.7 ms | 13,367.2 ms |
| 저장 준비 중앙값 | 8.32 ms | 9.54 ms | 9.93 ms |
| 직렬화 중앙값 | 50.70 ms | 51.53 ms | 63.33 ms |
| 스냅샷 쓰기 중앙값 | 96.54 ms | 96.04 ms | 105.22 ms |

시뮬레이션 총시간은 이 표본에서 6.8~14.4% 줄었다. 저장 경로와 p99는 반복 측정에서 느려진 경우도 있으므로 전체 앱·저장·지연 상위값의 개선을 주장하지 않는다. 이 호스트 결과는 물리 휴대전화의 FPS·배터리·온도 측정이 아니다.

## 결과 보존

모든 비교의 최종 전체 상태 SHA-256은 `93D31C4D13D6CC291480908E0377DB8C93419A0BC11D3570DD8CCF68B5960743`로 같다. 누적 체결 401,751회, 포트폴리오 재검토 215,112회, 난수 상태 3987641985도 같다. 100배속 경로는 43,200분을 수락·완료하고 대기 0분이며 20게임시간마다 실제 저장한다. 이는 가상 입력을 사용하는 호스트 측정이고 [Android 시간 검사](../../verification/v1.11.0/README.md)와 구분한다.

캐시는 시간별 이력의 변동성·추세 입력과 배당 지급액 합계에만 적용한다. 현재가에 의존하는 배당수익률은 매 분 재계산한다. 상태 객체·완료 시간·기업행동 ID가 바뀌면 이력 캐시를 무효화한다. 일일 가격 범위도 기준가가 바뀌면 다시 계산한다. 매 분 잠금 반환, 비동기 저장, 수락한 시간과 원본 이력 보존은 유지한다.

별도 저장 측정은 5년 분량 **합성** 이력 43,201행/91,525,120바이트의 조회·경계·전체 범위를 검사한다. 5년 경제 시뮬레이션 결과로 해석하지 않는다.

## 재현과 원자료

- 기준은 공개 커밋 `0cd7a25`에 `b95120e`의 `src/AlphaExchange.Core/Simulation/Trading/PortfolioExposure.cs`만 복사한 것이다. 현금만 가진 기관의 회복 정책을 같게 맞췄다. 로컬 비교 커밋은 `007eff4`이며 공개 이력으로 기준을 재구성할 수 있다.
- 변경본은 `b95120e`이다. 기준에서 시드 20261004, RunId `00000000000000000000000020261004`, 168시간을 진행한 입력 SHA-256은 `9986c26ff8fe8a099a8f02962d8bf9c7f90dd8730937934423c57aa0dd16479e`이다.
- 입력 생성은 기준의 `tools/PerformanceAudit`에 `label output.json missing-input.json fixed-input.json` 인수를 주면 된다. 비교는 각 체크아웃에서 `dotnet run --project tools/PerformanceAudit -c Release -- LABEL OUTPUT fixed-input.json`으로 실행한다.
- `before-cache-aligned`, `after-cache`, `after-cache-repeat`의 JSON과 로그를 그대로 보관했다. 커밋·입력 해시는 `provenance.json`에 명시한다. 규칙이 다른 v1.10과의 손익 비교는 [장기 시장 분석](../../analysis/v1.11.0/README.md)에 따로 기록한다.
