## 병합 전 꼭 해결

**1. 안드로이드 검사 실패: 앱 문제가 아니라 검사 방식 문제**
- 로그상 앱은 정상 렌더됐습니다(`rendered:true`, `error:null`, "연결됨").
- 그런데 런처(Quickstep)의 "응답 없음" 대화상자가 앱 화면을 가려서, 화면 구조에서 WebView를 못 찾고 실패했습니다.
- #219에서도 같은 일이 있었으니 우연이 아니라 반복되는 문제입니다. 지금은 실패 원문을 보존만 하고 원인은 그대로 남아 있습니다.
- 고칠 곳은 `v021-product.yml`의 `am start` 후 `sleep 20` 한 번 → 화면 1회 캡처 구조입니다.
  - `am start -W`로 실행 완료까지 기다리기
  - "응답 없음" 창이 앱 것이 아니면 "Wait"를 눌러 닫기
  - 화면에 앱 WebView가 보일 때까지 여러 번 재확인
- 이렇게 바꿔도 `verify-android-ui.py`의 합격 기준은 그대로라 기준이 느슨해지지 않습니다.

**2. main에 있는 작업 체계 파일이 삭제됨**
병합하면 아래가 사라지고, 다른 곳으로 옮긴 사본도 없습니다.
- 작업 체계 문서: `CLAUDE.md`, `docs/standards/` 전체(작업 진행 방식·코딩 규칙), `docs/redesign/`, `docs/tasks/`의 M0 명세
- 설정 파일: `.editorconfig`, `global.json`(.NET SDK 버전 고정), PR 템플릿, 이슈 템플릿
- 다른 프로젝트 코드: 월간 경제 게임(`Hora.*` 코드·테스트, `games/monthly-economy`)

다른 프로젝트 정리는 AGENTS.md 방침과 맞지만, 다음 두 가지는 정해야 합니다.
- **역할 분담:** "Claude는 기획·명세·리뷰, Codex는 구현" 규칙과 작업 명세 형식을 버리는 건지, AGENTS.md로 옮길 건지
- **SDK 버전 고정:** `global.json`이 없으면 빌드마다 SDK가 달라질 수 있어 "같은 제품 지문" 주장이 약해집니다. 새 루트에 다시 넣는 걸 권합니다.
