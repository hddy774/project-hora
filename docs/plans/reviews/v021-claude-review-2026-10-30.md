- 대상: Notion `04-02. 선로만상록 0.2.1 통합 개발 기획` (개정 5, 2026-10-30 기준 판본)
- 검토일: 2026-10-30
- 피드백 횟수: **1/1** (이 문서가 13장 "클로드 1회 요청"에 대한 수신 원문)

## 0. 검토 범위와 한계 (Codex가 먼저 읽을 것)

- **읽은 범위**: 기획 페이지 본문 전체(약 2,500줄, 1~13장, 모든 접기 영역)를 처음부터 끝까지 읽었다.
- **기계 검증한 것**: 12장 작업 원장 표를 파싱해 의존성 DAG를 검사했다.
  - 작업 수 107개, 모든 선행 ID 존재, **순환 없음**, 모든 작업이 V021-T06의 선행 사슬에 포함됨.
  - 원래 V020 요구 55개 모두 대응표에 있고, 대응된 V021 ID도 모두 원장에 있음.
  - 최장 선행 사슬 길이는 26단계(T06)이다.
- **읽지 않은 것**: GitHub 코드, 페이지에서 링크한 정본 Notion 하위 문서(경지 정본 10개, 유전·도려 문서 등), 외부 기술 문서.
  - 따라서 "기존 코드가 실제로 ~하다"는 기획의 서술은 **검증하지 않았고**, 아래 지적도 기획 본문 내부의 정합성과 설계 타당성에 한정된다.
- 구현, 테스트, 성능 결과는 아무것도 확인하거나 가정하지 않았다.

## 1. 총평

- 정보 경계, 실물 원장, 원자 전이, 결정론, "조회는 세계를 바꾸지 않음" 같은 **불변 계약은 매우 일관되고 강하다**. 정본, 신규 제안, 미정을 구분하는 태도도 좋다.
- 다만 아래 세 가지가 가장 큰 위험이다.
  1. **창세 규칙의 조합(반선 시조 2명 + 양친 금단 출산 + 혈연 미정)이 인구 성장 자체를 막을 수 있다.** 그런데 이것을 정하는 Q-01이 아직 열려 있다. (FB-01~03, FB-06)
  2. **작업 순서가 "기초 계약은 늦게, 기능은 먼저"로 역전된 곳이 있다.** 정보 경계(N01), 불변식 검사(T01), 저장(D02), 반선 시조 프로필(R07)이 그것을 쓰는 기능보다 뒤에 있다. (FB-04, FB-09, FB-03)
  3. **수치를 하나도 정하지 않은 상태로 "미정 값 임의 확정 금지"를 걸어 두어**, Codex가 구현에 착수할 수 없거나 몰래 값을 넣게 된다. (FB-05)

#### FB-01 · 창세 인구 병목: Q-01이 미정이면 2세대 이후 출산 경로가 없다
- 분야/작업: 3장, Q-01, V021-P02·F02·Z01, 8장 수용 검증
- 분류: **[사용자 결정]** + [원장 수정]
- 발생 조건: 기본 프리셋은 시조 2명, 양친 금단 출산, 외부 편입 없음이다. 그러면 1세대 자녀는 모두 같은 두 부모의 형제자매다.
- 실패 예: 혈연 규칙이 "직계·형제 관계 금지"이면 1세대 이후 가능한 짝은 0이다. 이 경우 인구 상한은 "시조가 낳은 자녀 수"가 되고, 시장·종문·왕조 성립 검사가 영원히 보류된다. 기획은 이 상태를 "구조적 차단"으로 표시하게 했지만, **기본 프리셋 자체가 차단 세계인지**는 정하지 않았다.
- 수정안:
  1. Q-01을 P02·F02의 **차단 결정**으로 격상한다. 결정 전에는 두 작업의 수용 조건을 확정하지 않는다.
  2. 사용자에게 다음 중 기본 프리셋을 고르도록 요청한다.
     - (a) 시조 후손 간 혈연 혼인 허용, 게임상 영향은 법칙으로 정의
     - (b) 혈연 제약 + 명시적 편입 사건(변이·생령 편입 등) 경로를 기본 활성화
     - (c) 혈연 제약 + 외부 유입 없음(정체·멸절을 의도한 세계로 인정)
  3. "양친 모두 금단"인지 "출산자만 금단"인지도 같은 결정에 포함한다. 1장 표는 "출산 기본 금단경"이고 3장은 "기존 양친 금단 조건을 기본안"이라 범위가 모호하다.
  4. 창세 검증 화면에 "기본 프리셋의 최대 도달 세대 / 차단 여부"를 생성 전에 표시한다.

#### FB-02 · 범인·무인 인구 모순: 기본 규칙으로는 시장·도시 설계가 전제한 범인 집단이 생기지 않는다
- 분야/작업: 3장 출산 규칙, 6장 "수요를 만드는 실제 원인", 8장 도시 운영, V020-J01 → V021-P01·P03, V021-W01
- 분류: **[사용자 결정]** + [원장 수정]
- 발생 조건: 기본값은 금단 이상만 출산하고 범인·무인 출산은 비허용이다.
- 실패 예: 6장은 "범인 집계 인구의 생산·생활 수요"를, 8장은 도시 거주 가계를 전제한다. 하지만 기본 세계의 범인은 "금단 부모에게서 태어났으나 수행에 실패한 자녀"뿐이고, 이들은 자손을 남기지 못한다. 범인 인구는 항상 금단 인구의 출산량에 묶이므로, 도시 규모의 범인 수요는 구조적으로 나오기 어렵다. 무인은 "금단과 비등"하지만 출산 환산 기본값이 없어서 기본 상태에서는 번식이 막힌 경로가 된다.
- 수정안:
  1. "범인의 기원 = 수행 미입문·실패 후손"을 3장에 명시한다. 6장의 "범인 집계 인구"는 이 실제 인물들의 집계로만 정의한다.
  2. 무인 정점(금단과 비등)의 출산 환산 기본값을 사용자에게 묻는다(허용 / 비허용).
  3. 도시와 시장 설계가 "범인 대중"을 전제한 문장은 "실제 존재하는 비수행 후손"으로 바꾼다.
  4. FB-06의 성장 곡선 추정에 범인·무인 비율을 포함한다.

     - 금단 도달 기본 기간
     - 기본 출산 간격

1. **P3 정정**(FB-22~25)을 Notion 페이지에 바로 반영한다. FB-25에서 13장 피드백 원장은 "1/1 수신"으로 바꾸고 항목별 판정 표를 붙인다.
