## 구현자가 선택한 조절 가능한 기본안

전체 구현 지시와 잠정값 보정 위임에 따라 선택한 값이다. 사용자의 추가 확정으로 기록하지 않는다.

| 질문 | 개발 기본안·근거 |
|---|---|
| Q-02 | 인간형 시조 2명·100세·상호 도려·상보 생식 프로필. 경지는 반선, 숙련 최대값 없음. 초기 자원/매체는 창세 출처 |
| Q-03 | 동시 존속 종문 기본 최대10, 해산/신생과 역사상 수는 분리. 법칙으로 변경 |
| Q-04 | 실제 한 주 주권으로 왕조 성립, 이후 영토0 존속. 처음부터 무영토 창건 예외는 추가하지 않음 |
| Q-05 | 명시 편입은 성인 범인·외부 기원·자산0. 창세 인원에는 포함하지 않음 |
| Q-06 | 성년/실제 재원·가계가 가주 자격. 출산 금단과 독립. 산후 부담과 간격은 법칙 |
| Q-07 | 13개 원인 생산자와 자격을 모두 포함. 분혼 기본1개·보존 비용30%, 법칙으로 변경 |
| Q-08 | 현재 .NET10·본문 크기에 따른 JSON schema2/UTF8 이진 version3 검증 봉투·파일 어댑터. 세계 DomainSchema2 유지, 상세는 [제품 저장 경계](../architecture/v021-product-boundary.md#메모리-저장-계약과-파일-어댑터). Unity 직접 호환 완료를 주장하지 않음 |
| Q-11 | 양친 금단 기본에서 무인 환산 비활성. 별도 법칙으로만 허용 |
| Q-12 | 13경로 전체 유지. 일부 경로 후속 이관 없음 |
| Q-13 | 적격 대기혼은 ReadyMonth→SoulId FIFO, 없으면 새 혼. 세계 법칙으로 신규혼 우선 선택 가능 |
| Q-14 | 주 전체 관측·실제 거주 가계·독립 주권·행정 노동을 통치 조건으로 사용. 임의 금지 연대 없음 |
| Q-16 | 엄격 관찰 전환 제한은 선택 기능으로 보류, 기본 플레이 수용을 막지 않음 |

세계 법칙 값의 단위·허용 범위·기본값·근거·잠정 상태는 Laws.All이 구현 원본이며 저장에는 적용 revision/차이를 보존한다.
법칙 편집은 조회와 분리한 명시 명령이다. 기존 잉태·계약·윤회 자격의 과거 증거를 다시 추첨하거나 소급 변경하지 않는다.
