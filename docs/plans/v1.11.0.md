# v1.11.0 가격 안정·호가 경쟁·투자 통계

## 목표

첨부된 v1.10 화면의 장기 기관 손실과 빈 매수 호가를 재현하고 가격·자금·매매 비용을 함께 점검한다. 15종목/5업종, 기관 100곳과 추세·뉴스 추종 개미, 오프라인 관찰형 구조를 유지한다.

- 전일 기준가 대비 일일 ±30% 범위에서만 주문·체결한다. 호가 단위의 안쪽 반올림, 자정·저장 재개·분할/배당락·대체 상장에서도 같은 규칙을 적용한다.
- 새 기관의 초기 자산은 100억 원이다. 실제 현금으로 초기 주식을 배정하고 성향별 주식 비중을 50% 이상으로 설정한다. 매도 가능량·매수 예약·재투자 계획에 현금 최대 50% 규칙을 적용한다. 평가 손실·미체결로 생긴 부족분은 실제 주문으로 복구하며 현금·주식을 임의로 생성하지 않는다.
- 매 게임 시간 모든 종목에 분산된 기관 호가 참여를 제공한다. 가격/시간 우선·자기 체결 금지·담보·수량 보존을 유지하고, 작은 변동에 반복 매수/매도하며 비용만 소모하는 경로를 줄인다.
- 회사별 뉴스 일정과 경제 노출 차이를 반영한다. 사건은 실적·수요·비용·투자 신호에 작용하고 주가는 실제 체결로 결정된다.
- 수수료·세금 포함 투자 성공 횟수의 정의를 만들고 저장·분할·교체·부분 체결에서도 일관되게 집계한다. 통계를 공통 카드/축/범례/금액 단위의 원형·막대·추이·표로 정리한다.

## 저장·성능·검증

v1.10 시장은 잔액·주식·원본 이력을 유지하여 이어간다. 과거에 기록하지 않은 성공 횟수는 소급해서 꾸미지 않는다. 새 초기 자금 규칙을 기존 잔액에 임의 지급하지 않는다. 더 오래된 30종목 원본 보관·내보내기는 유지한다.

금융 계산은 Core, 표시·차트는 Android/Client 경계를 지킨다. 시간별 유동성·뉴스·통계에 한정된 배열/캐시를 사용한다. 동일 시드 반복, 저장 후 재개, 회계 보존, 가격 제한, 시작 배분·매도 한도, 시간별 참여 분포, 성공 집계, 회사별 영향, 수개월 시장과 100배속/저장 병행을 검증한다. 호스트 비용과 Android 실행 결과를 구분해서 기록한다.
