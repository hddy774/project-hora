main의 피드백에서 공통으로 계승한 원칙은 작은 PR, 명확한 책임/주석, 실제 타입/권위 경계,
기획과 실행 결과의 분리, 명세·리뷰 템플릿, 측정에 근거한 개선이다.
다른 게임의 수치·게임 루프·가계 코호트·C#9 전환이나 clone/불변식 검사 일괄 제거는 적용하지 않는다.

새 기록은 실제 작성자·사용자 전달 여부·대상 source와 검토 범위를 적는다.
역할 이름 또는 Codex 자체 검토를 외부 Claude 수신으로 추가 계산하지 않는다.
