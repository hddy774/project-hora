# 공통 설계·피드백의 읽기 경로

현재 제품은 선로만상록이다. 실제 제품 요구는 [정본 원장](../plans/v021-tasks.json)과
[개정6 원본](../plans/revisions/v021-notion-revision6-source.md), 사용자 결정에서 찾는다.

- [피드백 연결](01-feedback.md): 원문·새 수신·반영 작업의 위치
- [현행 개발 기준](02-development-baseline.md): 실제 어셈블리/권위/검사와 명세 작성 기준
- [공통 개발 절차](../standards/development-process.md): Claude/Codex 핸드오프와 리뷰

main의 공통 개발 취지는 이 경로로 맞췄다. 경제게임의 상품·회사·도시·재무 설계와
그 제품의 전용 목표/성능 수치는 현재 제품 기획으로 복원하지 않는다.
[이관표](../standards/restoration-source-map.json)에 고정 source와 채택/제외 근거가 있다.
