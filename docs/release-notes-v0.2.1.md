# 선로만상록 v0.2.1

<!-- release-status: draft -->
> 미게시 초안입니다. 기능 감사·최종 성능·실제 Android/Windows 검사를 마친 뒤 확정합니다.

두 반선 시조에서 시작해 후손과 가계, 수행자와 무인, 종문과 왕조가 같은 세계 안에서 살아갑니다.

- 관찰과 플레이가 같은 명령과 세계를 사용합니다. 플레이의 정보와 판단은 인물의 기억·관측·권한에 제한됩니다.
- 오행 영근과 흡수·정제·순환·체화, 열 대경지의 서른 수행 경로를 연결했습니다. 형성 당시 품질과 현재 성장·손상·회복을 구분하고, 금단 파단 뒤의 실패와 소경지별 겁난을 실제 사건으로 처리합니다.
- 범인은 실제 입문 지식을 배워 토납 준비를 쌓은 뒤 감응을 따로 시도합니다. 연기 운기 공법은 입문 후 별도로 배우며, 준비 화면은 인물이 실제로 아는 출처를 보여 줍니다.
- 무인은 영근을 사용하지 않는 독립 열 경지를 단련합니다. 전투는 여덟 특성과 현재 구조·실습·장비·조건을 반영하며, 잠재력은 알려진 다음 경지의 조건으로 보여 줍니다.
- 서적의 실물 소유, 판본, 개인의 해독·이해·실습을 나눴습니다. 교육과 전수, 제작과 치료, 진법 유지에 실제 시간과 물품이 필요합니다.
- 물품의 소유·보관·수납·장착과 예약, 시장의 거래·경매·운송을 공통 실물·자원 원장으로 연결했습니다.
- 현지 탐색으로 비경 입구를 발견하고 개방 시기와 자격을 확인해 입장합니다. 실제 도구·식량·시간을 사용하고 유한 보상을 두고 경쟁하며, 진행·중단·귀환 상태를 저장합니다.
- 가계의 양육과 출산, 생물학 계보와 영혼 계보, 열세 윤회 경로를 구분합니다. 기본 세계는 혈연 후손 간 관계를 허용하고 양친 모두 금단 이상일 때 출산합니다. 새로운 육신이 과거 경지·숙련·재산을 자동으로 복제하지 않습니다.
- 인간과 비인간 종족의 육신·성숙·서식 조건을 구분하고, 기예 시연·진술·서약과 교육에는 상대의 요청·동의·거절을 반영합니다.
- 종문·왕조의 주권과 사유 재산, 정책 준비금과 실제 시행, 승계·채권·급여·세금을 각각 처리합니다.
- AI는 개인의 관측과 기억으로 생존·수행·생업·관계·정치를 판단합니다. 잘못된 믿음과 입문·생계 실패 뒤 관측·학습·이동 계획을 다시 세우며, 실제 채광한 영석만 소비해 환전합니다.
- 지도·수행·물품·세력·연대기 화면을 넓히고, 좁은 창·글자 확대·한국어·키보드·터치 조작을 다듬었습니다. 저장 중단·복원과 명령 재전송을 검증합니다.
- 작은 저장의 기존 형식을 유지하면서 큰 세계를 UTF8 이진 봉투로 저장합니다. 길이·순번·체크섬을 검사하고, 손상된 원본과 유효한 백업을 보존합니다.

기존 앱 ID와 배포 인증서를 유지하는 오프라인 APK입니다. Android 7.0(API 24) 이상을 대상으로 arm64-v8a와 x86_64를 한 파일에 제공합니다.

기존 0.2.0 저장의 연속 플레이는 지원하지 않습니다. 이전 저장 원본을 보존하며 새 세계·새 슬롯으로 시작합니다. 설치·업데이트·실제 화면 실행과 최종 성능 결과는 게시 시 연결되는 검증 기록에서 확인할 수 있습니다.
