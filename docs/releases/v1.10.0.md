# ALPHA EXCHANGE v1.10.0

투자자만 판단하는 15종목 시장으로 재구성했습니다. 5업종에 종목을 3개씩 두고 기관 100곳과 개미 10,000명이 실제 자금·호가로 경쟁합니다.

## 변경

- 경영자·정치인·금융인·직원 AI, 선거·투표·고용·사업 프로젝트·은행 자동 호가와 관련 화면·저장·아트워크를 제거했습니다. 경영·정책·금융·업종은 시드 난수의 공개 사건으로 변합니다.
- 기관별 15종목 목표 비중, 현금·업종·종목 한도, 예상 비용, 손절·익절·기한·손실 예산과 매집/추격 유도/분산 매도/철수 전략을 추가했습니다. 약 15~30분마다 재평가하고 실제 자금·주식으로 공격적으로 호가를 경쟁합니다. 개미는 시장·주가·뉴스 방향을 따릅니다. 기관의 이익을 보장하거나 주가를 임의로 움직이지 않습니다.
- ‘만·억·조/정확한 숫자’ 전환과 금액 상세를 추가했습니다. 통계 7탭, 기업 재무·분석 7탭, 기관·개미 재무 6종으로 현금흐름·자본변동·손익 기여·집중도·충격 분석·실제 집단 간 거래대금을 확인합니다.
- Core의 거래·기관·기업·이벤트 경제·보관 책임, Android 재무 화면을 정리했습니다. 사용하지 않는 모델·규칙·전달 계층과 100명분의 추가 초상화를 제거했습니다. 앞으로의 기준은 [개발 규격](../guides/development-standard.md)입니다.

## 시장 시작과 이전 기록

앱 ID와 기존 배포 서명키를 유지합니다. 저장은 상태 9/SQLite 6으로 바뀌며 **새 15종목 시장을 시작합니다**. 이전 30종목 시장은 원래 파일에 그대로 남고 로비 또는 기록 화면에서 원본·WAL·체크섬을 ZIP으로 내보낼 수 있습니다. 이전 보관본은 현행 시장의 가져오기 파일이 아닙니다. 앱을 삭제하기 전에 필요한 기록을 내보내세요.

새 시장은 시총 1조, 기관별 10억, 개미별 5천만으로 시작합니다. 개미가 처음부터 10,000명인 만큼 1인 자금을 조정해 개미 총 초기자금 5천억을 유지합니다. 초기 주식 배정과 교체 IPO는 실제 납입으로 이루어집니다.

## 설치

Android 8.0 이상, ARM64 또는 x86_64를 지원합니다. 서버·계정·인터넷 권한이 없습니다. APK는 이 버전의 GitHub Release에 제공합니다. 서명 개인키는 공개하지 않습니다.

## 검증

검증 진행 중입니다. 최종 호스트·Android 네이티브 결과와 APK 체크섬은 배포 전에 이 문서에 기록합니다. 재평가 기회와 위험 검사를 늘린 것이며 지능·수익률 자체가 두 배라는 주장은 하지 않습니다.
