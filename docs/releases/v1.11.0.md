# ALPHA EXCHANGE v1.11.0

- 하루 가격 제한은 전일 기준가의 **−30%~+30%**입니다. 주문과 체결 양쪽에서 검사하며 자정·배당락·주식 분할에도 적용합니다. 종목 상세에 상한·하한을 표시합니다.
- 새 기관 투자자의 초기 자산은 **100억 원**입니다. 초기 주식을 실제 자금으로 배정하며 성향별 현금 목표는 5~30%입니다. 기관 AI 매도는 주식 50% 하한을 검사하고 대기 매도까지 반영합니다. 가격 하락·기업 정산·미체결로 비중이 부족해지면 실제 매수로 회복합니다.
- 매 시간 장기 담당 종목과 순환 담당 종목에 기관들이 분산 호가를 냅니다. 유동성 호가와 전략 주문을 분리하고, 먼 가격의 호가를 무조건 체결하던 동작과 반복 매매·과도한 공매도를 줄였습니다. 상한·하한에 주문이 몰리면 한쪽 호가만 남을 수 있습니다.
- 모든 회사가 개별 뉴스 일정을 가집니다. 회사별 수요·정책·금리·물가 노출이 달라 같은 경제 사건에도 매출·비용·투자 신호가 다르게 반응합니다. 뉴스는 가격을 직접 변경하지 않습니다.
- 통계는 **8개 탭**으로 구성합니다. 원형표, 업종·호가·비중 막대그래프, 시간 추이, 참여 기관·투자 성과 표를 함께 제공합니다. 금액은 만·억·조와 정확한 원 단위로 확인할 수 있습니다.
- 투자자 목록·랭킹·상세에 **투자 성공 횟수**를 표시합니다. 부분 체결을 합산해 한 종목을 전량 정리했을 때, 수수료와 해당 거래 세금을 뺀 매매이익이 양수면 1회입니다. 배당·금융비용은 별도 재무 항목이며 기업행동으로 기준이 섞인 투자는 성공 집계에서 제외합니다.
- 변하지 않는 이력 신호와 일일 가격 범위를 재사용합니다. Android의 분 단위 잠금, 비동기 저장, 원기록 보존, 제한된 화면 캐시는 유지합니다.

## 설치와 기존 기록

[APK 다운로드](https://github.com/hddy774/project-hora/releases/download/alpha-exchange/v1.11.0/AlphaExchange-v1.11.0.apk) · [릴리스](https://github.com/hddy774/project-hora/releases/tag/alpha-exchange/v1.11.0)

Android 8.0(API 26) 이상, ARM64/x86_64용입니다. 앱 ID와 v1.10의 배포 서명을 유지합니다. 앱 버전은 1.11.0, 내부 버전은 12이며 인터넷 권한이 없습니다.

v1.10 시장은 현금·주식·시간·이력을 보존하여 이어갑니다. 이관 시 대기 주문을 해제하고 현재가를 첫 가격 제한 기준으로 삼습니다. 초기자금 차액을 기존 잔액에 추가 지급하지 않으며, 기존 보유분의 과거 성공 횟수도 소급 생성하지 않습니다. v1.9 이전의 30종목 기록은 별도 원본 보관·내보내기를 유지합니다.
