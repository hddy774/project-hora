# v1.2.0 · 기관 판단과 시즌 경제

**설치 안내:** 사용자 요청에 따라 GitHub Actions에서 새 서명키를 자동 생성했습니다. 기존 v1.1.0 앱에 덮어쓸 수 없으며 기존 앱 삭제 후 설치해야 합니다. 앱 삭제 시 로컬 저장 데이터가 삭제될 수 있습니다. 키는 실행 종료 시 삭제되어 다른 빌드에서 같은 서명을 재사용할 수 없습니다.

대표의 10개 능력치와 성향에 따른 혼합 투자 판단, 분산 포트폴리오, 하락장 현금 확보·부채 축소·공매도 헤지를 추가했습니다.

- 수익률·순수익·순자산·현금·거래량·거래금액 랭킹과 현재 시즌/전체/10일/5일/전일 비교.
- 통계·기업 결산의 그래프, 막대, 원형표와 비교 표. 기업 재무 5종을 뉴스·정책에 따라 매월 갱신.
- 50/100배속, 신규 CLUD·CARE 종목, 기관 공매도와 담보·상환·대여료 회계.
- 시즌별 정부 세금·수수료·금리·규제·보조금. AAA~C 9개 신용 등급의 은행 대출과 이자.
- 대표 상호작용·공동 작전 UI, 적발/목표 실패에 따른 벌금과 미납 부채.
- 기존 v2/v3 저장을 원본 보존하며 v4로 이전. 기존 기관의 현금·보유 종목·성적 유지.

APK는 GitHub Actions에서 병합된 태그로 빌드합니다. APK의 서명이 이번에 생성한 인증서와 일치하는지, 앱 ID/버전이 올바른지 검증하고, 업로드한 파일을 다시 내려받아 SHA-256을 확인한 뒤 최신 릴리스로 공개합니다. 서명 방식과 공개 인증서 지문은 SIGNING-INFO.txt, 빌드 실행의 실제 검사 결과는 CORE-CHECKS.txt와 ARTWORK-CHECKS.txt에 포함됩니다.

Android 8.0 이상 ARM64/x86_64, 완전 오프라인 관찰 게임입니다. 세부 검증 범위와 실제 기기 검증 제한은 VERIFICATION.txt를 참고하세요.
