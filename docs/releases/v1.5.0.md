# v1.5.0 · 시장 반응 AI·주주 경영·파산과 성능 개선

- 개인 AI는 가격 흐름과 거래량에 반응합니다. 가치·재무·배당 분석을 제거하고, 기관은 능력에 따라 분산·가치·추세·거래 비용·위험을 판단합니다. 보통은 유리한 지정가로 기다리고, 강한 투자 신호나 청산 필요 시 유동성을 사용합니다.
- 전체/6분야 탭으로 회사 목록과 재무·주총의 종목 선택을 나눕니다. 신규 시장/회사는 자사주 50%, 은행 50%로 시작합니다. 투자자는 현금으로 은행 물량을 매수하며 기존 저장의 실제 보유는 유지합니다.
- 은행은 실제 현금·주식으로 안정화 호가를 제출합니다. 과열에는 공급, 하락에는 제한된 매수로 대응합니다. 기업은 여유 현금으로 자사주 비율을 확대합니다.
- 회사 지분 화면에서 **주주총회**로 이동하면 성장/가치/방어 전략, 설비/비용/유동성 경영, 재투자/자사주/배당 정책과 지분 가중 가결/부결을 봅니다. 자사주·공매도 반환 청구권에는 의결권이 없습니다. 의결 결과가 월말 매출·비용·투자·배당·상환에 반영됩니다.
- 기업·기관·개인은 파산할 수 있습니다. 자산/채무를 정산하고 새 회사 식별자·투자자 세대로 교체하며, 재출자는 실제 경제 자금에서 지급합니다. **통계 → 파산 기록**에서 사유·당시 자산·미회수·재출자를 확인합니다. 과거 기록과 거래량/대금은 교체 후에도 이어집니다.
- 개인의 불필요한 개별 그래프/랭킹 복사본과 기본 통계의 반복 그래프/표를 정리했습니다. 재무 집계·판단·임금/소비 원장·저장 복사를 줄이고, v6 상태를 압축 저장합니다. 원본 시간별 기록·월별 결산·시즌·주총·파산은 SQLite와 ZIP에 보존합니다.

공개 첨부 파일은 **AlphaExchange-v1.5.0.apk 하나**입니다. Android 8.0 이상 ARM64/x86_64, 완전 오프라인이며 100배속을 지원합니다. 개발 진행표·시장 분석·성능 원자료·검증 근거는 저장소에 기록합니다.

**설치 안내:** 요청대로 기존 서명키 없이 GitHub Actions에서 새 임시 키로 서명합니다. 기존 앱에 덮어쓸 수 없으므로 **기록을 ZIP으로 내보낸 뒤 삭제 → 새 APK 설치 → ZIP 가져오기** 순서로 진행하세요. 앱 삭제는 내부 기록을 지웁니다. v1.2에는 내보내기 기능이 없습니다.
