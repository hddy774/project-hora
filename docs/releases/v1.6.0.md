# v1.6.0 · 기관 성장·직원·투자 판단과 양방향 호가 개선

- 실시간 호가의 매수·매도 열을 바로잡고, 은행이 실제 현금·주식 범위에서 소진된 잔량을 보충합니다. 주식 공급이나 자금이 부족하면 원인을 표시합니다.
- 기관은 평가 총자산의 5~30%를 현금 목표로 삼습니다. 종목/분야 비중·부채·공매도 담보를 관리하고 가치·뉴스·배당·추세·왕복 비용으로 판단합니다. 실제 비중은 초기 배치·유동성 부족·급변 시 목표 밖일 수 있습니다.
- 초단기는 시간~1일 미만, 단기는 1일~10일 미만, 장기는 10일 이상입니다. 20일·30일 이상 보유할 수 있고, 중요한 뉴스·위험 변화에 따라 계획을 바꿉니다. 계획 기간과 실제 보유 기간을 따로 표시합니다.
- 모든 대표의 10개 능력이 각각 50점에서 출발합니다. 시즌 상대 수익률의 상위 50/40/30/20/10/5/3/2/1위 구간에서 포인트·신용 보상 하나를 지급하고, AI가 부족한 능력을 성장시킵니다. 포인트는 능력별 100점 상한까지 배분하며 남은 포인트와 실제 지급 내역을 보관합니다.
- S/A/B/C/D 직원의 등급·역할·인원이 조직 능력에 반영됩니다. 대표 50% + 직원·조직 50%로 10개 기관 능력을 만들고 실제 판단에 사용합니다. 채용비와 급여를 실제 지급하며 예산 안에서 고용합니다. 단일 S급 직원의 기본 능력은 초기 대표보다 낮습니다.
- 대표 프로필에 누적 거래량·거래금액·수익률을 표시합니다. `자산 → 대표·은행`의 기관·능력/직원/시즌 보상/투자 기간 탭과 시즌 결과에서 성장 내역을 확인합니다.
- 전 종목 반복 계산·불필요한 주문 취소와 화면 갱신을 줄입니다. 순위/호가 집계 캐시, 문자열 일괄 측정, 제한된 틱 작업과 저장되는 대기 시간으로 고배속 화면의 작업을 분산합니다. 완료된 시간별 통계는 계속 보관합니다.
- 능력 합성·보상·직원·기간/집행·은행 유동성·화면 주기를 버전이 있는 오프라인 JSON 규칙으로 분리했습니다. 저장은 실행 규칙까지 보존하고 기존 금융·통계·주식·과거 능력 기록을 이어갑니다. 상태 JSON7, SQLite/ZIP5입니다.

공개 첨부 파일은 **AlphaExchange-v1.6.0.apk 하나**입니다. Android 8.0 이상 ARM64/x86_64, 완전 오프라인이며 100배속을 지원합니다. 개발 진행표·금융 조사·측정 원자료·검증 근거는 저장소에 기록합니다. 기기별 고배속 처리량과 실제 호가 공급은 달라질 수 있습니다.

**설치 안내:** 요청대로 기존 서명키 없이 GitHub Actions에서 새 임시 키로 서명합니다. 기존 앱에 덮어쓸 수 없으므로 **기록 ZIP 내보내기 → 앱 삭제 → 새 APK 설치 → ZIP 가져오기** 순서로 진행하세요. 삭제는 내부 기록을 지웁니다. v1.2에는 내보내기 기능이 없습니다.
