# ALPHA EXCHANGE v1.9.0

유지보수와 Android 실행 비용을 우선해 구조를 정리한 버전입니다. 기존 경제 규칙·저장 형식·앱 ID·v1.8.0 배포 서명키를 유지합니다.

## 변경

- Core의 모델·시뮬레이션·보고·저장·규칙을 구분하고 큰 모델·SQLite 파일과 저장 함수의 책임을 나눕니다.
- 공통 Client 프로젝트를 추가해 Android와 검사의 중복 소스 컴파일을 제거합니다. 화면 이동에 이름 있는 타입을 사용하며 실행·저장·입력·Canvas·화면을 분리합니다.
- 차트 버퍼·Path를 재사용하고 화면 밀도에 맞춰 초상화와 로비 그림을 디코딩합니다. 초상화 캐시에는 개수·픽셀 바이트 예산을 적용합니다.
- 순위 계산을 Core로 통일하고 통계의 가격 조회를 일괄 처리합니다. 회계 누적·반올림 규칙은 동일합니다.
- 새 시장 생성과 저장 준비·디스크 완료를 기다리는 작업이 UI를 막지 않도록 처리합니다. 기존 체크포인트를 보존한 뒤 새로운 시장을 저장합니다.
- [개발 규격](../guides/development-standard.md)을 AGENTS.md와 CI 검사에 연결합니다. 과거 문서는 이력 폴더로 정리합니다.

## 설치

[AlphaExchange-v1.9.0.apk](https://github.com/hddy774/project-hora/releases/download/alpha-exchange/v1.9.0/AlphaExchange-v1.9.0.apk)를 설치하세요. Android 8.0 이상 ARM64와 x86_64를 지원하며 인터넷 권한 없이 실행합니다. v1.8.0과 같은 키를 사용하므로 v1.8.0 위에 업데이트할 수 있습니다. 최초 설치도 가능합니다.

앱 ID는 `com.alphaexchange.offline`, 버전 코드는 10입니다. 개인키는 공개 릴리스·소스에 포함하지 않습니다. 이후 배포에도 사용자가 받은 기존 새 키를 계속 사용합니다.

[구조 설명](../guides/architecture.md), [전후 성능과 한계](../performance/v1.9.0/README.md), [검증 원자료](../verification/v1.9.0)를 참고하세요. 실제 처리량은 기기 성능에 따라 다르며 호스트 측정은 휴대전화 FPS·배터리 결과가 아닙니다.
