# [M0-02] 현재 금액·물량·단위와 보존 계약

## 목표와 실제 모델

현재 `Person.Money`, 세계 CreatedMoney/ConsumedMoney, 물품 Quantity와 재료 원장을 사용한다.
재화는 정수이며 금액·물량·품질/비율의 단위를 섞지 않는다. 다른 게임의 USD/센트/환율이나
새 Money/Quantity 타입으로 현재 저장 모델을 임의 교체하지 않는다.

## 동작 계약

- 거래는 실제 상대의 잔액/예치·소유/보관·예약을 검증한다. 숨은 구매자/무한 잔액을 두지 않는다.
- 제작/채집/소비/손실/이동은 실제 실물·원장 원인으로 설명되고 같은 원인을 두 번 적용하지 않는다.
- 영석 환전은 현재 `CurrencyPolicy`의 resource.02.0 실물과 법칙 단위/거부 조건을 따른다.
  영석 소각과 Money 발행의 실제 영수증을 보존한다.
- 0/음수/한도/오버플로·부족/예약/원격 접근·중복 명령을 확인한다.
  실패하면 돈·물품·재료 원장·ID/RNG를 부분 변경하지 않는다.

- [ ] 기존 실제 `INV-016/017/018`, currency/재고 시나리오 중 바뀐 계약의 정상/거부·저장 사례를 선택한다.
- [ ] 거절·같은 ID 재전송·저장 속행에서 실제 총량과 영수증이 맞는다.
