# XO-02 — 선협 관찰 전체 문서와 클로드 검토 자료

사용자 요청: “해당 게임의 모든 기획과 기술적 문서 작성해줘. 클로드에게 피드백을 요청할거야.”
사용자가 Codex에게 문서 작성을 명시적으로 지시했다. 기획 검토와 최종 결정은 이후 클로드 피드백과
프로젝트 오너의 선택으로 진행하며, 현재 구현에서 복원한 의도와 제안을 승인된 기획으로 표시하지 않는다.

## 범위

`games/xianxia-observer/docs/`에 현재 소스·공개 APK를 기준으로 기획, 전체 규칙·콘텐츠,
UI, 아키텍처, 데이터·저장, 빌드·배포, 검증 범위, 요구 추적, 후속 제안, 설계 결정과 열린 질문을 정리한다.
데이터 사전·소스/테스트 색인·실제 수치·격리 재현·장기 시드 표본과 클로드에게 전달할 요청문을 포함한다.
전달 편의를 위해 통합 Markdown과 ZIP을 작업 산출물로 만든다. 게임 코드·저장 형식·APK는 변경하지 않는다.
기존 경제 게임과 루트 Hora 기획은 수정하지 않는다. 이번 문서 묶음을 공개 릴리스 asset에 추가하지 않는다.

## 수용 기준

- [x] 구현·실측·해석·제안의 상태와 소스/APK 기준 커밋을 명시한다.
- [x] 기획·수식·카탈로그·일곱 화면과 상세·스레드/난수·모델/저장·Android/배포를 문서화한다.
- [x] 49개 기존 검사와 실제 Android 증거의 한계를 구분하고 신규 다중 시드·재현 자료를 남긴다.
- [x] 코드 근거가 있는 검토 항목과 미승인 수용 기준 제안, 복사할 클로드 요청문을 제공한다.
- [x] 상대 링크·표·JSON·수치와 문서만 변경됐는지 검사한다.
- [x] 저장소 필수 포맷·빌드·테스트를 통과하고 통합 검토본·ZIP을 준비한다.
