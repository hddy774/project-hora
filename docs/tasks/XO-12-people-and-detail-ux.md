# [XO-12] 인물 탐색·상세·개입·저장 UX

상태: 승인(사용자 전체 개발 지시, 2026-10-29) · 선행: XO-11·XO-06·XO-05 · 근거: [15 §3~5](../../games/xianxia-observer/docs/15-ui-ux-improvement.md).

## 배경과 범위
인물을 찾고 상세를 읽고 목록으로 돌아오는 흐름을 끊지 않으며 무료 관찰과 천기 소비를 구분한다.
포함: `Pages/PeoplePage`, `Services/PeopleQuery`, `Sheets/Cultivator*·RegionSheet·SettingsSheet`, 목록 UI 상태.
정렬8종·한 페이지20명·원래 수식·수치·저장 슬롯 수는 유지한다.

## 계약과 동작
1. 검색어·소속/관심·정렬·페이지·스크롤을 UI 상태로 유지한다. 뒤로 복귀 때 같은 인물을 찾을 수 있게 한다.
2. 새 세계/불러오기 **성공** 때만 새 세계 안내와 목록 초기화. 실패 시 현재 필터·세계 유지.
3. 검색48높이, 소속/관심 필터, 현재 정렬값+선택 패널, 결과 목록, 페이지 순. IME 중에도 입력과 결과에 접근한다.
4. 인물 상세 `개요/수행/인연/생애` 네 분류. 원래 전투력·소지·윤회 정보를 각각 개요/수행/생애에 모두 매핑한다.
5. 관심은 즉시 토글, 기연은 대상·경지·효과·비용2·남은 천기를 확인한 뒤 코어 계약으로 한 번만 실행한다.
6. Region의 비경/수조도 코어 Can…을 사용하고 거부 이유를 표시한다. 명세 승인된 본산 정책을 따른다.
7. 저장 상태·복구·새 세계 영역을 구분한다. faulted에서는 저장/재개를 막고 정상본 불러오기·새 세계를 안내한다.
8. 대상 윤회/비승·조회 실패 시 현재 상태를 다시 조회하며 다른 영혼에 잘못 개입하지 않는다.

## 수용 기준
- [x] 검색→필터→2페이지→상세→뒤로 후 검색·정렬·위치가 유지된다.
- [x] 원래7분류의 필드/링크를 대응 표로 검사하고 새4분류에서 모두 접근 가능하다.
- [x] 개입 확인 취소·잔액 부족·대상 소멸·중복 클릭에서 천기 불변, 정상 확인은 정확히 한 번 차감한다.
- [x] 성공한 세계 교체만 UI 상태를 초기화한다. 오류 상태에서 저장 금지·복구 조작을 확인한다.
- [x] 360폭·큰 글자·검색 IME·뒤로 입력/렌더 증거를 첨부한다.
- [x] 포맷·코드 규칙·Release 경고0·전체 테스트, 관심 A/B·저장 연속성 회귀를 통과한다.
