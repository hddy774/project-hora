# [XO-13] 천하 관찰 진입·사기·기록 탐색

상태: 승인(사용자 전체 개발 지시, 2026-10-29) · 선행: XO-12·XO-08 · 근거: [15 §4~6](../../games/xianxia-observer/docs/15-ui-ux-improvement.md).

## 배경과 범위
첫 화면에서 지켜볼 인물과 최근 사건을 찾고, 요약에서 상세·이력으로 이동할 수 있게 한다.
포함: `Pages/WorldPage·HistoryPage·LogPage·LegacyPage·StatsPage`, 추천용 읽기 질의, `Views/ToastHost`.
새 사건·보상·난수·통계 수집·세계 저장 필드를 추가하지 않는다. 기존 보관 한도를 따른다.

## 계약과 동작
1. 천하는 시대/전쟁→관심/추천→최근 주요 사건→종문 비교→지도를 기본 순서로 제안한다.
2. 추천은 보관된 최근100년의 돌파/대회 관련 생존 ID 중복 제거, 최신 연도 내림차순·ID 오름차순 최대3명.
   후보0이면 현재 전투력 내림차순·ID 오름차순3명. 카드마다 추천 이유와 데이터 보관 한계를 설명한다.
3. 사기의6분류·기록의 종류/관심 필터·페이지를 유지한다. 천하 `기록 전체`는 기록에 바로 연결한다.
4. 빈 결과는 조건과 초기화/인물 찾기/기록 보기 행동을 제공한다. 기록 누계와 보관 범위를 구별한다.
5. 토스트 화면 최대1개. 상세 또는 IME가 열렸으면 표시를 보류하고 복귀 후 최신 보관 알림부터 읽는다.
   읽은 알림을 세계 사건으로 다시 발행하지 않으며 표시 정책이 RNG·코어 상태를 바꾸지 않는다.
6. 시계열 x좌표는 실제 샘플 연도 비례. 색+이름 범례와 현재값/누계·단위를 표시한다.

## 수용 기준
- [x] 추천 후보·중복·동점·기록0건·대상 소멸을 검사하고 같은 입력의 질의 결과가 일정하다.
- [x] 관심0명에서도 첫 화면의 행동으로 인물 상세를 열고 관심을 지정할 수 있다.
- [x] 기존 사기6분류·기록 필터·업적·통계를 모두 탐색하고 사건에서 관련 상세를 연다.
- [x] 상세/IME 중 토스트가 가리지 않고, 표시 전후 세계 RNG와 코어 상태가 같다.
- [x] 압축 샘플의 연도 차이를 반영한 차트와 범례를 확인한다.
- [x] 포맷·코드 규칙·Release 경고0·전체 테스트, 360폭/큰 글자 PNG·입력 근거를 첨부한다.

`Toast_DefersDuringSheetOrIme`, `Chart_UsesSampleYears`. UI-QA는 15 §6의 Android·복귀 경로를 함께 수행한다.
