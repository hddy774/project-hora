# PC 0.0.19 장기 행동·수행 조건 수직 계약

## 사용자 확정 계약

- AI 행동 기간은 최소 1개월, 최대 1만년이다.
- 수행 계획이 정한 기간에는 다른 행동을 선택하지 않는다.
- 계획은 기간, 위치, 폐관/여유, 소비 자원, 수행 진법과 설치 주체/지식/경험을 가진다.
- 스승과 제자가 함께 수행할 수 있다. 스승의 수행 진척은 줄지 않고 학습자는 양측의
  자질·지식·경험에 따른 별도 진척 보너스를 얻으며 교사는 가르친 수행 경험을 얻는다.

## 권위·전이·성능 계약

- `CultivationActionPlanState`가 수행 계획의 authority revision과 모든 동결 조건,
  진행 월수와 실제 소비량을 소유한다.
- `World.CultivationPlans`는 계획 경계에서만 조건을 선택한다. 활성 계획은 위치가
  달라지거나 기간이 끝나고, 병목·돌파·안착 pipeline 경계에 닿을 때 종료한다.
- 같은 장소에서 양쪽의 현재 행동이 모두 수행일 때만 사제 공동 수행 역할을 만든다.
- 여유/일반/폐관은 각각 최대 6/12/24개월마다 due item 하나를 예약한다. 안정적인
  Realm Work는 다음 경계까지 일괄 계산하고 자원·돌파·RNG 상태는 월 단위 전이를 쓴다.
- 수행 pulse 동안 Goal/Plan/Task/Action, causal revision과 소셜 상호작용을 다시 만들지
  않는다. 개인 로그는 첫 달과 매 12개월에 기존 행의 지속 기간만 갱신한다.
- 전투력·경지·부자 랭킹의 이전값은 해당 행동이 실제 입력을 바꿀 수 있을 때만 캡처한다.

## 저장·관찰 계약

- 계획, 수행 경험과 진법 설치 경험은 schema 25 authority payload, state hash와 손상
  검증에 포함한다. partner Ref, 기간, enum, 예산/소비와 동결 계수의 범위를 검증한다.
- 인물 수행 상세의 `현재 장기 수행 계획` Expander는 닫힌 동안 계획 문구를 계산하지
  않는다. 펼친 경우에도 `기간·장소`, `자원·진법`, `가르침·효율` 내부 탭을 사용하고
  중첩 스크롤을 만들지 않는다.

## 임시 검토 ID revision 1

- `PC-TEMP-CULT-ACTION-DURATION-019`: 경지별 계획 기간과 여유 1/10·일반 1/3·폐관 1배
- `PC-TEMP-CULT-CONDITION-FACTOR-019`: 강도·자원·진법 50~200% 종합 계수
- `PC-TEMP-CULT-FORMATION-INSTALL-019`: 이해 30.00 설치 자격과 지식/경험 성공률
- `PC-TEMP-CULT-JOINT-TEACHING-019`: 학습 흡수 상한 130%와 교사 경험 월 100
- `PC-TEMP-MARKET-STARTER-DEMAND-019`: 최초 실물 공급 전 시작 수요와 임무 잉여 1~2개

이 값들은 승인된 Notion 수치로 위장하지 않는다. UI `RequiresReview`, 이 문서와
변경 이력에서 다음 버전 검토 대상으로 유지한다.
