# v1.11.0 검증 기록

## 기능·회계

첫 구현 `0cd7a25`는 전체 24,518,783개 검사와 16시즌·저장 재개, 6,718,673회 체결을 통과했다. `full-checks-initial.txt`는 당시 호스트 원문이다. 현금·주식·대여·예약 보존, 원 단위 재무 등식, 가격/시간 우선, 자기 체결 금지, 세금 환급·배당·기업행동·파산·원기록 저장을 검사한다.

최종 가격·비중 검사 990,794개와 투자자 설계 검사 626,808개가 통과했다. 가격·비중 검사에는 현금만 보유한 기관의 실제 매수 회복, 부분 체결 비용·세금과 투자 성공 횟수, 3일 동안의 15종목 시간별 호가 참여, 회사별 정기 뉴스와 금융 사건의 서로 다른 방향, 상태 9 이관과 결정적 저장 재개를 포함한다. 한 달 결산으로 배당이 지급된 시장에서 추가 1,440분을 진행해도 캐시를 사용한 실행과 매 분 이력을 다시 계산한 실행의 전체 상태가 같아야 통과한다. 새로운 포지션 성과 배열도 저장 캡처 후 변경으로부터 분리한다.

## Android

화면·생명주기 증거의 소스는 `0cd7a25`이다. [Actions 38567407066](https://github.com/hddy774/project-hora/actions/runs/38567407066), Android job `115863583224`, 원본 artifact `11896303544`에서 수집했다. APK 빌드와 전체 검사 작업도 통과했다. 최종 코드·문서 커밋의 재검증은 [PR #18](https://github.com/hddy774/project-hora/pull/18)의 Checks에서 확인한다.

- API 26 x86_64 에뮬레이터, 로컬 소스에서 빌드한 실제 Android 앱 실행. 인터넷 연결을 끈 상태다.
- 시장·투자자 프로필·초상화 확대·8개 통계 탭·정확한 금액 상세·회사 재무와 고정 5업종 필터를 탐색했다. 이 폴더에는 원형표·막대·표·호가 화면의 대표 PNG를 보관한다.
- 화면 높이 480/600/800에서 모달 본문 스크롤, 고정 닫기/버튼, 가려진 화면 입력 차단, 재개방 위치 초기화와 Activity 재생성을 검사했다.
- 8초 백그라운드 체류 동안 완료·대기 시간과 회계 거래 ID가 변하지 않았다. 저장 장벽 뒤 같은 시장으로 돌아왔다.
- 100배속 입력을 포함한 18.810초 동안 20,965게임분을 완료했고, 수락한 대기 71분은 저장했다. 입력 경계 허용치는 2초다. 일시정지로 남은 대기를 버리지 않는다.
- 실제 PSS 표본은 201,644~270,926 KiB였다. 에뮬레이터 프로세스 메모리이며 물리 기기의 FPS·배터리 측정이 아니다.
- 새 시장 전환 후 이전 시장의 완료 21,119분과 367개 원본 이력 행 해시를 보존했다.

`summary.json`, `modal-viewports.json`, `memory-samples.json`, `new-market-transition.json`이 원자료다. 이전 상태 8/SQLite 5의 DB와 백업은 바이트 SHA-256이 같았다.

## 실제 v1.10 저장 이관

Actions에서 `alpha-exchange/v1.10.0`의 실제 코어로 168시간 진행한 상태 9/SQLite 6 파일을 만들었다. 새 Android Activity에서 이 파일을 불러오고 진행 시간을 수락하지 않은 채 생명주기 저장을 수행했다. Core 재검증에서 상태 10, 동일 RunId·난수·완료 분·개별 현금·개별 종목 수량·현재가가 일치했고 모든 기존 시간별 행 해시를 유지했다. 결과는 `v110-upgrade.json`이다.

더 오래된 30종목 보관 검사와 v1.10의 동일 장부 이관을 구분한다. 초기자금 차액이나 과거 투자 성공 횟수를 만들어 넣지 않는다.
