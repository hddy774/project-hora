## 사용자 요청으로 적용한 UI/콘텐츠 보강

생성 네이비 스킨·청색 선택 상태·메트릭 카드·공사 단계·실제 등각 지도·고정 월 작업 영역으로 참고 이미지의 정보 위계를 재구성했다. 생성 UI 스킨/아이콘/조작 아틀라스, 건물/지형, 앱 아이콘을 리소스로 사용한다. 게임 수치·문자·버튼·차트는 실행 데이터에서 출력한다. 이미지 안에 고정 숫자를 그려 경제를 대신하지 않는다.

회사 대표 권한, 지분, 공직은 별도다. 공통 명령 등록부는 개인/법인/기관 맥락과 자격·권한·비용·정보를 검사한다. 계획에서는 자기 자금/재고/시간만 가예약하며 경쟁사의 재고·후보·부지를 편집 순서로 선점하지 않는다. 미공개 입찰과 경쟁사 개발/대출 정보는 UI 선택기와 조회에서도 걸러낸다.

전력/용수·진료·개발시간 등 서비스는 해당 월 제공 능력과 구매한 이용권이다. 미사용 능력을 실물 재고처럼 쌓지 않는다. 디지털 제품은 개발 진척·출시·라이선스·구독·플랫폼 호환성을 구분한다. 금융자산과 현금흐름·기존 주식 거래와 회사 신주 발행을 구분한다.

## 생활필수 수급/임금 규칙 보강

실제6개월 기준선에서 유휴 공정의 근로자에게 임금을 지급하지 않아 고용 중인204명이 필수 수요를 충족하지 못했다. 회사 자금은 남아 있었다. 고용 계약의 보장 보수·기지급 생산 임금 상계·유한 현금 지급·임금 체불의 양쪽 채권/부채와 청산 우선순위를 추가한다. 급여를 두 번 지급하거나 부족할 때 외부 자금을 생성하지 않는다.

초기 식품 가동 목표는 지역 수요와 재고/완충 전망을 사용하며, 제빵32배치·제분20배치·제빵소 추가 운영자1명/64시간과 대표 시급6/월6시간을 개시 계약에 명시한다. 이는 기본378인/작은84인으로 이어진다. 최종 성능/균형의 확정이 아닌 원인에 따른 실험 변경이며 수정 전/후 관측을 분리한다.
