## 사용자 요청으로 적용한 UI/콘텐츠 보강

생성 네이비 스킨·청색 선택 상태·메트릭 카드·공사 단계·실제 등각 지도·고정 월 작업 영역으로 참고 이미지의 정보 위계를 재구성했다. 생성 UI 스킨/아이콘/조작 아틀라스, 건물/지형, 앱 아이콘을 리소스로 사용한다. 게임 수치·문자·버튼·차트는 실행 데이터에서 출력한다. 이미지 안에 고정 숫자를 그려 경제를 대신하지 않는다.

회사 대표 권한, 지분, 공직은 별도다. 공통 명령 등록부는 개인/법인/기관 맥락과 자격·권한·비용·정보를 검사한다. 계획에서는 자기 자금/재고/시간만 가예약하며 경쟁사의 재고·후보·부지를 편집 순서로 선점하지 않는다. 미공개 입찰과 경쟁사 개발/대출 정보는 UI 선택기와 조회에서도 걸러낸다.

전력/용수·진료·개발시간 등 서비스는 해당 월 제공 능력과 구매한 이용권이다. 미사용 능력을 실물 재고처럼 쌓지 않는다. 디지털 제품은 개발 진척·출시·라이선스·구독·플랫폼 호환성을 구분한다. 금융자산과 현금흐름·기존 주식 거래와 회사 신주 발행을 구분한다.

## 생활필수 수급/임금 규칙 보강

실제6개월 기준선에서 유휴 공정의 근로자에게 임금을 지급하지 않아 고용 중인204명이 필수 수요를 충족하지 못했다. 회사 자금은 남아 있었다. 고용 계약의 보장 보수·기지급 생산 임금 상계·유한 현금 지급·임금 체불의 양쪽 채권/부채와 청산 우선순위를 추가한다. 급여를 두 번 지급하거나 부족할 때 외부 자금을 생성하지 않는다.

초기 식품 가동 목표는 지역 수요와 재고/완충 전망을 사용하며, 제빵32배치·제분20배치·제빵소 추가 운영자1명/64시간과 대표 시급6/월6시간을 개시 계약에 명시한다. 이는 기본393인/작은93인으로 이어진다. 최종 성능/균형의 확정이 아닌 원인에 따른 실험 변경이며 수정 전/후 관측을 분리한다.

임금 보강 후에도 다른 인물의 교육에 제빵 직원의 근무시간 전체를 강제로 배정하는 문제가 관측됐다. 교육 법인·강의에 동의한 직원·월16시간 한도·교실·종이/전력과 실제 강의료로 제공자를 제한한다. 도시별 학교를 실제 시설/직원/계정으로 초기 배치한다. 기본129회사/393인, 작은30회사/93인이라는 수치는 이 배치에서 나온다. 공장 직원이나 플레이어의 시간을 임의로 차출하지 않는다.


## 사용자 확정: USD·현실 단위·표시 환산·APK 전용 배포

기준 화폐는 USD, 내부 금액은 센트 정수다. 달러 입력은 소수점 둘째 자리까지 받고 센트로 정확하게 변환한다. 이번 화폐 표시 변경으로 기존 개시 자금/임금/가격을 일괄 배수로 늘리지 않는다. 이 값은 여전히 실험 밸런스이며 현실 시세를 재현한다고 주장하지 않는다. 기본 국가의 화폐는 모두 USD이고 EUR/GBP 외환 기능은 별도 거래와 유한 상대방을 유지한다.

큰 금액은 달러 기준 M(백만)/B(십억)로 축약한다. 원화 보기는 사용자가 정한 USD1=KRW1000의 고정 표시 환율이다. 예를 들어 $1M=10억원, $1B=1조원이다. 장부 금액·거래 통화·소비 예산은 원화 표시 설정 때문에 바뀌지 않는다.

상품은 품목별 실제 측정 단위를 사용하고, 물류·창고의 합산은 품목 수량에 단위당 질량을 곱해 같은 g 기준으로 계산한다. 화면은 kg/t를 사용한다. 이는 질량 한도 중심의 단순 모형으로 부피·축중·거리별 상세 연료 모델을 추가한 뜻이 아니다. 상품별 대표 규격·생산 수량·기술 계수는 실험 데이터다. 전문용어는 의미를 유지하며 짧은 쉬운말 설명을 붙인다.

구버전의 단위 의미와 물류 수량을 추정해 변환하면 재고/한도/운임을 왜곡할 수 있으므로 schema2는 명시 거절하고 원본을 보존한다. 기존 파일을 새로운 세계로 조용히 덮어쓰지 않는다. 새 파일의 세계 schema는3이며 파일 포맷은2를 유지한다.

v0.2.1부터 공개 GitHub 릴리스의 첨부는 APK1개다. 정확한 소스·테스트·미서명 입력·보관 게시자 서명·페이로드 보존·공개 다운로드 재검사는 유지한다. JSON/체크섬/Linux 자료는 공개 릴리스에 첨부하지 않고 CI/저장소 기록에서 구분한다.

진행 UI는 경제 상태 밖에서 완료된 처리 단계 또는 실제 작업량을 관측한다. 실행 시간이 늘었다는 이유만으로 퍼센트를 올리지 않는다. 전체 작업량을 모를 때는 현재 단계와 순환 막대를 표시한다. 단계 완료율은 예상 남은 시간과 구별한다.
