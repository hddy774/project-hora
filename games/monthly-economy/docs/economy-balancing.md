# 개시 배치와 근로계약 보강

2026-10-25 개발 중 발견한 실제 문제와 수정 이유다. 수치는 `experimental` 입력이며 사용자 확정 밸런스가 아니다.

## 관찰한 문제

수정 전 확장 세계의 6개월 관찰에서는 5·6개월 필수 수요 미충족이 증가했다. 6개월차에는 식품 재고가 남아 있는데도 구매하지 못하는 가계가 있었다. 상세 추적에서 필수품 부족을 겪은 204명이 모두 취업 상태였고, 그중 159명은 해당 월 소득이 0이었다. 해당 고용주들은 현금이 충분했다. 계약은 인물의 월 근로시간을 점유했지만 생산·공사가 없으면 실제 작업시간만 지급해, 기업이 유휴 인력을 비용 없이 붙잡는 구조였다.

초기 물리적 공급에도 별도 문제가 있었다. 제빵소는 지역 식품 수요보다 적은 재고를 보유해도 일률적인 재고 기준으로 2배치만 생산했다. 이후에는 두 운영자의 실제 시간에서 공공·정치 활동을 제외하면 필수 식품을 생산할 여유가 충분하지 않았다.

이전 관찰은 [수정 전 기록](observations/expanded-seed42-six-months-pre-final.json)에 보존한다. 그 기록을 수정 후 결과로 재사용하지 않는다.

## 적용한 규칙

- 고용계약에 근무 가능시간과 보장 유급시간을 별도로 기록한다. 기존 계약은 약정 시간을 보장하며 대표 경영은 계약의 6시간을 사용한다. 실제 지급한 해당 고용주의 작업 임금을 공제하고 차액만 지급해 이중 급여를 막는다.
- 유휴 시간 보장액은 기업 비용이다. 실제 기업 현금으로 지급하며, 부족액은 직원의 임금채권과 기업의 미지급 채무로 남긴다. 현금이 없는 회사에 돈을 만들거나 무관한 정부 급여·배당을 회사의 지급으로 대신하지 않는다.
- 월 진행·재로드·같은 급여 함수 재호출은 계약/월의 발생 식별자로 중복 지급하지 않는다. 지급 가능한 자금은 정해진 비례 배분과 시드 기반 잔여 배분을 사용한다.
- 초기 대표의 시급은 새로 임명되는 대표와 같은 `executive_hourly_wage`를 사용한다.
- 제빵 생산계획은 공개 인구에서 추정한 필수 수요와 안전 재고, 현재 실제 재고를 함께 사용한다. 실제 주문·지급·인력·원료 제약은 계속 적용한다.
- 최초 생성에서만 제빵소마다 실제 64시간 운영자 1명을 추가한다. 개인 ID·초기 자금 원천·고용계약을 개시 장부에 포함하며 기존 인물의 ID를 보존한다. 가동 후 부족분을 보충하는 인구·돈 생성 규칙은 없다.
- 실험 제빵 설비 용량을 32배치, 상류 제분 용량을 20배치로 조정한다. 추가 인력의 실제 시간과 원료·전력·용수·임금을 확보해야 해당 용량을 사용할 수 있다.

원본 정의는 `data/experimental.json`과 `data/lifecycle.json`이다. 실제 수정 후 실행 결과·시드·월·한계는 [검증 기록](validation.md)에 남긴다. 보장 임금으로 기업의 비용과 지급불능 가능성도 커지므로 영구 흑자·모든 가계 구매력·장기 균형을 보장한다고 해석하지 않는다.


## 강사 권한과 교실 공유

급여 수정 후의 관찰에서 구매력 문제는 줄었으나, 초기 교육 코드가 첫 번째 자격 보유자를 고르면 제빵 노동자가 다른 인물의 강의를 위해 소모되는 문제가 드러났다. 직원과 플레이어의 시간을 다른 기업이 임의로 가져갈 수 있는 경로였다.

수정에서는 도시별 실제 교육 시설과 법인·직원·개시 장부를 생성하고, 해당 고용계약에서 강의 업무에 동의한 자격 보유자만 강사가 된다. 인물별 강의 한도와 시설의 교실 배치 한도를 적용하고 실제 종이·전력·수강료·강사 임금을 사용한다. 전문 훈련과 일반 교육 서비스는 같은 교실과 인력 시간을 공유한다. 발전·급수 이후 훈련을 수행하고 남은 자원으로 다른 생산을 진행한다.

실험 수강료는 강의·보장 급여·운영 투입물을 부담하는 가격으로 보강했다. 임의의 공장 직원이나 교육 업무에 동의하지 않은 플레이어를 자동 강사로 차출하는 경로는 사용하지 않는다. 수정 전 단계별 관찰 자료는 그대로 보존한다.
