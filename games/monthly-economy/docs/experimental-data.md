# 0.2 실험 데이터의 단위와 변경 영향

Hora Economic Lab · 호라경제연구실의 경제 데이터는 `experimental`이다. 현재 기본 fixture는 version2 / rules experimental-0.2이며 산업·금융·인물·공공 모듈의 버전/내용 해시와 함께 저장한다. 아래 값은 검증 입력이며 사용자 확정 밸런스나 출시 성능 목표가 아니다. 금액은 최소 화폐 단위 정수이며 UI의 `100최소단위=1 CR` 표시와 구별한다.

## 초기 생활필수품/임금 보강 근거

수정 전6개월 관측에서 식품이438개 남아 있는데365개 수요가 미충족이었다. 미충족204명 모두 고용 중이지만159명은 유휴 공정 때문에 당월 임금0이었고, 가장 가난한 고용주도 현금10,980을 보유했다. 개시 재고가 있는 공정을 쉬면 아무 임금도 지급하지 않던 규칙이 주요 원인이었다. 계약 보장 보수를 명시하고 실제 작업 임금을 상계한 차액을 유한한 회사 자금에서 지급한다. 지급불능은 없애지 않고 근로자 채권/회사 체불 부채로 남긴다.

초기 식품 품귀에는 재고100이 있다는 이유로 도시당 생산10만 허용한 고정 감산 규칙과 노동시간 부족도 영향을 줬다. 식품의 가동 목표는 공개된 지역 필수 수요의10% 완충 전망과 실제 보유 재고로 계산한다. 제빵 설비32배치/월, 제분20배치/월, 제빵소에 실제64시간 계약의 운영자1명을 추가하는 개시 배치를 사용한다. 새로운 인물·계정·예금 대응·고용·임금은 시작 때 한 번 기록하며 게임 중 부족분을 무료로 보충하지 않는다. 기존 인물 ID를 유지하도록 이 추가 인물은 기본 배치 뒤에 생성한다.

대표는 기존 고용 대표 임명 조건과 같은 시급6·월6시간을 적용한다. 계수는 실험값이며 보강 후6개월 비교와 최종72개월/전체 CI를 통과한 결과는 검증 문서에서 별도로 기록한다.

교육 제공자는 교육 시설을 가진 법인과 강의 업무에 동의한 고용 계약으로 한정한다. 초기 학교의 강사 능력·교직원·재고·회사 자금도 개시 장부/배치에 기록한다. 강사당 월 강의 한도16시간·실제 교실 용량·수업당 종이1과 전력1을 사용하며 학생과 강사 모두 시간을 쓴다. 일반 공장의 직원/플레이어 시간을 임의로 강사에게 차출하지 않는다. 공통 명령으로 교육 운영 정책을 바꿀 수 있고, 정규 학교 서비스와 직무 수업은 같은 교실 용량을 공유한다. 기본 세계에는 추가5학교, 작은 세계에는3학교를 실제 부지에 배치한다.
