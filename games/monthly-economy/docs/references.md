# 참고 출처와 확인 범위

사용자가 제공한 기획서의 조사일은 2026-10-25다. 아래 C01~C19와 EX01~EX22의 URL 및 기능 요약은 **사용자 제공 조사 기록을 보존한 것**이다. 이번 구현 작업에서 해당 웹페이지를 새로 방문하거나 실행 파일·소스코드·버전별 실제 동작을 검증하지 않았다. 따라서 ‘이번 신규 조사로 확인했다’는 출처로 인용하지 않는다.

공식 공개 설명은 해당 기능의 참고 근거다. 숨겨진 수요함수·AI 의사결정·거래 원장·회계 완전성·전체 계산 순서까지 입증하지 않는다. 기존 게임의 상품 수치·명칭·이미지·UI 배치·음악·프로그램을 새 게임 자산으로 복제하지 않는다.

## 새 게임의 독자 요구와 제안

아래 기능은 위 자료에서 확인됐다는 주장을 하지 않는다.

- 모든 인물과 플레이어의 전체 명령·권한·정보·비용 동등성 및 자유로운 진로 변경.
- 정확히 3개 대륙·여러 국가·도시 실제 주체에서 올라오는 유한 세계 경제.
- 외부 월 단위 턴·계획 동시 확정·결정적 처리·복구 가능한 월 단일 커밋.
- 타일 부지·실제 자재·공수·장비·최소 기간을 연결한 건설과 다음 달 가동 제안.
- 국가 간 외교·외환·관세/제재·국가 군·유한 군수 예산과 계약 납품 경제.
- 모든 계정의 소유 분리·개시 장부·복식부기·운송 중 물량·노동·집계 불변식.
