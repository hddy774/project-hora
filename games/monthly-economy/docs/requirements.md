# 전체 요구 추적표

기준은 사용자의 「월 단위 경제 생태계 시뮬레이션 전체 게임 기획서」 0.1과 후속 요청이다. 후속 요청은 참고 이미지와 같은 세로 UI, 필요한 UI·아이콘의 이미지 생성과 실제 리소스 사용, 개발 중 기획 보강, 테스트 후 GitHub 최신 릴리스 배포를 포함한다.

현재 데이터 계약은 `schema_version: 3`, `rules_version: experimental-0.2-usd`다. 코드가 있는 기능, 실행으로 확인한 기능, 전체 기획의 완료는 구별한다. 아래 ‘구현’은 작동 경로가 있다는 뜻이며 수용 조건 전부를 통과했다는 뜻이 아니다. 검증 결과는 [validation.md](validation.md)에 기록한다. 미정 수치는 여전히 실험 데이터다.

선택하지 않은 계정·멀티플레이·클라우드·광고/과금과 미정 수명·상속·정치 체제 수·지원 기기·경제 규모는 사용자 요구에서 삭제하지 않고 별도 결정으로 남긴다. 출시 수치나 성능 목표를 임의 확정하지 않는다.

단위·생산식·물류 규칙이 달라진 schema2 저장은 자동 변환하지 않는다. 이전 파일을 보존하고 이유와 새 게임 경로를 안내한다. 세부 단위·용어는 [단위와 용어](units-and-terms.md), 실제 검사 결과는 [검증 기록](validation.md)을 따른다.
