# 요구 추적표

기준 문서: 사용자가 제공한 「월 단위 경제 생태계 시뮬레이션 전체 게임 기획서」, 설계 버전 0.1, 2026-10-25.

이 프로젝트는 기존 저장소의 알파 익스체인지 제품과 분리된 경제 게임 실험이다. 기존 APK, 루트 README, 서명·배포 작업을 이 게임의 구현 근거로 사용하지 않는다. 이 문서는 전체 목표를 보존하는 추적표이며 최종 게임의 완료 선언이 아니다.

## 판정 규칙

- **확정**: 사용자 직접 요구. 구현 편의를 이유로 삭제하거나 변경하지 않는다.
- **제안**: 확정 요구를 연결하는 기획 규칙. 현재 기본안으로 검토하되 변경 근거와 영향을 기록한다.
- **미정**: 사용자 확정값이 없는 결정. 개발에 필요한 값은 `experimental` 데이터로만 사용한다.
- **실제 구현**: 실행 가능한 코드와 검증 근거를 확인한 범위만 표시한다.
- **부분 구현**: 요구의 일부만 작동한다. 빠진 동작과 제한을 함께 표시한다.
- **계약/정의만 존재**: 데이터 구조·문서·화면 표시가 있어도 실제 정산 기능으로 계산하지 않는다.
- **미구현**: 실행 경로가 없다.
- **확인 대기**: 병렬 개발 중이며 최종 코드와 실행 결과를 아직 대조하지 않았다.

미구현 목표를 화면에 정상 사용 가능한 기능처럼 노출하지 않는다. UI에 보이는 수치도 코어에서 계산한 실제 값인지 실험 데이터인지 구분한다. 아래 상태는 이번 작업 트리의 코어·저장 코드를 대조한 범위다. 실행 판정은 별도 검증 기록을 따른다. 단계 이름이나 화면 존재만으로 충족으로 바꾸지 않는다.

## 제안을 확정과 섞지 않기

아래는 현재 기획 기본안이며 사용자가 확정한 값이 아니다.

- 하단 탭 이름 `메인 / 사업 / 시장 / 자산 / 확장`.
- 내부 탭을 최대 3단계로 해석하고 각 표시 묶음을 최소 3개로 구성하는 방식.
- 월말 준공 건물의 다음 달 가동. 완공과 운영 인력·투입물 확보를 구분한다.
- 생성형 AI API 없이 작동하는 규칙·계획·효용 기반 인물 AI.
- Android 단일 기기·오프라인 싱글플레이를 우선 검증하는 방식.
- 샌드박스, 실패 후 계속하기, 목표 달성 뒤 계속 플레이, 선택형 수명·승계.
- 데이터 모드 우선 지원, 클라우드와 계정은 선택 기능으로 분리하는 방식.

국가/도시 수·이름·시작 연도·인구·상품 수·가격·공수·임금·금리·세율·정치 제도·군 규모·성능 목표는 [decisions.md](decisions.md)의 미정 항목으로 관리한다. `experimental` 값이 코드에 필요하더라도 사용자 확정값이나 출시 밸런스로 승격하지 않는다.

## 구현 상태 갱신 절차

1. 해당 요구의 데이터 공급자·명령·권한 검사·상태 변화·저장 경로를 확인한다.
2. 명목상 엔터티나 정적 화면과 실제 정산을 구분한다.
3. [validation.md](validation.md)에 재현 명령·커밋·결과·한계를 기록한다.
4. 부분 충족은 빠진 동작을 유지한 채 갱신하고 [roadmap.md](roadmap.md)에서 제거하지 않는다.

## 현재 코어의 명시적 제한

- 현금 원장은 분개 균형·소유자·통화·잔고 재구성을 검사하지만 모든 지급을 송금자 비용/수령자 수익으로 분류한다. 재고원가·건설중자산·주식/채권·배당의 정식 회계와 중앙은행/은행 대응부채까지 구현한 것은 아니다.
- 초기 현금은 실험 소유자의 개시 자본으로 기록한다. 통화 발행·예금·은행 대차대조표를 가진 완전한 신용 경제는 후속 단계다.
- 구매는 실제 판매자 재고와 구매자 현금에 한정되고 시드 기반 순서를 사용하지만, 제한 주문장·동순위 비례 배정·권한별 사적 정보·계약 예약의 전체 모델은 아니다.
- 도시 간 운송은 운송 중 물량과 다음 월 도착을 표현한다. 경로·용량·연료/인력·보험·통관·외화·계약별 인도 조건은 미구현이다.
- 전력과 용수도 이 실험에서는 재고형 품목으로 취급한다. 기간별 미사용 공급능력 소멸을 구현한 최종 서비스 모델과 다르다.
- 현재 집계는 실험 현금흐름/품목별 활동 조회이며 GDP나 검증된 소비자물가지수가 아니다. 서로 다른 단위의 품목을 금액이나 물량으로 무조건 합산하는 정식 지표는 제공하지 않는다.
- 고정 세계와 실험 시드의 시험 결과는 여러 시드의 초기 배치 균형, AI 진입/퇴출, 전체 산업의 장기 생존, 출시 규모의 성능을 입증하지 않는다.
