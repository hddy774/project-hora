# 전체 범위 로드맵

이 로드맵은 사용자 기획 버전 0.1의 전체 목표를 보존한다. 단계 개발은 구현 순서를 정하는 것이며 농업·소프트웨어·자유로운 인물·금융·국가·세계 시장·정치·군수 기능을 삭제하는 근거가 아니다. 현재 실험 빌드와 출시 제품의 완성은 구분한다.

완료 판정은 [requirements.md](requirements.md)의 요구를 실행 가능한 코드와 [validation.md](validation.md)의 증거로 확인한 뒤 갱신한다. 아래 항목은 계획이며 이미 통과했다는 주장이 아니다.

## 단계와 독립적으로 유지할 품질 조건

- 매월 불변식 검사를 통과한 결과만 저장한다. 계층 확장 때도 같은 분개·재고·노동·권한 규칙을 사용한다.
- 검증 세계의 규모를 늘릴 때 여러 시드와 충격을 기록한다. 한 시드의 장기 생존을 자연스러운 전체 경제의 입증으로 확대하지 않는다.
- 일반 인물을 묶어 계산해도 ID와 창업·이직·취임 등 법적 행동권을 유지한다.
- AI와 반복 정책이 다음 달 명령에 따라 작동한다. 앱 대기·종료·실제 시간 경과는 달을 진행시키지 않는다.
- 장기 순환은 개시 완충 재고 소진 뒤 중간재·정비 부품·대체 설비·생산 인력의 재생산 경로까지 관찰한다.
- 인과 설명은 실제 이벤트·계약·장부에서 생성한다. 경쟁사 비공개 정보는 원인 추적 화면으로 우회 공개하지 않는다.
- 호황·불황·품귀·과잉투자·파산을 허용한다. 모든 기업 흑자나 영구 호황을 성공 기준으로 쓰지 않는다.

## 단계 보고 양식

각 단계 보고에는 변경한 실제 동작, 필요한 이유, 실행한 검증, 실패·한계, 미구현 요구, 사용한 실험 수치를 함께 쓴다. 테스트 통과 수만으로 경제적 타당성이나 출시 준비를 주장하지 않는다. UI·APK 빌드 성공은 월 경제 불변식 통과와 별개다.
