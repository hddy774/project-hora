# 전체 범위와 후속 검증

전체 목표는 사용자의 기획0.1을 유지한다. 이번 v2는 인물·산업·금융·정치/외교/군수와 생성 이미지 UI를 실제 명령·계정·물량·월 정산으로 연결한다. 대표 체인의 실행, 각 단계 수용 조건 전체, 출시 기기의 품질 검증은 서로 다르다.

| 단계 | 현재 실행 가능한 범위 | 계속 완료할 조건 |
|---|---|---|
| P0 | 버전/단위 정의·공통 명령·소유자별 원장·금융 대응부채·실물 재고 이벤트·시드·복제 정산·정상 이전본 저장 복구 | 모든 행동의 자기 자원 가예약·법적 정보 경계·극단값/형식·실제 OS/디스크 오류 주입·구버전 마이그레이션 정책 |
| P1 | 실제 도시 생산·구매·노동·소비·기간별 서비스·타일 공사·토지권/임대/허가·월 보고 | 공동 가계·주거/통근·상세 소매·복합 공사 도급/해체·준공/자산회계 경계 |
| P2 | 구직/고용·훈련·창업·대표 임면·지분·위임·자회사/인수·청산·자산 처분·인물 전환 | 복합 이사회/위임·이해충돌·개인 보증·실패 후 모든 재기 경로·선택형 수명/상속과 장기 행동 다양성 |
| P3 | 세 대륙·국가별 복수 도시·실제 화물/운송업체/연료·외환·관세/제재·도시 원장 기반 조회 | 국내/해외/경유 경계·부가가치/가격지수 정의 확장·대체 항로·복잡한 인도/보험/통관 계약·확장 규모 성능 |
| P4 | 농림축수산·자원/에너지·소재/화학·부품·소비/자본재·부산물·부패/재활용·연구/도입·디지털/구독·서비스·은행/증권/보험 | 전 산업의 개시 완충 재고 이후 자립/교체·대체재/품질/호환성 심도·고갈/재생산·신용/서비스 위기와 장기 밸런스 |
| P5 | 공직/정당/선거·정책 절차/발효·세입/예산·외교/협정·군 조직/보급·조달/검수/지급·추상 분쟁 | 다양한 정치 제도·공직 이해충돌·복합 예산/규제·분할 납품/보증/부도·외교/군수 충격의 민간 영향 실험 |
| P6 | 생성 네이비 스킨·아이콘/지도 이미지·세로 대시보드·실제 명령 폼·도움말·설정·저장/복귀/종료·정상본 보존 | 실제 Android 입력/접근성/중단·독립 연습 튜토리얼·시나리오/목표·선택형 모딩·지원 규모·최종 빌드/공개 다운로드 검증 |

우선순위는 현재 실행의 불변식/결합 회귀 → 전체 산업의 장기 재생산/금융/공공 충격 → 규모별 처리·메모리·저장 증가 최적화 → Android 실기기 입력/중단/접근성 → 남은 제품 심도다. 화면에 수치가 있다는 이유로 실제 경제가 구현됐다고 판정하지 않는다. 모든 새로운 행위는 플레이어/AI 공통 검증과 장부·물량·시간 비용을 사용한다.

| 미정/선택 항목 | 관리 원칙 |
|---|---|
| 가격·임금·공기·생장·세율·금리·정치/군 규모·세계 크기 | 버전이 있는 experimental 데이터. 여러 시드의 관측 근거를 남기며 사용자 확정값으로 꾸미지 않는다. |
| 국가 체제·수명/상속·목표/실패·관찰 인물 전환 | 현재 행동 자유/소유권 규칙과 충돌 없이 구체화하고 설정별 계약을 검증한다. |
| 플랫폼·지원 기기·최대 세계·성능 목표 | 실측 후 공개한다. Linux 호스트의 단발 시간이나 APK export 성공을 Android 성능으로 전용하지 않는다. |
| 계정·클라우드·멀티플레이·광고/과금·모딩 배포 | 실제 채택/운영 정책 이후 추가한다. 오프라인 핵심 경제/저장을 외부 서비스에 의존시키지 않는다. |

릴리스에는 해당 소스·실행한 시험·남은 한계·생성 자산의 출처·빌드 서명/호환성을 명시한다. GitHub 최신 릴리스라는 게시 상태는 전체 기획의 모든 심도와 실제 기기 검수가 완료됐다는 의미로 사용하지 않는다.
