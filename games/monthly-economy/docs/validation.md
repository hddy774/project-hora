# 검증 기록 — v2 작업 상태

검증일 2026-10-25, Godot 4.6.3 stable, Linux 작업 호스트. 현재 내용 계약은 `schema_version: 2` / `experimental-0.2`다. v0.1 릴리스의 검사 수·CI·다운로드 체크섬은 [이전 검증 기록](archive/validation-v0.1.md)에 보존했다. 그 결과는 변경된 v2 소스의 검증 근거로 재사용하지 않는다.

이 문서는 실행 증거를 기록한다. 모듈이 존재하거나 APK를 내보냈다는 이유만으로 전체 기획 완료, 장기 균형 또는 실제 Android 성능을 주장하지 않는다. 게시 직전 소스 커밋·CI·다운로드 검증은 최종 배포 작업에서 갱신한다.

저장소 루트에서 재현한다. 도구 이름은 설치된 Godot 4.6.3 경로로 바꿀 수 있다.

```bash
godot --headless --path games/monthly-economy --editor --import --quit
godot --headless --path games/monthly-economy --script res://tests/run.gd -- --quick
godot --headless --path games/monthly-economy --script res://tests/run.gd
godot --headless --path games/monthly-economy --script res://tests/test_ui.gd
godot --headless --path games/monthly-economy --script res://tests/test_ui_forms.gd
godot --headless --path games/monthly-economy --script res://tests/test_game_flow.gd
```

`tests/run.gd`는 코어/원장/저장, 금융, 인물, 공공, 산업, 수동시장, 토지, 집계, 세계생성, 지도, 결합/독립 검토 검사를 등록한다. `--quick`은 코어의 3시드×24개월 관찰을 생략하고 세계 생성 예비 정산을3개월에서1개월로 줄인다. 생성 이미지가 로드되지 않거나 필수 suite가 빠지면 실패한다. UI 탐색·실제 명령 폼/연습 세계·비동기 콜백 여정은 각각 독립 SceneTree 프로세스에서 실행한다. 중첩 GDScript 오류가 있어도 프로세스가0으로 끝날 수 있으므로 빌드 게이트는 종료 코드와 SCRIPT ERROR/Parse Error/ERROR 로그를 함께 검사한다.

## 이번 검토에서 발견한 문제

- 새 금융/신용 모델에서 현금 총합 고정은 올바른 불변식이 아니다. 대출 발행·원금 상환을 통화별 명시적 화폐 사건과 양쪽 장부로 검사하고 저축 이동을 구분했다.
- 기간별 전력·용수는 실물 재고로 이월하지 않는다. UI와 테스트도 재고와 제공 능력을 구분해야 한다.
- 국제 운송 시험에는 실제 운송업체·연료·인력·용량이 필요하다. 고정1개월 도착 기대를 계약 ETA 검사로 바꿨다.
- 공직자는 결합 시나리오 진행 중 선거로 교체될 수 있다. 이전 인물의 권한을 가정하지 않고 현재 직위를 다시 조회한다.
- 하단 월 버튼이 지출 카드 안으로 이동했다. UI 검사는 `NextMonthAction`을 재귀 탐색하고 외부 탭과 분리된 위치/부모를 확인한다.

## 남은 제품 검증

최종 서명 APK의 실제 Android 기기·에뮬레이터, 백그라운드/강제 종료, 저장 공간 부족, 수명주기/안전 영역/터치·접근성, 최대 규모·저전력·메모리·저장 증가, 개시 재고 소진 뒤 전체 산업 재생산, 여러 시드의 정치/금융/군수 충격을 검증해야 한다. 이 항목은 릴리스 latest 표시와 구별해 공개한다.

## 확장 세계의 실제6개월 관찰

seed42, 기본6도시/124회사/372인물/82품목에서 `Generation.experiment([42], 6, {cities_per_nation: 2, expanded_industries: true})`를 별도 복사본으로 실행했다. 종료0·월별 불변식 모두 통과했고 실제 시작 세계는 변경하지 않았다. 이 실행은 최종 estate/잘못된 금융 타입 보완 직전의 작업 소스다. 최종 커밋의 전체 회귀와 구분한다. 6개월 합계 미충족585사건/10,502최소단위였다. 과일 개시 재고164→24(생산24), 음료100→19(생산0/소비60)로 줄었고 퇴비의 organic_waste 공급 경로와 곡물/전력 순환의 개시 재고 의존 경고가 남았다. 이는 관찰한 실제 품귀/소진 위험이며 무한 자금·재고를 투입해 지우지 않았다. 모든 경고 품목의 장기 재생산과 세부 원인 분해는 후속 검증이다.

호스트 전체 실험은101,372ms, `resolve_month` 호출 관측은5,173/10,056/14,176/11,038/17,274/23,620ms였다. 이 값에는 동시 작업 부하가 있고 최종 최적화/Android 성능을 대표하지 않는다. 부가가치는 고정가격 실물/서비스·공공 실제 원가·현재 가격 디지털을 구분하는 실험 통계이며 전체 실질 GDP 재현을 주장하지 않는다.

## 원인 검토와 수정 전 전체 회귀

후속 [품목/도시/소득별 실제 진단](observations/expanded-seed42-six-months-cause-baseline.json)에서 초기 품귀와 후기 구매력 부족을 구분했다. 월1은 식품 재고100에 고정 감산 규칙이 걸려 도시당10개만 추가 생산했다. 월2~4는 제빵 노동시간이 한계에 도달했다. 월6에는 식품438개가 남아 있는데365개 수요가 충족되지 않았고, 필수재를 구하지 못한204명 모두 고용 중이었다. 그중159명은 당월 근로소득0,45명은36최소단위 미만이며 고용주의 최소 현금은10,980이었다. 개시 재고가 많아 유휴 생산이 이어질 때 실제 투입 공수에만 지급하는 임금 모델이 가계 현금을 소진시켰다.

이에 초기 식량 생산 예측·유급 근무 계약/유휴 보수·연체 의무를 보강하고 개시 직원/생산능력을 실제 장부로 조정하는 수정이 진행된다. 이는 실행 중 무료 현금/재고 보충과 구별한다. 아래 결과는 이 보강 전 기준선이며 새 보강의 검증 근거로 재사용하지 않는다.

수정 전 전체 suite는 경제160,969검사·72개월(시드7/42/99 각24개월)을 통과했다. 마지막6개월 모두 생산/소비가 발생했지만 위 가계 품귀 분석에서 이 조건만으로 생활 필수 수요의 안정성을 판단할 수 없음을 확인했다. 시드별 추가 검사 포함 구간 시간은135,828/156,663/150,239ms였다. 금융121·인물70·공공168·산업118·시장63·토지70·집계31·생성16·지도1,749·결합467검사도 통과했다. 마지막 독립 검토66검사에서는 실행 도중 뒤늦게 추가된 청산/예약 해제·유통기한4사례가 실패했다. 해당 함수 보완 후의 정확한 최종 소스 CI를 배포 게이트로 사용한다.

### v0.2.1 공식 APK의 Android 기동 관측

실제로 공개한 APK(SHA `0d45b3d7e54fbf049cef57379808d1a3bc596c9412c40bbf15ba2a9548cb5b2b`) 그대로 API24/x86_64 소프트웨어 에뮬레이터에 설치했다. 로컬 재서명/재내보내기를 하지 않았다. 공식 인증서, ADB 설치 성공, Godot4.6.3/OpenGL ES3.1 Mesa 초기화와 [생성 H 로고의 실제 렌더링](screenshots/v0.2.1-android-official-splash.png)을 확인했다.

이 환경은 하드웨어 가속 없는2코어/1024MB/host Mesa llvmpipe다. 앱 프로세스는 살아 있고 마지막 관측 PSS는 약115MB였으며 캡처 로그에 스크립트 오류·네이티브 크래시·셰이더 링크 실패가 없었다. 그러나 **스플래시를 벗어난 타이틀·달러/원화 입력·스크립트 진행바·월 정산은 확인하지 못했다.** 데스크톱의 실제194여정 검사를 Android 전체 플레이 검증으로 확대하지 않는다. 물리적 ARM64 기기도 미검증이다. 최초 내부 Activity 지정 명령은 Android의 비공개 컴포넌트 거부였고 공개 런처를 확인해 정정했으며 APK 크래시로 분류하지 않았다.

[공식 파일/단계별 관측 JSON](observations/android-v0.2.1-official-boot-probe.json)에 범위를 보존했다. 검증 후 테스트 에뮬레이터·전용 ADB와 X11 서버는 정리했다. 위 상태를 제품 지원 기기의 성능·기동 성공 인증으로 사용하지 않는다.
