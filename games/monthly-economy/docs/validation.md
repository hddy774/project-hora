코드 동결 소스의 별도 CLI 3개월 실행(seed 42)은 실제 거래 건수 `243 / 243 / 252`, `resolve_month` 함수 호출 시간 `948 / 1588 / 2492 ms`를 관측했다. 이는 이번 호스트와 동시 CPU 부하에서 한 번 실행한 값이며 Android 처리시간·출시 목표·다른 규모의 성능을 입증하지 않는다. 월별 품목 관측은 단위를 유지하며 실험 CLI에서 출력한다.

장기 검사 구간 측정은 시드별 `143250 / 145905 / 155357 ms`였다. 월별 추가 검증과 독립 assertion을 포함하는 suite 구간 시간이며 **월 정산 함수만의 성능 수치가 아니다**. 출시 정산시간·지원 규모·메모리·배터리 목표는 아직 확정하지 않았다.

재현 명령은 저장소 루트 기준이다. 엔진 실행 파일 이름이 다르면 Godot 4.6.3 바이너리 경로로 바꾼다.

## 발견해 수정한 결함

| 문제 | 수정과 확인 |
|---|---|
| 저장 JSON의 키 순서가 레시피 입력 반복 순서를 바꿔 후속 월 이벤트/해시가 달라짐 | 경제 결과에 영향을 주는 Dictionary 반복을 정렬했다. 독립 상태 diff로 원본과 로드본의 후속 월 결과 일치를 확인하고 진행 공사 저장 뒤 재현 검사에 포함했다. |
| JSON 뷰 경로의 숫자가 실수로 복원됨 | 내부 탭 경로를 정수로 정규화했다. 미실행 계획·뷰 경로·스크롤 복원 UI 여정으로 확인했다. |
| 지도 높이 override가 콘텐츠 공간을 과도하게 점유함 | 레이아웃 높이 설정을 수정했다. 480×920의 153개 말단 방문 및 실제 렌더링으로 확인했다. |

UI 뷰 파일은 `.view`로 경제 저장 상태와 분리한다. 화면·탭·스크롤을 복원하는 동작은 정산이나 경제 난수 소비가 아니다. 화면에서는 구매 의사를 ‘구매요청’, 공급 관련 보유량을 ‘도시귀속재고’로 표시한다. 지불 능력을 검증한 유효 수요나 별도 시장 공급 주문장까지 구현했다는 뜻이 아니다. 단위가 다른 품목의 합계를 총생산량/GDP로 표시하지 않는다.

최신 quick 원시 로그는 이번 작업 환경의 `/workspace/hora-final-quick.log`에 있다. 저장소에 포함된 재현 진입점은 [tests/run.gd](../tests/run.gd), [test_economy.gd](../tests/test_economy.gd), [test_ledger_save.gd](../tests/test_ledger_save.gd), [test_ui.gd](../tests/test_ui.gd), [test_game_flow.gd](../tests/test_game_flow.gd)다. 원시 로그 경로는 사용자 기기의 경로나 영구 공개 링크가 아니다.

## 결과를 나누는 기준

| 판정 | 의미 |
|---|---|
| 미실행 | 아직 실행하지 않았다. 코드/문서 존재만 확인한 상태도 포함한다. |
| 통과 | 지정한 입력과 검사의 기대 결과를 만족했다. 범위·명령·커밋을 함께 적는다. |
| 실패 | 기대 계약을 어겼다. 재현과 원인을 남긴다. |
| 부분 | 일부 자극·플랫폼·경계만 검증했다. 제외 범위를 명시한다. |
| 해당 단계 밖 | 전체 목표에는 남아 있으나 아직 구현 단계가 아니다. |

실행 중 크래시가 없다는 결과, 불변식 보존, 경제 순환의 타당성, UI 사용성, 실제 기기 성능은 각각 다른 판정이다. 하나의 결과를 나머지의 근거로 확대하지 않는다.
