# 02. 시뮬레이션 상세 규칙

> 0.1.0 작성 시점의 설계·검토 기록입니다. 0.2.0 구현과 달라진 사항은 [현재 구현 기준20](20-v0.2.0-implementation.md)과 [실측19](19-balance-v0.2.0.md)를 우선합니다.

상태: 기준 소스의 실제 동작. 수치는 [03](03-balance-and-content.md), 공개 데이터 형식은
[데이터 사전](reference/data-dictionary.md)을 함께 본다. 별도 설명이 없는 난수는 세계의 단일 PCG32다.
정수 Range는 양 끝 포함, 실수 Range는 하한 포함·상한 미포함이다. Math.Round는 별도 모드를 지정하지 않은
C# 기본 반올림을 사용한다.

## 1. 한 해의 처리 순서

`WorldSimulator.Step`은 다음 순서를 고정한다. UI 갱신 주기와 시뮬레이션 틱은 별개다.

1. Year를 1 증가시킨다.
2. 시대 갱신, 전쟁 시작·종전·증원 여부를 처리한다.
3. Cultivators 리스트의 **슬롯 순서**로 인물을 갱신한다.
4. 접경지 전투를 해결한다.
5. 비경 → 수조 → 경매 → 천하 대비무 순으로 세계 사건을 처리한다.
6. 종문 정산·입문·배신·직위 재편을 처리한다.
7. 통계·세계 기록·숙적 정리를 처리한다.
8. 천기를 회복한다.

인물의 한 해는 노화/좌화 → 전생 각성 → 관계 생성 → 자연 회복/행동 → 연수단 → 돌파 순서다.
좌화하면 해당 슬롯의 그 해 인물 처리는 끝난다. 비승에 따른 슬롯 교체는 돌파 단계에서 일어난다.
행동과 전투·사건이 같은 해에 모두 일어날 수 있어 한 인물의 연간 전투 횟수는 1로 제한되지 않는다.

## 2. 세계 생성과 새 생

| 항목 | 규칙 |
|---|---|
| 인구 | 요청 수를 100~3,000으로 제한. 기본 1,000 |
| 초기 소속 | 산수 약 20%, 나머지를 양 종문에 배분. 정수 반올림 포함 |
| 종문 금고 | 각각 영석 20,000 생성·장부 기록 |
| 초기 지역 | 종문은 65% 확률로 자기 영지, 나머지 접경지. 산수는 75% 접경지, 나머지 주변 영지 |
| 개창 원로 | 종문별 재능 순 상위 13명까지. 첫 인물 금단경 초기, 나머지 축기경. 공법·나이·공헌 보정 |
| 초기 직위 | 원로 설정 뒤 종문별 재편. 직위 정원은 [03](03-balance-and-content.md) 참조 |
| 시대 | 평온으로 시작, 길이는 3,000~8,000년 |
| 초기 기록 | 천지개벽 연대기와 0년 통계 표본 |
| 천기 | 3점 시작 |

네 재능은 각각 `floor + round((500-floor) × u^1.6)`으로 뽑는다.
`floor=clamp(10+업보,10,300)`이며 최종 값은 10~500이다. 첫 생의 업보는 0이다.
변이 영근을 뽑을 확률은 10%이며 뇌·빙·풍 중 하나, 그 외에는 오행 중 하나다.

새 생의 기본 값은 나이 16, 연기경 초기, 영기 0~60, 깨달음 0~50, 도심 55~85,
내공 8~20, 공법 0~2등급, 영석 30~140, 영초 0~10, 영철 0~4다.
초기 세계는 나이와 원로 상태를 추가 보정한다. 현생 전투·인연·공헌·호칭·생애는 초기화하고 전생 요약은 유지한다.
BornYear는 새 생을 시작한 세계 연도이며 나이가 이미 16이므로 달력상 0세 출생연도와 일치하지 않는다.

성격은 소속별 가중치로 생성한다. 윤회 시 이전 성격 60%, 이전 속성 30%를 계승할 기회가 있다.
기예 생성 가중치는 없음/연단/연기/진법/부록 = 57/15/10/8/10이다.

## 3. 자연 회복과 행동 선택

- 매년 부상 수치가 최대 체력의 1.5%만큼 회복한다. 소속 영지에서는 연단방 단계당 0.5%를 추가한다.
- 요양 연수가 양수이면 1 줄인다. 도심이 70 미만이면 0.3 회복한다.
- 이후에도 요양 중이거나 건강 비율이 35% 미만이면 요양을 강제로 선택한다.
- 그 외에는 성격의 9개 가중치에서 행동 하나를 뽑는다. 기본 가중치 전체는 [03](03-balance-and-content.md)에 있다.

| 상황 | 기본 가중치에 적용하는 변경 |
|---|---|
| 건강 <70% | 비무 ×0.2, 요양 가중치 15 |
| 산수 | 임무 0, 이동 ×1.6, 탐색 ×1.3, 거래 ×1.2 |
| 기예 없음 / 있음 | 기예 0 / ×1.3 |
| 제자 없음 | 지도 0 |
| 영석 <30 | 탐색 ×1.5 |
| 연기경 | 비무 ×0.5 |
| 전쟁 파견 중 | 비무 ×2, 이동 0, 임무 ×0.3 |
| 혈월 + 마도 성격 | 비무 ×1.3 |

회복 연수의 감소가 강제 행동 판정보다 먼저이므로 1년 남은 요양은 그 해 정상 행동으로 바뀔 수 있다.

## 4. 행동 효과

| 행동 | 실제 처리 |
|---|---|
| 수련 | 연간 수련량 × 실수 난수 [0.9,1.5) × share만큼 영기, 깨달음과 내공 증가 |
| 탐색 | 영석·재료 생성, 종문 십일조 이전, 수련 share 0.3, 기연·부상 판정 |
| 거래 | 잉여 재료 판매 → 산수 공법 구입 또는 종문 공헌 교환 → 지역 시장 필요 물품 구입 |
| 기예 | 제작 시도. 자원 부족으로 시도 불가하면 수련 share 0.7 |
| 비무 | 같은 지역 상대 탐색. 상대가 없으면 수련 share 0.5 |
| 임무 | 종문 공헌 15~30 × (경지+1), 영석 5~15 × (경지+1) 생성, 금고 30%·본인 나머지, 깨달음 +5 |
| 이동 | 종문은 영지·접경지, 산수는 영기·재료·비경·수조 가중치로 목적지 선택. 같은 장소면 수련 share 0.5 |
| 지도 | 같은 지역 제자에게 깨달음·필요 영기 5%를 주고 공헌 증가. 본인은 수련 share 0.5 |
| 요양 | 최대 체력 10% 추가 회복. 조건에 맞으면 회복단·청심단을 소비하고 도심 +1 |

탐색 영석은 `round(U[4,16] × (1+0.6r) × 풍부도)`다. 풍부도는 영초·영철 평균이며
영기 보정이 1 미만인 지역은 ×0.8이다. 정도는 발견 영석의 10%, 마도는 15%를 금고에 이전한다.
영초는 0.5×풍부도 확률로 1~3개, 영철은 0.35×풍부도 확률로 1~2개 얻는다.
탐색 기연 확률은 `0.0015 × 산수보정(1.5) × (0.5+매력) × 부흥시대보정(1.5)`다.
탐색 부상은 `위험도 ×0.15×(1-0.5×신중함)` 확률로 최대 체력의 5~20%다.
임무는 5% 사고, 0.2% 기연 확률을 별도로 갖는다.

## 5. 영기·깨달음·수명

연간 수련량은 다음 9항의 곱이다. 이 값은 **수련 행동 1회분의 기준량**이며 매년 항상 얻는 수동 수입이 아니다.

~~~text
G = Base × Root × Technique × Place × Rank × Ideology × Era × Bonds × Condition
Base = 10 × 1.55^r
Root = 0.5 + 1.5 × (영근능력치/500)^1.1
Technique = (0.75+0.05×공법등급) × 속성일치(1.1) × 변이영근(1.05)
Place = clamp(지역영기,0.3,2.0) × 지배/영맥진 보정
Bonds = 살아 있는 스승(1.15) × 같은 지역 도려(1.1)
Condition = (0.7+0.3×도심/100) × (0.4+0.6×건강비율) × 고령(나이/수명>0.9이면0.8)
~~~

자기 지배지의 원래 영지는 `1.05×(1+0.04×영맥진단계)`, 점령 접경지는 ×1.15다.
직위·이념·시대 보정은 [03](03-balance-and-content.md)의 표를 따른다.
수련 시 깨달음 기준은 `0.5+2.5×오성/500`, 난수 [0.5,1.5)와 share를 곱한다.
내공 증가는 `(0.3+0.1r)×share`다. 깨달음은 0~1,000, 도심은 0~100으로 제한한다.

`수명 = round(경지기본수명 × (1 + 체질/5000 + 0.05×먹은연수단수))`.
연수단은 나이/수명이 80% 이상일 때 한 생 최대 3알까지 자동 사용한다.
`최대체력 = 100 + 체질/5 + 경지×40 + 단계×8`, `건강비율=clamp(1-부상/최대체력,0,1)`이다.

## 6. 돌파와 천겁

영기가 현재 단계 요구량 이상이고 요양 중이 아니면 한 번 시도한다. 영기가 많이 남아도 한 해에
인물별 TryAdvance 호출은 한 번이다. 초기→중기→후기→대원만 뒤 다음 경지 초기로 이동한다.

### 소경지 돌파

`P=clamp(0.82+0.12×오성/500-0.2×(1-건강비율),0.5,0.97)`.
실패하면 요구 영기의 30%를 잃고 도심 -2. 성공하면 요구 영기를 빼고 단계 +1, 내공
`2×(경지+1)`, 소경지 돌파 수와 종문 공헌 `20×(경지+1)`를 올린다.

### 대경지 돌파

~~~text
P0 = 경지기본확률
   × (0.6+0.8×(오성+영근)/(2×500))
   × 공법한계보정(공법등급,목표경지)
   × (1+0.5×깨달음/1000)
   × (0.6+0.5×도심/100)
   × (1-0.3×(1-건강비율))
   × 시대돌파보정
종문: ×1.1×(1+0.02×영맥진단계)×이념돌파보정
살아 있는 스승: ×1.1
나이/수명>0.85: ×0.8
P=clamp(P0,0.01,0.8)
파경단이 있으면 1개 소비 후 min(0.95,P×1.35)
~~~

목표 경지가 공법 한계보다 높으면 한 경지 차이마다 ×0.4다.
공법 한계가 목표 이상이면 `1+0.03×min(3,여유경지)` 보정이다.

실패하면 요구 영기를 전부 잃고 깨달음 절반, 도심 -6, 최대 체력 10~20% 부상을 받는다.
주화입마 확률은 `0.06 + 이념가산(정도-0.03/마도+0.05) + 낮은도심가산(40미만+0.06)`이며,
발생하면 추가로 단계 하락·30% 부상을 적용한다.

목표가 화신경 이상이면 돌파 확률을 통과해도 천겁 판정을 통과해야 한다.

~~~text
천겁 P = clamp(0.30 + 0.25×min(1,내공/(150×목표경지))
 +0.15×체질/500 +0.15×도심/100 +0.04×법보등급
 +0.02×호산대진단계 -0.04×max(0,목표경지-4), 0.1, 0.92)
피뢰부를 쓰면 +0.1, 상한0.95
~~~

천겁 실패는 도심 -10, 최대 체력 40~70% 부상과 영기 0을 적용한다.
성공하면 통과 횟수·내공 `20×목표경지`가 증가한다.
대경지 최종 성공은 경지 +1·초기, 깨달음 0, 부상 절반, 도심 +5, 내공 `10×(새경지+1)`,
수명 재계산, 공헌·최초/최연소 기록·호칭 확인을 수행한다. 원영경부터 도호를 얻을 수 있다.

### 비승

반선경 대원만에서 일반 대경지 대신 별도 비승 확률을 쓴다.

`P=clamp(0.2×(0.6+0.8×(오성+체질)/1000)×(1+0.5×깨달음/1000)×(0.6+0.5×도심/100)×(1+0.04×법보),0.02,0.6)`.
피뢰부는 ×1.1, 상한 0.7이다. 성공하면 명부·영혼 업적을 기록하고 새 영혼으로 슬롯을 교체한다.
실패하면 요구 영기 소모, 도심 -10, 50~80% 부상을 받는다.

## 7. 부상·하락·좌화·윤회

- 부상 누적이 최대 체력에 닿으면 부상을 최대 체력 50%로 재설정하고 10~30년 요양·한 단계 하락을 적용한다.
- 단계 하락은 영기 절반. 초기에서 하락하면 경지 -1·대원만이 되고 수명을 재계산한다.
- 대경지 하락은 경지 -1·초기, 영기 0, 내공 ×0.7(최소1), 도심 -15, 수명 재계산이다.
- 연기경 아래로는 내려가지 않는다. 부상이 곧바로 사망을 호출하지 않는다.
- 매년 노화 후 나이≥수명이면 좌화한다. 최고 경지보다 낮고 최고 경지 기본수명 미만이면 경지 붕괴로 분류한다.
- 생애를 종료해 점수·전생을 기록하고 관계 상대를 정리한 다음 유산을 이전한다.
- 유산 영석은 첫 살아 있는 제자 → 도려 → 소속 금고 → 상속자 없는 소멸 순이다.
  관계 정리 시 떠나는 인물의 참조 목록은 아직 유지되어 유산 조회에 사용된다.
- 윤회는 같은 영혼 ID·이름을 유지한다. 이전 종문에 돌아갈 기회는 55%이며, 새 생은 낮은 직위에서 재시작한다.
- 업보 하한은 `min(150,최고경지×12 + 누적호칭종류×4 + 완료생수×2)`다.
- 전생 각성은 25~300세, 이전 생이 있고 아직 미각성이면 연간 `0.0008×min(10,윤회수)` 확률이다.
  각성 시 공법 기억 `min(12,전생최고경지×2)`, 깨달음 +300, 도심 +10, 각성 호칭을 적용한다.

비승은 관심 ID를 목록에서 제거하고 새 ID를 발급한다. 자연 윤회는 관심이 같은 영혼을 계속 따른다.

## 8. 인연

| 관계 | 생성·유지 |
|---|---|
| 사제 | 스승 원영경 이상, 제자 최대3명, 연간0.5% 탐색 시도. 같은 지역·같은 소속, 제자는 축기경 이상이며 2경지 이상 낮아야 함 |
| 도려 | 금단경 이상, 연간0.2% 탐색. 서로 미결연·경지 차≤1·정파/마도 성격 충돌 없음·사제/숙적 제외 |
| 도려 수락 | `0.3+0.4×양쪽매력평균`. 같은 지역에서 수련 ×1.1 |
| 숙적 | 원한·전쟁 뒤10% 형성 기회. 상호 등록, 최대3명, 같은 ID 제외 |
| 정리 | 100년마다 없는 상대·경지 차≥2 숙적을 양쪽에서 제거. 생애 종료 시 상대 참조 해제·도심 반영 |

관계 후보는 지역 거주자 목록의 난수 시작점부터 최대40명을 확인한다. 지도는 같은 지역 제자에게
깨달음 `20×(0.5+스승오성/500)`와 현재 요구 영기 5%를 준다.

## 9. 전투

~~~text
Power = 경지기준 × 근골 × 공법 × 법보 × 내공 × 경험 × 상태 × 종문/변이
경지기준 = 100×2.8^경지×(1+0.18×단계)
근골 = 1+0.5×근골능력치/500
공법 = 1+0.04×공법등급
법보 = 1+0.08×법보등급
내공 = 1+0.3×min(1,내공/(200×(경지+1)))
경험 = 1+min(0.2,승수×0.004)
상태 = (0.5+0.5×건강비율)×(0.85+0.15×도심/100)
종문/변이 = (1+0.03×연무장단계)×변이영근(1.05)
~~~

각자의 Power에 전투별 보정, 난수 [0.85,1.15), 오행 상극 ×1.15, 허용된 공격부 ×1.15를 적용한다.
그 결과를 A, B라 하면 승률은 `A^2.5/(A^2.5+B^2.5)`다. 전투력 두 배의 약85%라는 설명은
난수·상극이 없는 조건의 근사다. 이변 표시는 실효 난수 이전 기준 전투력이 낮은 승자다.

같은 지역 숙적을 우선 찾고, 그 외에는 최대6회 후보 탐색으로 경지 차≤1·요양 아님을 확인한다.
소속이 같으면 친선, 다른 종문은 접경지 전쟁 중 전투/그 외 교차 비무, 일부 공격적인 산수는 원한 결투다.

| 종류 | 패자 부상 | 추가 단계/대경지 하락 | 전리품 |
|---|---|---|---|
| 일반 친선 | 3~6% | 누적 중상 규칙만 | 보유 영석3%, 최대20 이전 |
| 종문 간 친선 | 4~8% | 누적 중상 규칙만 | 같은 내기 규칙 |
| 토너먼트 | 5~10% | 누적 중상 규칙만 | 내기 없음 |
| 원한 | 20~40% | 단계8% / 대경지0% | 영석15~35% |
| 전쟁 | 25~50% | 단계12% / 대경지3% | 영석20~40% |
| 비경 | 15~30% | 단계5% / 대경지0% | 영석10~25% |

누적 부상으로 먼저 하락하면 추가 하락 판정은 생략한다. 마도 전리품 ×1.5, 탈취 상한은 패자 영석60%다.
전투는 승패·연승·경험용 횟수와 공헌·도심·숙적·호칭을 갱신한다.
전쟁의 Casualties는 **전투로 경지 순위가 떨어진 사례 수**이며 실제 사망자 수가 아니다.

## 10. 종문·직위·재정

직위 점수는 `경지단계순위×1500 + 현생누적공헌(Merit)`다. 동점이면 영혼 ID 순이다.
종주→대장로→장로→직전→내문→외문 순으로 정원을 채우고 나머지는 잡역으로 둔다.
새 가입자는 외문 자리가 있으면 외문, 없으면 잡역이다. 종주가 떠나면 즉시 재편한다.

입문 시험은 50년마다, 종문별 기본3명이며 인구 열세를 반영해 1~6명 한도다.
자기 지배지 도달률1, 접경지0.5, 성격 친화·재능과 은둔 성격 보정으로 지원 수락 확률을 계산한다.
100년마다 도심<55인 비종주에게 친화도 기반 배신 기회가 있고 혈월의 정도 종문은 그 확률이 두 배다.

100년 정산은 영지 수입 → 시설 유지비 → 녹봉 → 시설 한 단계 투자 → 단약 생산 순서다.

- 영지 수입: 지배 지역마다 `round(1500×지역영기)`를 금고에 생성한다.
- 유지비: 시설별 `300×단계²` 합, 금고 잔액 한도 내에서 소멸한다.
- 녹봉: 직위 기본액 `×(4+경지)/4`, 리스트 순으로 금고 잔액 한도 내에서 개인에게 이전한다.
- 시설: 최고5단계. 비용 `round(20000×2.5^현재단계)`, 금고가 비용1.5배 이상이면 이념별 우선순위 중 하나를 증축한다.
- 연단방: 단계당6회 생산, 파경/회복/청심 = 50%/35%/15%, 종류별 재고60 상한이다.
- 전쟁 중에는 매년 금고의 1/1,000을 군비로 소멸시킨다.
- 공헌 교환은 사용 가능 공헌(ContributionPoints)을 쓰며 직위용 Merit는 줄지 않는다.

## 11. 정마대전

전쟁 구간은 `year≥3000 && (year-3000)%11000<1000`이다.
개전 때 전적·공훈을 초기화하고 파견한다. 이후 개전 기준 매100년의50년째에 증원한다.
축기경 이상·대장로 미만·요양/기파견 아님을 대상으로 성격별15/35/55% 확률로 파견한다.
최대5개 접경지 각각 연간2라운드, 양측 후보가 있고 60% 판정을 통과하면 추가 전투한다.
인물 비무 행동에서 벌어지는 접경전은 별도로 집계한다.

실제 승자의 소속에 따라 청운 +1 / 천마 -1로 제어점을 갱신한다. 범위는 -10~10,
+4면 청운 지배, -4면 천마 지배다. 중간 값에서는 이전 지배자를 유지한다. 전쟁 종료 후 지배·제어점은 유지한다.
방어 보정에는 이념, 연패당5%(최대15%), 가까운 보급선10%, 지배자의 진법·호산대진이 반영된다.

종전 시 양 종문의 최강자 대표 결투 뒤 `승수 + 점령지수×30 + 대표결투승리50`으로 승자를 정한다.
같으면 무승부, 아니면 패자 금고10%를 승자에게 이전하고 전적·연패를 갱신한다.
전체 공훈 1위에게 영웅 호칭과 공헌2,000을 주며, 승리 종문 인물로 제한하지 않는다.
주요 장면은 최대12개, 종료된 WarRecord는 누적 보관한다.

## 12. 천하 대비무

휴전 시작 후500년째부터1,000년 간격으로 열린다. 초기 세계도 마지막 종전0년으로 간주하므로 첫 대회는500년이다.
축기경 이상·요양 아님 중 청운12명·천마12명·산수8명까지 전투력 순으로 선발한다.
총 후보 수 이하의 가장 큰 2의 거듭제곱을 사용하며 최소4명이다. 시드 배치 후 라운드별 경기를 기록한다.
토너먼트는 친선 피해 규칙이며 공격부를 쓰지 않는다.

우승자는 양 종문 금고2%씩을 모은 상금, 깨달음300·도심10·우승 호칭, 소속 공헌1,500을 얻는다.
준우승 호칭, 개인 최고 성적, 종문 우승 횟수를 기록한다.
영혼 우승 집계는 종료한 생의 TournamentBest가1이면 생애당 한 번 올리므로 실제 대회 우승 횟수와 같지 않을 수 있다.

## 13. 시대·비경·수조·경매

| 시대 | 선택 가중치 | 수련 | 돌파 | 비경 발생 | 수조 발생 |
|---|---:|---|---|---|---|
| 평온 | 45 | ×1 | ×1 | ×1 | ×1 |
| 영기 부흥 | 15 | ×1.25 | ×1.1 | ×2 | ×1 |
| 말법 | 15 | ×0.75 | ×0.85 | ×0.5 | ×1 |
| 혈월 | 12 | 정도×0.95·마도×1.15·산수×1 | ×1 | ×1 | ×2 |
| 만수 난동 | 13 | ×1 | ×1 | ×1 | ×4 |

자연 비경은 활성 개수<2일 때 연간0.15%×시대보정이다. 입장 최저 경지0~5, 최고는+2(최대8),
기간30~60년, 보물20~60개, 입장 누적40명 상한이다. 현재 거주자 중 경지 조건과 야망·성격 판정으로 입장한다.
입장자별 연간15% 보물, 그 외5% 부상, 그 외10% 쟁탈 판정으로 처리하므로 각 분기는 독립 최종 확률이 아니다.
보물은 공법·법보·깨달음·영기·영석이며 종료 시 수확 점수1위에게 조건부 비경의 주인 호칭을 준다.

자연 수조는 활성 개수<2일 때 연간0.08%×시대보정이다. 평균 경지 반올림+1~2, 범위1~8,
기간20~50년, 최초 세력은 해당 경지 후기 기준 전투력×40이다.
지배 종문에서 조건을 갖춘6명까지 증원한다. 연간 최대30명 방어, 성공 시 전투력×[0.5,1.0) 피해와 공헌,
실패 시15~35% 부상이다. 격퇴되면 최고 공훈자에게 호칭을 주고, 기간 만료 시 그냥 물러간다.
비경·수조는 지역 영기 보정을 각각1.2/0.8로 직접 덮어쓰고 종료 시1로 되돌린다. 겹치는 사건의 합성 규칙은 없다.

경매는150년부터300년 간격, 전 세계 부자30명이 후보이며 실제 지역 이동을 요구하지 않는다.
출품3~5건은 공법10~16등급·법보4~5등급·연수단·파경단3개·피뢰부3개 중 무작위다.
입찰은 보유 영석30~70%와 기준가80~200% 중 작은 값, 낙찰가는 최고 입찰 이하이면서
기준가60%와 차순위 입찰110% 중 큰 값이다. 낙찰 영석은 소멸하며 최근30회 경매를 보관한다.

## 14. 기예·거래·영석 보존

| 기예 | 투입과 성공 | 결과 |
|---|---|---|
| 연단 | 영초3, `min(0.95,0.4+숙련/150)` | 회복/파경/청심. 숙련70 이상이면8% 연수단 기회 |
| 연기 | 영철3, 연료영석 `30×(제작등급+1)`, `min(0.9,0.35+숙련/150)` | 등급 `min(5,1+floor(숙련/22))` 법보. 기존보다 낮으면 상회 판매 |
| 부록 | 영초1+영철1, `min(0.95,0.5+숙련/150)` | 공격부, 숙련40 이상이면30% 피뢰부 |
| 진법 | 별도 재료 소모 없음 | 종문 공헌 `5×(경지+1)`와 수련share0.4. 지역 진법 숙련 합이 전쟁·수조 방어 지원 |

재료가 없어 제작 시도가 불가능할 때는 false다. 재료를 쓰고 성공 판정에 실패한 경우도 true를 반환하므로
시도한 기예의 숙련은 증가한다. 증가량은 `1.5×(1-숙련/110)`, 상한100이다.
개인 보유 단약·부적이 종류별2개 이상이면 제작품을 지역 시장에 판매한다. 시장 종류별 재고 상한30이다.

상회 재료 판매가는 영초6·영철9·내단40영석, 구매는 판매가×2다.
상회는 실제 NPC 지갑을 갖지 않는다. 판매 대금은 생성, 구입 대금은 소멸이다.
이 게임이 보존하는 것은 세계의 **영석 장부**이며 영초·영철·단약의 전체 질량 보존은 아니다.

~~~text
실제 영석 = 살아 있는 수선자의 SpiritStones 합 + 종문 Treasury 합
장부 영석 = Created 합 - Destroyed 합
검사 불변식: 실제 영석 == 장부 영석
~~~

생성: 초기 지급(윤회·비승 대체 포함), 탐색, 상회 판매, 영지, 기연·비경, 임무.
소멸: 상회 구입, 시설 건설, 경매, 제련, 비승 소지금, 군비, 유지비, 상속자 없는 유품.
녹봉·십일조·전리품·상속·상금·배상은 세계 내부 이전이므로 생성/소멸에 추가하지 않는다.
보유 값은 long이지만 일부 비율·가격 중간 계산은 double과 반올림/정수 절삭을 쓴다.

## 15. 점수·기록·표본

`생애점수=최고경지×1000+최고단계×100+대경지돌파×20+승수×2+천겁통과×80+호칭점수합+대회성적점수+현생전쟁누적공훈/10`.
대회 성적은 우승500·준우승250·4강120·8강50점이다. 전체를 반올림해 정수화한다.
영혼별 최고 생애, 상위5생 점수, 누적 돌파·승리·천겁·호칭 종류를 저장한다.

| 기록 | 보관·집계 |
|---|---|
| 사건 로그 | 최근600건 링 버퍼. 저장은 오래된 순, 화면은 최신순. Counts는 잘린 기록과 CountOnly도 누적 |
| 연대기 | 주요 사건 최근1,500건. 모든 행동을 기록하지 않음 |
| 생애 | 현생40건. 최초 항목을 보존하고 넘치면 두 번째 항목 제거 |
| 전생 | 최근20생 요약. 영혼의 최고/5생 합 집계와 구분 |
| 통계 | 시작0년·기본100년 간격. 400표본 초과 시 하나 걸러 보존하고 간격2배 |
| 알림 | 최근40개 대기열은 저장하지 않음. 화면최대3개·약5초 |
| 전쟁·대회·비승·영혼 업적 | 현재 코드에 전체 길이 상한 없음 |

최초·최연소 진급은 경지 초기 도달에서 기록한다. 최고 전투력·최다 영석은100년 정리 때 표본 갱신하므로
매 순간의 최고를 전수 조사한 값이 아니다. 초기 원로 경지를 최초 기록에 반영할지는 별도 검토 항목이다.

## 16. 근거와 변경 시 영향

각 절은 같은 이름의 [Systems](../src/Xianxia.Simulation/Systems/) 파일을 기준으로 한다.
전체 파일별 책임은 [소스 색인](reference/source-and-tests.md)에 있다.
틱 순서·난수 호출·정렬 동점 규칙·주기·확률의 변경은 기존 시드의 미래 결과를 바꾼다.
변경 전후의 상태·분포·장부를 비교하고 저장 호환성 정책을 함께 정해야 한다.
