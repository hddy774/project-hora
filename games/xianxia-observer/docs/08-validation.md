# 08. 테스트·검증 기록

상태: 기존 CI 증거, 이번 문서 작성의 신규 실측, 아직 확인하지 못한 범위를 구분한 QA 기록이다.
문서 작성 과정에서는 게임 코드·자동 테스트·APK를 수정하지 않았다.

## 2. 자동 테스트 범위

| 묶음 | 확인하는 성질 | 한계 |
|---|---|---|
| PCG | 같은 시드 수열·참조 출력·상태 복원·범위·가중치 0·잘못된 bound | 전체 세계 교차 CPU 수치 동일성의 증거는 아님 |
| 결정론·저장 | 같은/다른 시드 세계, 저장 후 동일 이력, 손상 gzip 거부, 색인 복원 | 임의의 유효 JSON 의미 오류는 모두 검사하지 않음 |
| 장기 불변식 | 시드21·인구400·4,500년의 장부·직위·종주·산수·지역·관계·수치·기록·인구 | 한 장기 시드의 표본 검사. 수학적 증명이나 퍼징 아님 |
| 기능 | 비승 인구 교체, 제자 유산, 대회 대진·우승, 개입 비용, 비경·수조 종료, 숙적, 호칭, 전쟁 주기 | 인공 상태로 경로를 열어 검사하는 사례도 있음 |
| 회귀 | 실제 승자의 점수, 신규 입문 직위, 재편 정원, 로그 순서, 이념 성장, 경지 중심 전투력, 붕괴 기록 | 현재 알려진 모든 위험을 포괄하지 않음 |
| 순수 질의 | 인물 필터·모든 정렬의 비변경성, 종합 업적 순위 | 세계 밖의 UI 전체 접근성은 별도 |
| 헤드리스 UI 입력 | 전 탭·상세, 검색·관심·로드, 중복/잔액 부족 개입, 설정 입력·확인, 저장 교체, 빈 대상 | 실제 Android 터치·시스템 UI·IME와 다름 |
| 렌더 스모크 | 세계 진행 후 화면 생성, 뒤로 가기, 화면 파일·자리표시 문구 검사 | 픽셀 golden 비교·글자 잘림·색 대비 자동 판정이 아님 |

렌더 검사는 412×860과 좁은 360폭 조건을 포함한다. PNG 생성 성공이나 placeholder 부재만으로
모든 텍스트·레이아웃이 제품 품질 기준에 맞는다고 판정하지 않는다.

## 3. Android에서 실제로 확인한 것

공식 APK는 API34·x86_64·Google APIs·Pixel 6 프로필 에뮬레이터에 설치했다.
패키지 버전·ABI 두 종류·인터넷 권한 부재·비디버그·서명을 빌드 job에서 확인했다.
동일 APK의 SHA-256을 에뮬레이터 아티팩트에 남겼고, 프로세스 실행·게임 화면·세계 연도 진행,
백그라운드 복귀와 저장 후 재실행 화면을 관찰했다.

**제한:** 해당 실행에서 외부 **Pixel Launcher의 ANR 대화상자**가 탭 입력을 가렸다.
스크립트의 각 탭 좌표 탭과 PNG 파일 생성이 실제 게임의 모든 탭 전환 성공을 입증하지 못한다.
이 실행에서 앱 자체의 크래시를 관찰하지 않았지만 이를 전체 사용 경로 무결함으로 일반화하지 않는다.
상세 UI 탐색의 현재 근거는 헤드리스 입력 검사다.

이후 smoke 스크립트에 외부 런처 정지 처리를 추가했으나 **공식 APK로 수정 스크립트 전체를 다시 검증한
증거는 아직 없다**. 따라서 에뮬레이터 job 성공 상태와 모든 탭의 실 Android 수용 완료를 구분한다.
ARM64 실기기·API24 최소 버전·여러 제조사·장시간 발열/배터리는 미검증이다.

읽어야 한다. 세 시드만으로 특정 이념의 보편적 우세를 확정하지 않는다. 전쟁·대회·좌화가 실제 발생한

세 세계 모두 비승 0이었다. 기능 테스트에서 비승 경로는 실행 가능하지만 자연 도달 빈도가 재미와
맞는지는 미결정이다. “불가능”이나 “의도한 희귀도 달성” 어느 쪽으로도 단정하지 않는다.

## 5. 격리 실험과 확정 수준

| 사례 | 실제 관측 | 해석 한계 |
|---|---|---|
| 고급 공법 기연 | 18등급에 +1 처리 → 15등급 | private 보상 연산을 격리 호출. 자연 발생 빈도 미측정 |
| 잘못된 지역 저장 | RegionId999를 담은 gzip JSON → ArgumentOutOfRangeException | 앱 시작 전체를 UI로 재연한 것이 아니라 serializer 경로 재현 |
| 관심 영향 | 시드7·100명·600년, 관심0명과100명의 RNG/핵심 상태 다름 | 입력이 다르므로 같은 입력 결정론 실패라고 부르지 않음 |
| 사건 중첩 | 수조가 남았는데 비경 종료가 영기 .8→1로 덮음 | private 종료 연산으로 상호작용 격리. 자연 중첩 확률 미측정 |
| 개창 원로 최초 기록 | 0년에 금단 이상 2명, FirstReach[2]는 null | 최초 기록이 개창 이전 인물을 제외한다는 기획일 수도 있음 |

이 결과와 정적 소스 확인을 [12](12-open-questions.md)에서 나누어 설명한다.
재현 도구는 임시 별도 콘솔 프로젝트이며 게임 빌드·자동 테스트에 추가하지 않았다.

## 6. 추가 검증 제안

| 우선 검토 | 제안 수용 증거 |
|---|---|
| 저장 의미 검증·복구 | 잘못된 ID·중복·null·큰 파일을 거부하고 정상 슬롯 유지, 시작 실패 대신 안내 |
| 관찰 입력의 영향 | 허용 여부 결정 후 동일 시드·개입 없는 관심 변경 A/B 검사 |
| 보상 단조성·공법 도달 | 전 등급 보상 경계 검사, 정의한 최고 공법의 정상 획득 경로 |
| 사건 중첩 | 비경/수조 및 동일 종류 중첩의 시작·종료 순서 조합 검사 |
| Android 입력 | 가려진 시스템 대화상자 없이 일곱 탭·상세·검색·설정·저장 교체·뒤로 가기 영상/PNG·입력 증거 |
| 성능 | 인구100/1,000/3,000, 실기기 저/중급, 초기·장기 저장 크기·로드/저장·프레임·메모리·발열 측정 |
| 장기 밸런스 | 합의한 시드 수와 기간, 경지별 인구·최초 도달·비승·종문 승률·부 분포·사건 빈도 분포 |
| 배포 갱신 | 같은 인증서·증가한 versionCode로 이전 설치 위 업데이트, 저장 호환 확인 |

위 항목은 제안이며 현재 완료 표시하지 않는다. 제품 오너와 클로드가 목표·우선순위를 정한 뒤
[09](09-requirements-and-roadmap.md)의 수용 기준으로 구체화한다.
