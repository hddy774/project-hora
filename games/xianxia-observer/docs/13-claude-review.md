# 13. 클로드 검토 결과와 개선 계획

검토일: 2026-10-29. 대상: [10 검토 요청문](10-claude-review-request.md)의 범위 전체(01~12와 부속 자료).
기준 코드: `17b48ad` (PR #28 병합 커밋 `137fbfa`와 게임 소스·테스트 동일).

이 문서는 **검토 의견과 권장안**이다. 오너가 결정 표(§4)에서 고른 항목만 작업 명세의 상태를 `승인`으로 바꾼다.
작업 명세는 [docs/tasks/](../../../docs/tasks/README.md)의 XO-03~XO-10이다.

## 0. 검토 방법과 한계

- **코드 정적 대조**: 문서의 수식·처리 순서·OQ 근거를 기준 코드 파일에서 직접 읽어 확인했다. 아래 표의 근거 열에 파일과 줄을 적었다.
- **실행 검증 없음**: 검토 환경의 네트워크 정책으로 .NET SDK를 설치하지 못했다. 격리 실험 5건과 3시드 실측은
  **다시 실행하지 않았다.** 해당 관측은 코드 경로가 실험 결과와 맞는지만 확인했다.
- **추정** 표시: 실행 없이 식으로 계산한 값은 `(추정)`으로 표시했다. 수용 기준에 쓰기 전에 XO-10 도구로 실측해야 한다.
- Android 실기기·에뮬레이터는 확인하지 않았다. 문서 08의 증거 범위를 그대로 따른다.

## 1. 상위 5개 — 먼저 결정하거나 고칠 것

| 순위 | 항목 | 이유 |

## 3. 밸런스 — 권장 목표와 이유

측정치는 3시드뿐이므로 아래 수치는 **제안**이며 확정 사실이 아니다. 먼저 XO-10으로 10시드 분포를 얻은 뒤 확정한다.

| 지표 | 현재 관측 (3시드·3만 년) | 권장 목표(제안) | 이유 |
|---|---|---|---|
| 경지 분포 | 화신경이 최빈(307~405), 대승 4~16, 반선 0~1 | 3만 년 시점 중앙값: 화신 이상 30~45%, 대승 이상 1~3% | 피라미드 상층이 "관찰할 고수"를 공급하되 희소해야 기록이 의미를 가짐 |
| 첫 도달 연도 | 측정 안 됨 | 원영 ≤ 1,000년, 화신 ≤ 3,000년(첫 전쟁 전), 대승 ≤ 15,000년 | 첫 세션(20년/초 × 10분 ≈ 12,000년)에서 고경지 등장을 목격 가능 |
| 비승 | 0/0/0. 구조적으로 자연 비승 거의 불가(R-04, 추정) | 1,000명·3만 년에서 시드 중앙값 1~3회, 첫 비승 15,000~30,000년 | 비승은 유일한 "완결" 사건. 한 번도 못 보면 장기 동기가 사라짐 |
| 종문 회복성 | 전쟁 9회 정3·마6, 시드3은 접경 5:0 | 10시드에서 어느 종문도 연속 3회 전쟁 패배 비율 ≤ 20%, 전쟁 승률 30~70% | 비대칭은 허용하되 한쪽 고착은 관찰 서사를 단조롭게 함 |
| 영석 흐름 | 장부 일치, 총량 2.4~2.7억 | 1만 년 이후 총량 증가율이 시대 1주기 동안 ±50% 이내 | 인플레이션이 경매·상회 가격 의미를 무너뜨리는지 확인 |
| 천기 영향 | 측정 안 됨 | 기연 1회가 대상의 다음 소경지 도달 시간을 30~70% 단축 | 현재 고경지에서 비율 보상이 수만 년 가치 → 개입 효과가 경지에 따라 극단적으로 달라짐 |

조정 순서 권장: D-01 결정 → XO-06 적용 → XO-10 측정 → D-02·D-03 수치 확정 → 밸런스 명세(1회에 한 계수군).
비승을 늘리는 1차 후보는 반선경 요구 영기 축소 또는 수련 성장률(1.55)과 요구 증가율의 격차 축소다. 공법·천겁 계수부터 바꾸지 않는다.
