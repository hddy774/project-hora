상태: 대표 PR #32 통합 검증 중. 구현·자동 검사·Android 실제 입력·공식 게시를 서로 구분한다.

## 게임과 화면

게임 이름은 **선로만상록 프로젝트**다. 수선자·종문·전쟁·인연·윤회를 관찰하는 한국어 오프라인 게임이다.
Android 우선 세로 화면이며 같은 C# 시뮬레이션과 Avalonia UI를 데스크톱·검사에서 공유한다.
수선자의 행동은 AI가 정하고 관찰자는 관심 표시·속도·정지와 제한된 천기 개입을 사용한다.

## 시각·접근·입력

한지#F3E8CC·밝은 종이#FAF3DF·먹#202A2B·목재#805B25, 청운#2F5B79·천마#914740을 사용한다.
산수는 고정 벡터 장식이고 판 테두리/낙관 색을 사용한다. 선택은 색·문자·테두리로 함께 표현한다.
본문15sp·보조 최소13sp·제목20sp, 게임 버튼 최소48dp, 기본 좌우 여백16dp다.
주요 글자/동작 색은 밝은 종이 위 대비4.5:1 이상으로 확인했다. 표본은 woodblock-theme-20261029.json.

시스템 글자 배율은 자원 바인딩으로 기존 텍스트·차트 축·지도까지 반영한다. 화면 전체를 축소하지 않는다.
큰 글자 지도는 번호 약도와 동일 지역 목록으로 이름·인구·사건을 읽고 같은 상세로 이동한다.
통계는 실제 표본 연도에 비례해 그리며 색과 이름 범례를 함께 표시한다. 압축 표본을 균등 간격으로 바꾸지 않는다.
안전 여백은 루트에서만 적용하고 실제 렌더 밀도가 바뀌면 현재 플랫폼 여백을 다시 읽는다.
키보드 중 본문 공간 확보와 상세 큰 글자 배치는 별도 UI-QA 증거로 확인한다.

추천은 보관된 최근100년의 돌파·대회 생존 ID를 최신 연도 내림차순/ID 오름차순으로 중복 제거한다.
후보0이면 현재 전투력/ID 순으로3명을 고른다. 보관 밖 사건을 복원하거나 새 난수를 뽑지 않는다.
토스트는1개만 표시하고 상세·검색 입력 중 보류한 최신 알림을 복귀 후 표시한다. 사건을 재발행하지 않는다.

## 기술 구조와 추적

Simulation은 엔진을 참조하지 않는 net10.0 규칙·데이터·저장이다. App은 Avalonia12.1.4 화면/질의/세션이다.
Desktop/Android는 호스트다. SimulationRunner가 세계를 잠금으로 보호하고 별도 스레드에서 진행한다.
UI는 초당 최대4번 보이는 화면만 읽는다. 진단 누계는 JsonIgnore·명시 환경 변수이고 게임 난수를 사용하지 않는다.
Android의 화면 전환 출력과 초기 글자 배율은 Application 빌더에서 연결해 저장 복구 로그보다 먼저 준비한다.
실제 전환과 입력 뒤 보이는 조작/본문 좌표를 기록하며 연간 진행 자체에는 UI 로그를 남기지 않는다.

| 모듈 | 코드/검사 |
|---|---|
| 세계/규칙 | src/Xianxia.Simulation/Model,Data,Systems,WorldSimulator.cs |
| 결정론/저장 | Persistence/WorldSerializer·WorldValidator, Services/SaveStore·GameSession·SimulationRunner |
| 화면/이동 | Pages,Sheets, Views/MainView·SheetHost·Destinations·TransportBar |
| 테마/글자 | Theme/Palette·Typography, Controls/Ui·RegionMap·Charts |
| 순수 관찰 | RecommendationQuery·PeopleQuery, ToastHost, 별도 로그 RNG |
| 도구 | Xianxia.Tools report --seeds1-10 --years30000 --population1000 --balance |
| 자동 검사 | Simulation.Tests, App.Tests, tools/tests의 진행/입력/버전 계약 |

3,000명·10만년의 변경 후 저장은5,307,299바이트, Souls3,536/전쟁9/대회91이다.
저장·로드725.03/1,043.88ms는 공유 Linux 참고값이며 Android·발열·전력·정밀 회귀 성능으로 쓰지 않는다.
실제 PeopleQuery3,000명×8정렬×50표본도 원시 JSON과 공유 호스트 한계를 함께 보관한다.

## 배포와 증거

버전0.2.0/코드2, APK ID org.hora.xianxiaobserver, 최소API24, ARM64/x86_64, 인터넷 권한 없음.
출시 인증서SHA-256은0832f24441f1caf335166fbc16ae0b9536e262ca48f258926a8027fc31dca25a를 유지한다.
키스토어는 보관된 CI 비밀에서 임시 경로로만 사용하며 개발 작업 폴더로 가져오지 않는다.
공식 태그는 xianxia-observer/v0.2.0, 공개 첨부는 XianxiaObserver-v0.2.0.apk1개다.
main의 최종 SHA로 검사·서명하고 같은 APK를 API24/34에 설치해 실제 입력·기존 공개 저장 업데이트·재실행을 확인한다.
런처 포커스 음성 대조와 새 전환 로그가 없으면 실패한다. PNG만 남기고 탭 성공이라고 하지 않는다.
초안 첨부 재다운로드 해시→최신 안정 게시→공개 다운로드 해시를 확인하며 기존 게시 태그는 덮어쓰지 않는다.

물리 ARM64 기기는 사용자가 연결 불가라고 확인했다. 실기기·장시간 발열 검사는 미실행으로 남긴다.
에뮬레이터·헤드리스 결과를 실기기 통과로 바꾸지 않는다. 수동 항목은 device-checklist.md에 있다.
완료한 서브 PR은 대표 브랜치에 병합하고 최종 대표 PR을 main에 병합한다. 진행표는 실제 검사 근거로 갱신한다.
