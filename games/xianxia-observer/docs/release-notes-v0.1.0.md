선협 세계가 스스로 흘러가는 한국어 오프라인 관찰 게임입니다.

- 천하·종문·인물·사기·업적·현황·기록의 7개 탭을 제공합니다.
- 인물 검색·소속/관심 필터·8종 정렬·쪽 넘김, 종문 시설·직위·강자·공헌을 확인할 수 있습니다.
- 인물의 수행·전투력·소지품·인연·생애·윤회, 지역 시장·거주자, 대비무 대진표·전쟁사를 탐색합니다.
- 천기로 기연을 내리거나 지역에 비경·수조를 열 수 있습니다.
- 경지·종문 추이 그래프, 영석 보존 장부와 호칭 도감을 제공합니다.
- 자동 저장·백그라운드 저장·수동 저장/불러오기와 시드·인구를 정한 새 세계를 지원합니다.

Android 7.0(API 24) 이상, ARM64·x86_64, 세로 화면입니다. 패키지는 `org.hora.xianxiaobserver`,
버전 코드 1이며 인터넷 권한이 없습니다. 호라경제연구실과는 별도로 설치됩니다.
