# [XO-14] 성장·수명·종문 회복성 밸런스

상태: 승인(2026-10-29 사용자 전체 피드백 수용) · 선행: XO-10.
근거: 클로드 검토13 §3과 전체 구현 승인17.

XO-10의 고정 기준10시드 보고서에서 경지·비승·종문 승패·영석·영기 출처를 확인한 다음 조정한다.
첫 조정 대상은 경지별 총 요구 영기와 수련 성장률의 격차다. 공법·천겁 확률은 처음부터 동시에 바꾸지 않는다.
목표는 화신 이상30~45%, 대승 이상1~3%, 자연 비승 중앙값1~3회, 첫 비승15,000~30,000년이다.
종문 승률30~70%·연속3패 비율20% 이하, 1만 년 이후5,000년 총량 변동±50%를 함께 본다.
천기1회가 다음 단계 도달 시간을30~70% 줄이는지 별도 대조군으로 측정한다.

- [x] 목표 범위 미달이 있으면 실제값과 원인을 기록하고 조정을 계속한다.
- [x] 영석 장부·인구·직위·관계·저장 연속성 불변식과 전체 테스트 통과.
- [x] 버전 노트에 동일 시드 미래 변경·구 저장 호환과 실제 도달 범위를 적는다.
