# PC 0.0.21 대경지 세부 수행 진척 계약

## 사용자 확정 범위

- 기존 `수행 진척`에 현재 대경지의 세부 수행 과정을 함께 표시한다.
- 연기경은 영기를 감지하고 감응한 뒤 수행 원리를 이해·깨닫고, 영기를 인도해 단전에
  축적하는 흐름을 보여 준다. 요청의 `강응`은 문맥상 `감응`으로 정리해 UI에 표기한다.
- 세부 진척을 추가해도 사용자가 확정한 선천 수행자질 50.00 기준과 대경지 전체
  1층→9층·대원만 수행 기간은 바뀌지 않는다.

## 계산·권위 계약

- `CultivationDetailProgressRules`는 기존 권위 Work를 읽어 관찰용 진척으로 투영한다.
  별도 RNG를 소비하거나 Work·병목·돌파·경지 구성요소를 변경하지 않는다.
- 현재 대경지 누적 Work는 `완료한 층의 RequiredWork 합 + 현재 층 Work`다. 9층 완성
  또는 대원만이면 대경지 전체 Work로 고정한다.
- 다섯 단계 가중치는 임시로 `10 / 15 / 20 / 25 / 30%`이며 각 단계는 0.00~100.00%,
  전체 대경지는 0.00~100.00%로 정수 basis point에서 계산한다.
- 세부 단계의 `깨달음`은 수행 원리를 이해하는 관찰 문구다. 공법·법술 품질을 올리지
  않고, 별도 깨달음 사건이나 영구 연대기를 생성하지 않는다.
- 이 기능은 권위 상태가 아니라 결정론적 파생 DTO이므로 checkpoint/world schema와
  state hash를 변경하지 않는다.

## 관찰 UI·성능 계약

- 인물의 `수행·자질` 내부 탭에 `대경지 세부 수행 진척` Expander를 추가한다.
- Expander 안에는 현재 단계, 대경지 전체 Work와 다섯 개 단계별 진행 막대를 표시한다.
  내부에는 별도 `ScrollViewer`를 두지 않고 기존 인물 상세의 외부 스크롤만 사용한다.
- Expander가 닫혀 있거나 수행 탭을 보지 않을 때 `ObservationSections.CultivationDetail`을
  요청하지 않으며 단계 DTO와 UI 행을 만들지 않는다.
- 범인은 연기경으로 위장하지 않고 `범인 입문 준비` 단계로 표시한다.

## PC_TEMP_REVIEW revision 1

- `PC-TEMP-CULT-DETAIL-STAGES-021`: 범인 입문 및 10대경지의 다섯 단계 명칭·설명,
  순차 진행 방식과 10/15/20/25/30% 가중치.

이 값은 승인된 Notion 공식으로 위장하지 않으며 다음 수행 기획 검토에서 단계의 병렬
진행 여부, 경지·층별 가중치, 실제 사건과의 연결을 재검토한다.
